 시간만 있으면...

 2.

 매일 글을 쓰시면 충성도 높은 독자와 고객을 많이 확보하실 수 있을 거예요.


 저도 왕년에 잡지에 기고도 하고 글 좀 썼었어요.

 맘만 먹으면 언제든지.... ㅎㅎ


 뚜우~ 뚜우~ 뚜우



 3.

 그분처럼 매일 글을 써보는 건 어떠세요?


 그분 글 읽어 봤는데 전 별로 안 와닿더라고요. 근데 저도 글 쓸 내용 많은데 한번 써봐야겠네요.


 뚜우~ 뚜우~ 뚜우~



 4.

 그분이 운영하는 전문가 커뮤니티에 참여해서 스터디와 네트워킹을 좀 하시면 어떨까요?


 그 친구 제가 가르치다시피 한 친구예요.

 제가 강의나 모임 같은 거 하면 더 잘할 수 있어요.
