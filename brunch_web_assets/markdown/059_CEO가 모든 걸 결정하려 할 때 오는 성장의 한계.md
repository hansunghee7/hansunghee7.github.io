# 📝 059_CEO가 모든 걸 결정하려 할 때 오는 성장의 한계

📂 **브런치북: 성장 정체 해부학**


![대표 이미지](/brunch_web_assets/images/059_CEO%EA%B0%80%20%EB%AA%A8%EB%93%A0%20%EA%B1%B8%20%EA%B2%B0%EC%A0%95%ED%95%98%EB%A0%A4%20%ED%95%A0%20%EB%95%8C%20%EC%98%A4%EB%8A%94%20%EC%84%B1%EC%9E%A5%EC%9D%98%20%ED%95%9C%EA%B3%84_cover.jpg)

"시리즈B 라운드 후 팀이 50명을 넘어서자, 의사결정 속도가 현저히 떨어졌다."

그 이유는 모든 결정이 CEO 책상에서 병목되고 있었기 때문이었습니다.

창업 초기엔 CEO가 모든 것을 직접 결정하는 게 당연했습니다. 하지만 조직이 커질수록 이런 방식은 독이 됩니다.

첫째, 결정 속도가 급격히 떨어집니다. 간단한 기능 하나 추가하는 데도 CEO 승인을 기다려야 하니 일주일이 한 달이 됩니다.

둘째, 인재들이 떠나기 시작합니다. 실력 있는 팀원들은 자율성을 원합니다. 모든 결정을 상부에서 내리면 시니어급 인재들이 먼저 이탈합니다.

셋째, CEO 본인도 지쳐갑니다. 하루 종일 크고 작은 결정을 내리느라 정작 중요한 전략적 사고에 집중할 시간이 없어집니다.

마이크로매니지먼트는 성장의 천장입니다. 해법은 '결정 권한 매트릭스' 구축입니다. 제품·영업·재무·문화 네 영역으로 권한을 나누고, 의사결정 단계·금액·위험도를 기준으로 위임 레벨을 문서화해야 합니다.

예를 들어, 100만원 이하 마케팅 비용은 마케팅 팀장이 결정하고, 신규 기능 개발은 PM과 개발팀장이 함께 결정하되, 1000만원 이상 투자나 핵심 전략 변경만 CEO가 직접 결정하는 식입니다.

핵심은 CEO는 '왜'만 말하고 '어떻게'는 팀이 결정하도록 하는 것입니다. 비전과 방향성은 CEO가 제시하되, 구체적인 실행 방법은 각 팀의 전문성에 맡겨야 합니다. 하지만 권한을 위임했을 때 각 팀이 제각각 다른 방향으로 가면 안 됩니다. 모든 팀이 같은 기준으로 의사결정할 수 있는 나침반이 필요합니다.

바로 이 지점에서 성장 목표에 얼라인된 비전, 핵심지표, 브랜딩이 핵심 역할을 합니다. 명확한 회사의 지향점이 있어야 각 팀이 "이것이 우리 가치에 부합하는가?"라는 동일한 기준으로 판단할 수 있습니다.

권한 위임과 지향점이 함께 작동할 때, 조직은 성장의 속도를 가속화시킬 수 있습니다.
