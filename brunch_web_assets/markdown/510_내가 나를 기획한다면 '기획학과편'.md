# 📝 510_내가 나를 기획한다면 '기획학과편'

📂 **미분류**


#### 

#### ‘[링크드인](https://www.linkedin.com/in/simplifier/ "https://www.linkedin.com/in/simplifier/") X [페이스북](https://www.facebook.com/sunghee.han.790 "https://www.facebook.com/sunghee.han.790")’ 동시 진행, 심플리파이어 싱가포르 가족여행명 공모전 결과 및 추천 여행 정보를 발표합니다.

#### 

#### 4년 만에 떠나는 4박 5일 싱가포르 가족여행에 생각보다 많은 이웃들이 여행정보와 타이틀을 제안주셔서 감격을 하며, 스프레드시트라는 최첨단 기술을 동원하여 최종 정리한 내용을 공유합니다.

#### 

#### 싱가포르 여행을 가실 계획이 있으실 분은 참고하시기 바랍니다. :-)
