# Simplifier SNS 인사이트 수집기 (크롬 확장, 개인용)

LinkedIn·Facebook·Instagram·Threads·네이버블로그·리멤버·로켓펀치 프로필을
열 때 팔로워 수를 자동으로 읽어서, Simplifier Studio의 "SNS 인사이트"에
기록해주는 개인용 크롬 확장입니다.

## 설치 방법 (한 번만 하면 됨)

1. 크롬 주소창에 `chrome://extensions` 입력 후 이동
2. 오른쪽 위 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 버튼 클릭
4. 이 폴더(`_sns-extension`)를 선택
5. 브라우저 오른쪽 위 확장 아이콘 목록에서 "Simplifier SNS 인사이트 수집기" 아이콘 클릭
6. "GitHub 연결" 버튼 클릭 → 뜨는 창에서 GitHub 로그인(글쓰기 CMS 로그인할 때와 동일한 방식)

여기까지 하면 끝입니다. 이후로는 평소처럼 멀티 퍼블리싱에서 "새 글쓰기
열기" 버튼으로 각 SNS를 방문할 때마다, 그 화면에 보이는 팔로워 수가
자동으로 기록됩니다.

## 확인하는 곳

Simplifier Studio → "SNS 인사이트" 탭에서 쌓인 기록을 그래프로 볼 수
있습니다.

## 참고

- 이 확장은 오직 본인 브라우저 안에서만 동작하고, 본인이 실제로 로그인한
  화면에 보이는 숫자만 읽습니다. 어딘가에 몰래 접속하거나 비밀번호를
  가져가지 않습니다.
- 사이트가 화면을 바꾸면 숫자를 못 찾을 수 있습니다. 그럴 땐 그 페이지에
  실제로 어떻게 적혀 있는지 알려주시면 바로 고칠 수 있습니다.
- 크롬 확장을 새로고침해야 할 때(코드가 바뀌었을 때)는 `chrome://extensions`
  에서 이 확장의 새로고침 아이콘을 누르면 됩니다.
