PROCESS.md·VISUAL_GRAMMAR.md·PRODUCTION_ROLES.md는 "엔진 설계도" — 제가 씬 플랜을 만들 때 내부적으로 참조하는 규칙서입니다. 성희님이 그 규칙을 직접 알거나 신경 쓸 필요는 없습니다. 이 문서는 그 엔진을 돌려서 실제로 반복하는 7단계 루프만 남긴 실행 매뉴얼입니다 — 매 단계에서 성희님 손에 남는 건 결과물 하나뿐입니다.

지금의 현실적 제약 (이것 때문에 루프가 이런 모양)

  • Typecast: 공개 API가 없어서 브라우저에서 직접 생성·녹음 캡처 — 수동.
  • Veo(Google Flow): API를 안 쓰고 Flow UI에 프롬프트를 직접 붙여넣어 클립 생성 — 수동.
  • 이 두 수동 단계는 사람(성희님)만 할 수 있는 구간이고, 그 앞뒤를 제가 채웁니다.

7단계 루프

  1. 주제 제공 (성희님) — 주제 초안 + 참고 시나리오(있으면) 전달.
  2. 대본 초안 (Claude) — channel.json 톤·구조·sentence_rule 적용해 초안 작성. 결과물: 대본 텍스트 하나.
  3. 대본 검수 (성희님) — 읽고 수정 지시.
  4. 음성 녹음 (성희님) — Typecast에서 생성 → 녹음 파일 전달.
  5. 씬 플랜 + 프롬프트 생성 (Claude) — 성희님이 안 봐도 되는, 제가 내부적으로 하는 일: - Whisper로 실제 발화 타이밍 정렬 - VISUAL_GRAMMAR.md 전체 규칙(역동성·인포그래픽·전환연속성·대사동기화)을 적용해 씬별 프롬프트 작성 - validate_scene_plan.py 기계 검증이 0건 될 때까지 스스로 반복 수정 - 결과물: 씬 플랜 페이지(아티팩트) 링크 하나.
  6. Veo 테스트 (성희님) — Flow에 프롬프트 붙여넣어 클립 생성.
  7. 결과 리뷰 (같이) — 생성된 클립을 보고 다음 라운드에 반영할 점 논의 → 2번(대본 문제) 또는 5번(씬/프롬프트 문제)으로 되돌아감.
① 주제(성희) → ② 대본 초안(Claude) → ③ 검수(성희)
   → ④ 녹음(Typecast, 성희) → ⑤ 씬플랜+프롬프트(Claude)
   → ⑥ Veo 테스트(성희) → ⑦ 리뷰(같이) → ②나 ⑤로 반복

지금 라운드에서 성희님이 할 일

ep01(복도의 문)은 ⑤까지 끝난 상태 — 45개 씬 프롬프트가 검증 완료돼 있습니다. 지금은 ⑥ 단계: 씬 플랜 페이지의 프롬프트를 Veo 3.1 Lite/Quality에 순서대로 넣어서 실제 클립을 뽑아보는 것 — 특히 씬01(기준점)과 씬19(가장 크게 손 본 씬)부터 먼저 테스트해보는 걸 권합니다.
