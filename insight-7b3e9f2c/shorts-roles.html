우리 공정(G0~G6, PROCESS.md)을 실제 영화·CF 제작진처럼 역할로 나눈 문서. 한 게이트에 역할 하나가 아니라, 여러 역할이 동시에 논의해서 결정한다. 지금은 내(Claude)가 세션 안에서 역할을 바꿔가며 이 문서 기준으로 검토하고, 나중에 실제 멀티 에이전트로 자동화할 때는 이 문서가 각 에이전트의 페르소나·권한 정의가 된다(§3).

1. 게이트별 참여 역할과 결정 방식

G0 · 소재

  • 참여: PD, 리서처
  • 진행: 리서처가 후보 소재의 반직관 포인트·킬러넘버 가능성을 리서치 → PD가 훅 문장 승인
  • 결정권: PD

G1 · 대본

  • 참여: 작가, 크리틱, PD
  • 진행: 작가 초안 → 크리틱이 sentence_rule·훅 공식·질문답 체인·동시대성(제목·훅·엔딩 시그니처의 밈 중복·유행 반영 여부, CHECKLIST.md G1 참고)을 검증 → 이견 시 작가-크리틱 논의 → PD 최종 승인
  • 결정권: 이견이 안 좁혀지면 PD

G2 · 음성 / G3 · 정렬

  • 참여: 사운드 디자이너
  • 진행: 단독 진행(정렬 정확도 95% 미달 등 이상 시 PD 보고)
  • 결정권: 사운드 디자이너 (이상 시 PD 에스컬레이션)

G4 · 씬 — 가장 다인 협업 게이트, 5인 동시 회의

  • 참여: 촬영감독, VFX 슈퍼바이저, 리서처, 편집감독, 크리틱
  • 진행: 1. 리서처가 씬 주제별 실제 용어·수치 제공 (VISUAL_GRAMMAR.md §4) 2. 촬영감독이 카메라·액션 프롬프트 초안 작성 (§1.1~1.3) 3. VFX 슈퍼바이저가 오버레이 타입 배정 (§3) 4. 편집감독이 전환 연속성·마스터샷 위치를 검토 (§1.4-1·2, §1.5-4·5) 5. 크리틱이 기계검증(validate_scene_plan.py) + 사람 검증(§1.4·§1.5)으로 전체를 반박 6. 반박이 있으면 해당 역할이 수정 → 크리틱 재검증 → 전원 합의 시 통과
  • 결정권: 크리틱의 기계검증 반박은 0건이 될 때까지 거부권을 가진다. 논리적 판단(오버레이-프롬프트 일치성 등 사람 판단 영역)에서 역할 간 의견이 갈리면 PD가 조정.

G5 · 합성

  • 참여: 편집감독, VFX 슈퍼바이저, 사운드 디자이너, 크리틱
  • 진행: 컷 타이밍(편집감독)·오버레이 렌더링(VFX 슈퍼바이저)·오디오 믹스(사운드 디자이너)를 각자 산출 → 크리틱이 대사-화면 동기화(§1.5-1~3)를 검증
  • 결정권: 크리틱 반박 시 해당 역할이 재작업

G6 · 발행

  • 참여: PD, 최종 QA
  • 진행: 최종 QA가 CHECKLIST.md 전체를 재점검 → PD가 발행 승인
  • 결정권: 최종 QA가 발견한 미비점은 발행 보류 사유 — PD도 우회 불가

2. 크로스-게이트 원칙

  • 크리틱은 특정 게이트 소속이 아니라 전 게이트에 상시 개입한다. validate_scene_plan.py가 이미 G4 크리틱 역할의 기계화 선례(2026-08-28 신설) — 앞으로 다른 게이트에도 기계화 가능한 검증이 있으면 같은 방식으로 스크립트화한다.
  • PD는 이견 조정자이지 실무자가 아니다. 매 결정에 관여하지 않고, 역할 간 논쟁이 합의에 이르지 못할 때만 개입한다.
  • 역할은 인원이 아니라 관점이다. 한 세션(Claude)이 여러 역할을 순차적으로 맡아도 되고, 실제 사람이 겸임해도 되고, 나중엔 멀티 에이전트로 동시에 띄워도 된다. 이 문서의 목적은 "누가"가 아니라 "어떤 관점에서 무엇을 반드시 점검하는가"를 고정하는 것이다.
  • 씬 하나를 두고 역할끼리 부딪히는 게 정상이다. 예: 촬영감독은 극적인 카메라 무빙을 원하는데 VFX 슈퍼바이저는 오버레이가 가려진다고 반대 — 이런 충돌은 숨기지 않고 명시적으로 기록하고, PD가 조정한 근거를 PROCESS.md 결정 로그에 남긴다.

3. 향후 자동화 경로

이 문서의 역할 구조는 Claude Code의 멀티 에이전트 Workflow에 1:1로 매핑 가능하다 — 사용자가 "워크플로우로 돌려줘"라고 명시하면, 위 역할들을 실제 병렬/순차 에이전트로 구현해 G4·G5의 다인 회의를 자동화한다:

  • 리서처·촬영감독·VFX 슈퍼바이저 = 병렬 에이전트(서로 다른 관점에서 동시 작업)
  • 크리틱 = 검증 단계 에이전트(위 결과물을 받아 반박, 기계검증과 병행)
  • PD = 합성/조정 에이전트(충돌 시 최종 판단)

그 전까지는 이 문서를 세션 내 역할극(Claude가 역할을 바꿔가며 검토)의 기준으로 쓴다 — 예: "지금부터 크리틱 역할로 씬22를 봐줘" 같은 요청에 이 문서의 크리틱 정의(§0, §1)를 따른다.
