# 로컬 지시서: 로컬 자율 에이전트 P0 (검사만, 쓰기·렌더링 없음)
사장님확인: 아니오 (P0 시작 사장님 승인 완료 2026-10-07)
발주: 클라우드 탐. 받는 쪽: 로컬 탐 세션(구현은 로컬 스크립트·Qwen, 소넷 서브에이전트 금지). 설계 정본: `docs/설계_로컬_자율에이전트_GPU연동.md`(P0 절).
- 목표: 이미 만들어진 영상 산출물을 결정적 코드로 매일 한 번 검사해 결과를 남긴다. **읽기만 한다.** 렌더링·인코딩·원본 수정·삭제·외부 전송 없음. 클로드 호출 없음(토큰 0).
- 대상: 각 에피소드 폴더의 조립 결과(`05-assemble` 아래 mp4)와 쇼츠 산출물 중 **최근 7일 안에 바뀐 파일**. 대상 폴더 목록은 로컬이 실제 경로를 확인해 스크립트 설정 한 곳(상수)에 둔다(공개 문서에 채널명을 쓰지 않는다).
- 검사 항목(모두 코드가 참·거짓 판정, 기준값은 설정에 둠): ① `ffprobe`: 해상도, 길이, 비디오·오디오 코덱, 오디오 스트림 유무, 파일 크기가 0이 아닌지 ② `ffmpeg`의 `blackdetect`와 `silencedetect`로 검은 화면·무음 구간 길이 합계(임계값은 설정, 처음엔 기록만 하고 통과·실패 판정은 하지 않는다) ③ 같은 에피소드 폴더에 자막 파일이 있으면 줄 수·글자 수 규칙(기존 확정: 한 번에 10글자 이내) 위반 개수. 목표 길이·해상도와의 비교는 명세가 없으므로 이번엔 **기록만** 한다.
- 실행 방식: 낮은 우선순위로, 파일당 시간 제한을 둔다. GPU는 쓰지 않으므로 `gpu_gate`는 필요 없다. 킬 스위치: `C:/work/_ops/STOP_AUTONOMY` 파일이 있으면 시작하지 않는다. 결과는 `C:/work/_ops/p0_inspect/<날짜>.jsonl`(파일 경로, 각 항목 값, 검사 시각)에만 쓴다(그 폴더 밖 쓰기 금지). 실패해도 다른 작업을 멈추지 않는다.
- 안전: 창이 뜨지 않게 실행(`CREATE_NO_WINDOW`), 호스팅 모델에 파일 내용을 보내지 않는다. 비밀·키 폴더는 읽지 않는다.
- 등록과 증거: 주기 작업이므로 지금 1회 실행해 성공 증거, `jobs.toml` 등록, **첫 자동 실행 결과까지** 확인해야 완료. 증거: 첫 실행 결과 줄 수와 대상 파일 수. 일주일 뒤 결과표에서 사람이 표본 5건을 영상 눈 확인과 대조한다(대조 결과도 이 지시서에 붙이는 후속 항목).
- 되돌리기: 크론(작업 스케줄러)을 끄면 끝이다. 쓰기가 없으므로 되돌릴 데이터가 없다.
- 끝나면 결과 5줄을 맨 아래 "P0 결과"에 붙이고, 결과 요약은 덱스에게 한 번 확인한다(소넷 서브에이전트 금지, 질문에 채널명·고객 정보 금지). `git mv tasks/todo/<이 파일> tasks/done/`은 일주일 표본 대조까지 끝난 뒤에 한다(그전엔 todo에 두고 진행 상황만 적는다).
