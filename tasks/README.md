# 지시서 브릿지 (클라우드 관제탑 → 로컬)

클라우드 세션은 `C:/work` 파일·브라우저 임대·헤르메스·GPU·gcloud 로그인을 못 만진다. 그런 일은 여기에 지시서로 올린다.

## 두 갈래 (받는 쪽이 다르다)
- **`tasks/todo/*.md`**: Claude 세션이 있어야 하는 일(훅·판단·사장님 확인이 낀 일). 로컬 탐이 `session_brief.py 탐`의 "열린 지시서" 목록으로 집어 간다(하이~ 때). 자동 실행은 없다.
- **solar-bible `tasks/pending`**: 헤르메스가 혼자 끝낼 수 있는 단순 일. 기존 `pending_poller.py`가 15분마다 받아 간다(감시 대장 `hermes:solar-bible-tasks-poller`).

## 규칙
- 지시서 첫 줄은 제목, 본문에 입력·순서·증거·하지 말 것을 쓴다. 공개 저장소라 고객 실명·키·프로젝트 ID 금지.
- 끝나면 받은 쪽이 증거를 `worklog.py`로 남기고 `git mv tasks/todo/<파일> tasks/done/`.
- 알려진 한계: 로컬 탐 세션이 열려 있지 않으면 `tasks/todo`는 읽히지 않는다. 급하면 우편함 또는 텔레그램을 같이 쓴다.
- 지시서 둘째 줄에 `사장님확인: 예|아니오`를 쓴다. 예(승인·돈·사장님 몫 할 일)면 로컬이 마야 형식 텔레그램 1초 컨펌 알림을 보내고, 아니오면 폰 알림 없이 로컬 inbox에만 기록한다.
- 큐 정본은 `tasks/QUEUE.md`.
