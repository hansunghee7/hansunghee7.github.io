# 유튜브 스튜디오 브라우저 화면수집 가이드

> 2026-09-21 사장님 결정: **API 수집 방안(YouTube Analytics API)은 지연(분석 데이터가 2~3일 늦게 확정), 유료·인증 요소 등 제약이 많아 폐기하고, 브라우저 화면수집으로 간다.** 이 문서가 그 방식의 정본이다. 관련: [딥리서치 실행 가이드](딥리서치_실행_가이드.md)(같은 도구·같은 원칙).

## 1. 무엇을 수집하나

| 종류 | 어디서 | 로그인 |
|---|---|---|
| 공개 수치(구독자, 동영상 수, 영상별 조회수) | 공개 채널 페이지 `youtube.com/@sinkihanapt/shorts` | **필요 없음** |
| Studio 전용 수치(시청 지속률, 유입 경로, 노출수, 노출 클릭률, 최근 28일 요약) | YouTube Studio 분석·콘텐츠 화면 | **채널 소유 계정 로그인 필요** |

공개 수치는 기존 무료 API 수집(`fetch_youtube.py`, 매일 자동)이 계속 돌고, 화면수집은 그 값과 **교차 확인**하는 용도로 쓴다.

## 2. 누가 어떻게 하나

- **서브에이전트(소넷급)가 Claude in Chrome으로** 수집한다. 부모 세션은 수집 지시와 판정만 한다. 헤르메스는 화면 조작이 승인 필요라 무인으로 못 한다(2026-09-21 실측, 어사이드 유인 시험만 가능).
- 조작 요령은 딥리서치 가이드 4절과 같다(자기 탭 하나, `find`로 ref 확인, `get_page_text`로 본문, 끝나면 탭 닫기).
- 읽기 전용이다: 허용되는 조작은 화면 이동(Studio 왼쪽 메뉴), 기간 선택 탭, 스크롤, 새로고침뿐이다. **수정, 삭제, 업로드, 댓글, 설정 변경, 게시 금지.**

## 3. 사장님이 해 두셔야 하는 것

1. **채널 소유 계정이 로그인된 크롬 프로필**을 준비한다. 로그인은 사장님만 한다(에이전트는 비밀번호·2단계 인증을 통과하지 않는다).
2. 권장: **다른 프로필과 분리**한다. 개인 SNS와 업무 계정이 함께 로그인된 브라우저에서 무인 조작하는 위험을 피하려는 것이다(cxo-db #140). 채널 계정만 로그인된 전용 크롬 프로필이 가장 안전하다.
3. 2026-09-21 실측: 지금 Claude in Chrome이 붙는 크롬에는 채널이 없는 개인 지메일이 유튜브 기본 계정이라 `studio.youtube.com`이 채널 만들기 화면으로 넘어갔다. **채널 만들기 창이 뜨면 잘못된 계정이 로그인됐다는 신호**이니 "취소"만 누르고 멈춘다(만들지 않는다).

## 4. 안전 규칙 (어기면 그 실행은 실패)

1. 로그인·비밀번호·2단계 인증·CAPTCHA·본인 확인 화면이 나오면 즉시 멈추고 "막힘"으로 보고한다. 채널 만들기 창도 같다.
2. youtube.com·studio.youtube.com 밖으로 나가지 않는다. 다른 탭·다른 즐겨찾기는 열지 않는다.
3. 이메일·계정 표시는 보고서에 쓰지 않는다.
4. 실수로 눌러도 되돌릴 수 없는 버튼(게시, 삭제, 채널 만들기, 구독)은 누르지 않는다.
5. 원본 수치는 **저장소 밖** `C:\work\_ops\studio\<날짜>.md`에 저장한다(공개 저장소에 비공개 분석 수치를 올리지 않는다). 대시보드로 보낼지는 따로 정한다.

## 5. 수집 절차와 검증

1. 공개 페이지를 먼저 읽는다(로그인 없이). 구독자, 동영상 수, 영상별 조회수를 표로 만든다. 화면은 조회수를 **잘라서** 표시한다(1,368은 "1.3천회"). 정확한 값과 비교할 때는 "1.3천 = 1,300~1,399"로 본다.
2. Studio 화면(계정이 맞을 때만): 개요(최근 28일 조회수·시청 시간·구독자), 콘텐츠(영상별 조회수·평균 시청 지속률), 유입 경로, 노출수와 노출 클릭률. 각 수치 옆에 **화면에 표시된 기간**을 같이 적는다(없으면 "기간 불명").
3. **검증**: 구독자·영상별 조회수를 공개 페이지 값과 대조한다. 대조 가능한 항목의 절반 미만이면 "검증 불충분"으로 표시한다.
4. 새로고침을 한 번 하고 값이 바뀌는지 기록한다.

## 6. 실측 기록 (2026-09-21)

- **공개 페이지 수집: 성공.** 크롬 확장으로 열어 스크롤 한 번에 영상 10개를 모두 읽었고, 구독자 28명·동영상 10개·영상별 조회수가 API 수집값과 전부 일치했다(표시 잘림 고려).
- **Studio 수집: 미시험.** 채널 계정이 이 크롬에 로그인돼 있지 않아 막혔다(3절). 사장님이 계정을 준비하면 시험한다.
- 어사이드(채널 계정 로그인됨)는 헤르메스 화면 조작이 승인 필요라 무인 시험이 막혔고, 승인 없이 되는 화면 읽기(캡처)는 가능했다.

## 7. 지금 하지 않는 것

- YouTube Analytics API와 유료 API는 쓰지 않는다(사장님 결정, 위 상단).
- 자동 예약(크론) 화면수집은 하지 않는다. 로그인 재인증이 언제 나올지 모르고, 계정이 분리되기 전에는 개인 SNS가 같은 브라우저에 있다. 승격 신호: 전용 프로필이 준비되고 첫 유인 실측이 성공했을 때.
