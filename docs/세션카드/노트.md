# 세션 시작 카드: 노트 (2026-10-03 기준)

**하이~ 첫 명령(2026-10-05 신설): `python scripts/ops/session_brief.py 노트`** 한 번이 내 최신 인수인계 원문과 열린 건 목록(번호·제목)과 상태판 문제 줄을 약 5~6KB로 준다. 업무대장·진행상황.md 전체는 읽지 않는다(세부는 `python scripts/ops/opsdb.py select tasks --where no=eq.N번호 --cols title,raw --fmt json`으로 그 행만). DB는 최대 1시간 뒤처질 수 있어 방금 바뀐 건은 md를 직접 본다. 규칙 정본: 탐 프로세스표 9절.

**작업 기록은 직접 DB에 쓴다(2026-10-05 신설, 탐이 대신 옮기지 않는다)**: `python scripts/ops/worklog.py add --who 노트 "한 일 한 줄" [--task N번호] [--evidence 로그경로]` (추가 전용, 300자, 비밀값 모양은 거부). 내 최근 기록은 `python scripts/ops/worklog.py list --who 노트`, 전체 오늘 기록은 `worklog.py today`. 업무대장 md는 시간당 자동으로 DB에 복사되는 거울이다.

**공정은 DB에서 단계 카드로 관리한다(2026-10-05 신설, 사장님: 토큰 부담 없이 쉽게 쓰고 읽고 고치고 단계별로 진행)**: 읽기 `python scripts/ops/proc.py steps <공정>`(공정 전체 카드, 사장님 말 포함) · 키워드 `proc.py show 자막`. 쓰기·고치기 `proc.py add <공정> "제목" --do ".." --boss "사장님 말(날짜)"` / `proc.py amend <공정> <번호> ...`. 작업 1건 진행 `proc.py run start <공정> "작업명"` → 단계마다 `proc.py run done <run번호> <단계> --evidence "경로"`(증거 없으면 완료 안 됨) → `run status <번호>`로 빠진 단계 확인.

목표: 다른 페르소나가 넘긴 전문 개발을 구현한다. 새김(Carvit) MCP 개발, 서비스 화면, 자동화 스크립트를 담당한다.
