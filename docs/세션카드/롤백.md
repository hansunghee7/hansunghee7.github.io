# 세션 시작 카드 롤백

## 끄는 법
- 파일 `C:/work/_ops/session_card_off` 를 만든다(빈 파일). 다음 세션부터 카드 줄이 사라진다.

## 켜는 법
- 그 파일을 지운다. 기본은 켜짐이다.

## 훅을 도입 전으로 되돌리는 법
- `git log --oneline -- .claude/hooks/session-start.sh` 로 카드 도입 커밋을 찾고 `git revert <커밋>` 으로 PR을 낸다.

## 롤백 판단 신호
- 세션 시작 시간이 눈에 띄게 늘어난다.
- 카드 내용 때문에 틀린 행동이 생긴다(역할노트와 다른 안내).
- 안내 횟수는 `python scripts/ops/card_reads_report.py` 로 센다.

- **카빗DM 모니터(2026-10-23, 카빗DM 3차 항목 13·15)**: 새 세션은 모니터가 꺼진 채 시작한다. 세션 시작 훅이 첫 줄에 '🔴 카빗DM 모니터 꺼짐'과 켜는 명령을 보여 주면, 사장님께 묻지 말고 첫 보고 전에 그 명령을 Monitor 도구(timeout_ms 1800000)로 켠다. 설정 파일은 `C:/work/_ops/carvit_<영문이름>/autoreceive_config.json`이다. 신호 1건이나 30분 만료 뒤에는 같은 명령으로 다시 건다. 앱 세션 제외 안내가 나와도 이 방식은 앱에서 돈다(노트 확인).
