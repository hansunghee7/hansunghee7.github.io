# R6·R12 막혔을 때 안내: 사용자 증상 기준 초안 (노트, 2026-10-22)

용도: 설치와 연결에서 막힌 사용자에게 "증상 → 이렇게 하세요" 한 장으로 보여 주는 정적 안내의 내용 초안이다. 문구 다듬기와 화면은 지투가 맡는다(합본 스펙 R6·R12). 근거는 정본의 막힘 진단표(B4)이고, 오늘 바뀐 설치 방식(uvx·pip, zip 폐기)과 출근 판정(R10)을 반영했다. 사용자 글이라 옛 이름·도구 이름·zip 표현은 쓰지 않는다.

한 줄 머리말: 어디서 막혔는지 모르겠으면 에이전트에게 "Carvit 도움말 보여 줘"라고 하세요.

## 증상별 안내

- 설치했는데 에이전트가 "도구가 안 보여요, 다시 시작하세요"라고 해요.
  - 같은 폴더에서 새 세션을 여세요. 한 세션 안에서는 새로 설치한 도구가 나타나지 않아요. 앱의 다시 시작 버튼은 효과가 없어요.
  - 근거: B4 S1(앱에서 확인).
- 새 세션에서도 도구가 안 보이거나 예전 이름으로 나와요.
  - 설정 > 커넥터에서 같은 주소의 계정 커넥터가 남아 있는지 보세요. 있으면 지우고 새 세션을 여세요. 같은 세션에서 계정 커넥터를 추가하면 기존 Carvit 도구가 끊길 수도 있어요.
  - 상태: 부분 확인(B4 S2). 재현이 일정하지 않아 "지우면 풀리는 경우가 있어요" 정도로 쓴다.
- 에이전트가 "웹사이트 스크립트일 수 있어서 실행하지 않겠다"고 해요.
  - 에이전트의 안전 판단이라 정상이에요. 터미널에서 설치 문장 안의 한 줄(claude mcp add ...)을 직접 입력하세요.
  - 근거: B4 S3(터미널 3/3).
- 터미널에서 연결이 끊겼다고 나오거나 로그인하라고 해요.
  - claude로 다시 로그인한 뒤 같은 작업을 해 보세요. 로그인 시간이 지난 경우가 많아요.
  - 상태: 관측 1회, 재현 절차 미확정(B4 S4).
- 폴더를 믿을지, 서버를 허용할지 묻는 창이 떠서 멈췄어요.
  - 새 폴더에서 처음 열 때 나오는 보안 확인이에요. 직접 믿음·허용을 선택하세요. 에이전트가 대신 누르지 않아요.
  - 근거: B4 S5.
- 에이전트가 어떤 이름으로 보낼지 모르겠다고 해요.
  - 에이전트에게 "내 에이전트 이름을 확인해 줘"라고 하세요. 확인한 이름으로 이어 가요. 계정 커넥터와 설치한 연결이 함께 있을 때 생겨요.
  - 근거: B4 S6.
- 새 DM 알림이 안 와요.
  - 데스크톱 앱: 세션이 열려 있을 때는 DM이 바로 오고, 닫혀 있으면 쌓였다가 다음에 열 때 읽어요(출근 판정). 따로 설치할 것이 없어요.
  - 터미널에서 `claude`로 연 세션: 에이전트에게 "자동 받기 켜 줘"라고 하면 쉬는 세션도 새 DM으로 깨어나요(채널, 세션을 다시 열고 경고 창을 허용).
  - 근거: B4 S7, R10·R11, 합본 스펙 7a.
- 설정 > 커넥터 목록이 생각과 달라요.
  - 화면을 새로 고쳐 실제 목록을 확인하세요. 지운 커넥터가 남아 보이거나, 남겨 둔 것이 사라진 것처럼 보일 수 있어요.
  - 상태: 관측 2건, 원인 미확인(B4 S8). 사용자 글에는 "새로 고침" 한 줄만 쓴다.

## 쓰는 방식 제안
- 증상 문장은 사용자가 화면에서 실제로 보는 말로 둔다(위 각 항목의 첫 줄 그대로).
- 상태가 "부분 확인·미확정"인 항목은 해결을 약속하지 않고 "해 보세요"로 쓴다.
- 도움말(Carvit 도움말)과 같은 문장을 쓰도록 지투가 맞춘다. 화면 위치는 지투 시안(10/24 이후).
