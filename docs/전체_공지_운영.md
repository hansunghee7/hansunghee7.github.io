# 크루 전체에 알릴 게 있을 때: 📢 전체 공지 <!-- id: 98ae -->

여러 명 또는 전원이 알아야 할 것(예: 공통으로 겪을 도구 제약, 전원에게 영향 주는 정책
변경)은 진행상황.md 맨 위(마지막 업데이트 줄 바로 아래)에 **`📢 전체 공지`** 절을
만들어 적으세요. 모든 세션이 "아침 의식"에서 상단부터 읽으므로 페르소나가 누구든 다음
세션이 자연히 봅니다. 특정인 앞으로 보내는 `📥`/`📤`와 달리 그 세션이 언제 다시 열릴지
기다릴 필요가 없습니다.

- **아무거나 올리지 마세요.** 개인 간 인수인계는 그대로 `📥`/`📤` 절을 씁니다. 전체
  공지는 "이걸 모르면 여러 명이 각자 같은 삽질을 반복한다" 수준일 때만.
- 항목마다 **수신 확인이 필요한 이름**을 적고, 확인한 사람은 자기 이름 옆에 체크만
  남기세요. 전원 확인됐거나 상황이 끝났으면 이 절에서 빼고 평범한 이력 절로
  내려보냅니다(오래된 공지가 쌓이면 아무도 안 읽습니다).
- ⚠️ **"동료에게 뭔가 전달하는 것 자체가 안 된다"로 넓혀서 오해하지 마세요.** 클로드가
  진짜 못 하는 건 아티팩트 공유 버튼처럼 사람만 누를 수 있는 웹 UI 조작뿐입니다.
  **진행상황.md에 `📥`/`📤`/`📢` 절을 직접 쓰는 건 어떤 세션이든 할 수 있는 일**입니다.
  다른 페르소나에게 전달할 게 있으면 사장님께 "대신 전달해주세요"라고 하지 말고,
  저장소를 `add_repo`로 부착해 직접 쓰세요. "동료와 상의해라"도 같은 원칙입니다. 지금
  당장 답이 필요 없으면 `📥`를 남기고 다음 세션이 `📤`로 답하게 하고, 즉석 관점이
  필요하면 CLAUDE.md "세션 운영" 절의 서브에이전트 시뮬레이션을 씁니다. "권한이 없다"는 이 중
  어디에도 해당하지 않습니다.
- **사장님 알림 채널은 텔레그램 하나로 통일하고, 카카오톡(MCP 포함)은 사용을 중지합니다**
  (2026-09-17 원칙, 2026-09-19 사장님 확정으로 채널 통일). 텔레그램 알림은 포인터일 뿐이고
  내용을 담는 곳이 아닙니다. 실제 지시·인수인계 내용은 항상 `📥`/`📤`/`📢`로
  진행상황.md에 먼저 남기고, 텔레그램으로는 "여유 있을 때 진행상황.md 확인해주세요"
  정도만 보냅니다(대화가 끊기면 사라지므로 긴 지시문을 메신저에만 쓰지 않습니다).
