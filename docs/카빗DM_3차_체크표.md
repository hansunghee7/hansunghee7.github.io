# 카빗DM 3차 완료 체크표 (담당별 체크, 사장님 지시 2026-10-23)

기준 문서(정본): [카빗DM_3차_슈퍼프로젝트.md](카빗DM_3차_슈퍼프로젝트.md). 목표·범위·항목 1~20·담당 분배·단계별 할 일이 거기 있다.

## 쓰는 법 (담당 모두)

1. **내 줄만 고친다.** 일을 끝내면 내 줄의 `[ ]`를 `[x]`로 바꾸고 줄 끝에 **증거**(PR 번호, 로그 경로, 측정값)를 적는다. 증거 없이 체크하지 않는다(DONE = VERIFIED).
2. **작은 PR로 올린다.** 이 파일만 고치는 작은 PR이다. 다른 사람 줄은 건드리지 않는다. 충돌하면 `origin/main`을 받아 내 줄만 다시 적는다.
3. **노트에게 DM 한 줄:** "P2-a 끝, 한 줄 요약, PR 번호". 노트가 증거를 확인하고 사장님께 현황표로 보인다.
4. 내 공정 카드(`proc.py add <내 이름> "카빗DM3차 P2-a ..."`)에도 같은 줄을 남긴다(세션이 바뀌어도 이어가기 위해).
5. 막히면 체크하지 말고 노트에게 DM: 막힌 곳과 필요한 것.
