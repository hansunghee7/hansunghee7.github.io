# 핏 업무대장 (2026-09-24 신설, 할 일의 상태 정본)

> 핏(로컬·클라우드)이 맡은 할 일을 한 표에 둔다. 방법(프로세스표)은 쇼츠랩 저장소 `GENERATION_PIPELINES.md`가 정본이라 여기로 옮기지 않는다. **상태는 이 표가 정본이다.** 인수인계 산문의 상태는 참고용.
> - 번호: `P<n>` = 사장님이 확정한 우선순위(2026-09-24), `N<n>` = 그 뒤 새로 들어온 요청(우편·지시·사고).
> - 상태(여섯 개만): `대기` / `진행` / `사장님` / `보류` / `확인필요` / `이관`. 끝난 것은 "닫힌 항목"으로 옮긴다(`완료`/`드랍`).
> - **세션 시작 때 할 일 = 상태 `대기`·결정자 `핏`인 행을 위에서부터.** 인수인계에는 이 목록을 다시 쓰지 않는다.
> - 채널명·대본·편 제목 같은 다크 런칭 정보는 쓰지 않는다(공개 저장소). 편은 `ep<번호>`로만 부르고, 세부는 쇼츠랩 경로로 가리킨다.
