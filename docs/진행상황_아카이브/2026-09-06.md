확인돼 방향을 뒤집었습니다: 이제 `/logs/<id>/`가 진짜 주소이고, 옛 긴
주소는 영구 리다이렉트 안전망입니다.

**한 것**:

   없이 멱등적 재실행으로 해결), `sync_all.py`(이전/다음글 링크),

   변경), `add_new_log_cards.py`(카드 href + 중복 판정을 href 텍스트가 아닌

   `generate_short_links.py`(방향 반전: 이제 옛 긴 주소 자리에 스텁을 심음,
   `MIGRATION_CUTOFF_ID=618`로 새 글엔 스텁을 안 만듦), `sync_sitemap_and_drafts.py`,
   `fetch_ga4.py`·`fetch_index_coverage.py`(통계 판정 접두어), `check_exposure_changes.py`

   옛 `logs/<id>/index.html` 스텁 590개(이제 실제 콘텐츠 자리라 충돌) 삭제.
4. 검증: 로컬 빌드 + Playwright로 실제 클릭 테스트(공유 버튼·이전/다음글·
   연관글·홈 카드·log.html 카드가 전부 새 주소, 옛 주소는 canonical+메타
   리프레시로 새 주소를 정확히 가리킴 — 절대경로 리다이렉트라 로컬 샌드박스
