## 숏폼 자동화 파이프라인 v2 — 전 역할 공지 (2026-09-02, 숏감독)

사장님과 숏감독이 숏폼 제작을 **"17단계 중 사람은 4곳"**으로 자동화하는 설계를
확정했습니다. 정본은 `shorts-lab/AUTOMATION_PIPELINE.md`, 읽기용은 스튜디오
[숏폼 자동화 로드맵](/insight-7b3e9f2c/shorts-automation.html)(PR #137).
핵심: **구글 시트가 유일한 정본(공책)**, 드라이브 폴더가 창고, shorts-lab이
도구함, 4090 PC가 낮에만 켜는 일꾼(`/remote-control`), Apps Script 웹앱이
숏감독이 시트에 쓰는 "우편함". 사람 자리는 주제 픽·대본 확정·이미지 확정·
업로드. 각 역할이 볼 것:

- **탐 (AI CTO 튜터)**: 이번 설계의 판단 근거가 학습 자료입니다 — "판단이 단순한
  일은 API로, 창작은 하루 한 번 세션으로", "사람은 돈 나가기 직전과 밖으로
  나가기 직전에", 미니PC 미도입(신호 3개 명시), 딥리서치 API 자동화에도
  검증 단계는 유지. **cxo-db 인박스 미기록 3건** — 이 세션에 cxo-db가 안 붙어
  못 올렸음: ① 시트를 정본으로(뒤집을 신호: 편집자 등 타인 접근) ② 미니PC
  미도입 ③ 사람 관문 위치 원칙. stage: S1.
- **노트 (PO Tech)**: 계단 1(우편함 = Apps Script `doPost` 웹앱, 상태 열
  11단어, 주제관리 탭 한 줄=한 주제)과 계단 3(제미나이 딥리서치 API를
  Apps Script에서 백그라운드 호출 + 5분 타이머 폴링)이 시트 쪽 구현입니다.
  숏감독이 코드를 쓰지만, 사장님 시트 Apps Script 소관을 이미 맡으셨으니
  토큰 잘림 수정과 충돌하지 않게 같은 프로젝트 안에서 파일을 나눌 것.
  Routine(아침 대본 세션)이 생기면 `system-map.html` 갱신 대상.
- **시안 (CXO 튜터 / UX)**: ep07 씬 생성 플랜 페이지를 아티팩트로 게시함
  (https://claude.ai/code/artifact/60280e10-d963-4f9a-8422-7c040b29c238) —
  다크모드는 홈페이지 팔레트(`#080808`/`#f5f3ee`/`#8f8b82`/`#111`)를 그대로
  씀. 계단 2 "거울 페이지"(시트를 비추는 Apps Script 웹앱, 검토·이미지·영상
  3모드)는 스튜디오 밖이지만 UX_GUIDE·STYLE_GUIDE를 따를 예정 — 새 UX
  판단이 필요하면 숏감독이 문의합니다. 사장님이 다크모드 가독성을 지적한
  건 1회 있었고 팔레트 교체로 해소.
- **마야 (CMO 튜터)**: 릴스 2편 성과(택배차 52,000 / 물탱크 12,000, 유튜브
  1,229 / 3,035, 틱톡 500대) — 유통 엔진은 인스타. 파이프라인 0·17단계
  "성과 기록 → 주제 반영"을 넣었고, 발행 3일 후 플랫폼별 조회·시청률·팔로우를
  시트 "성과" 탭에 적는 규칙. 열 줄 쌓이면 반영 규칙을 정함 — 그 규칙 설계는
  CMO 관점이 필요. 콘텐츠 인사이트 페이지(`content-insight.html`)와 데이터
  중복 여부 확인 요망.
