**프롬프트 v10 규칙** (`compile_prompt_v10`, 린트는 기존 `lint()` 그대로 통과해야 한다)
- 한 문단, 현재형, **6~8문장, 110~180낱말** (200 넘기지 않는다).
- 층 순서: ① 주체 동작을 시간 순서로 셋(시작 → 중간 → 끝). 셋은 **한
  동작의 세 국면**이지 세 동작이 아니다(공식 "2~3초에 동작 하나"). "as /
  while / then" 으로 잇고, 두 물체가 같이 움직이는 씬은 **한 문장 안에서
  기구로 묶어 하나의 동작으로 만든다**(로프가 도르래 위를 미끄러지며 한쪽은
  오르고 한쪽은 내린다). 공식 "흔한 실수 3"은 여러 요소를 동시에 두지 말고
  시간을 나누라고 하는데, 반대 방향 운동은 나누면 뜻이 죽으므로 기구로 묶는
  쪽을 택한다(이게 A/B의 검증 대상). ② **끝 상태
  문장** "By the end of the shot ..." 로 끝 스틸의 배치를 말로 한 번 더
  (공식 근거 3번, 키프레임과 문장이 같은 말을 하게). ③ 고정 목록(기존).
  ④ 카메라 고정(기존 문장 + "framing identical from the first frame to the
  last"). ⑤ 기존 제약 문장.
- 숫자·비율·각도 금지("a quarter of the frame" 도 안 됨). 대신 "just under
  the sheave", "near the bottom of its lane" 처럼 장면 안 기준점으로.
- 글자·라벨·화살표 언급 금지(기존). 스타일 낱말 금지(기존). 오디오 문장 없음
  (0.9.8은 무음 모델).
- IR 추가 필드: `"beats": [시작, 중간, 끝]`(각 물체 동작 문장 소재),
  `"link": "..."`(기구 문장, 선택), `"end_state": "..."`.

   22: {"objects": [{"name": "the cab mass", "verb": "rises up the left lane", "dir": "상", "power": "중"},
                    {"name": "the counterweight mass", "verb": "sinks down the right lane by the same distance", "dir": "하", "power": "중"}],
        "hold": ["sheave", "cutaway walls"], "camera": "정지"},
   ```
   `--scenes 22 --dry`로 `lint=[]` 확인 →
   `python v4_champion_scenes.py --scenes 22 --tag _v9 --denoise 0.92`.

   "OVERBALANCE"·"1200 KG"·"50 PCT" 그대로. (b) 3단계 스트립에서 라벨 글자가
   뭉개지지 않음. (0.92는 주인공 하나 씬용이라 라벨이 바뀔 위험이 있어 1회만.)
A'. 로우폴리 판(사장님 팁 실측. A와 별개 폴더 `--tag _v9lp`). 씬22만 스타일을
   `lowpoly_soft`로 바꿔 시작·끝을 새로 뽑는다. `_slot_with_override()`의
   STYLE_LOCK 블록 다음에 씬별 예외를 한 줄 넣는다:
   ```
   STYLE_OVERRIDE = {22: "lowpoly_soft"}   # v9.2: 사장님 팁 A/B, 씬22만
   ...
   if sid in STYLE_OVERRIDE:
       slot["style"] = STYLE_OVERRIDE[sid]
       slot["subject"] = ARCHVIZ_SUBJECT[sid]      # 문장은 재질 중립이라 그대로
       slot["instead"] = ARCHVIZ_INSTEAD.get(sid, slot.get("instead", ""))

   기피하므로 조건이 있다: 끝 프레임은 `fit_clip`이 버리는 마지막 0.6초 안에
