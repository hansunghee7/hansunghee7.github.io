# R13 한 폴더 여러 에이전트: 신원 설계 (확정안, 2026-10-22)

한 줄 결론: 같은 폴더에서 에이전트마다 **서버 이름이 다른 연결**을 등록하고(후보 D), 각 세션은 자기 이름의 서버만 부르며, 세션 시작 때 연결 확인 줄의 이름을 세션 역할과 대조해 다르면 멈춘다. 알림기는 0.1.3의 신원 확인(R13ⓐ)이 이미 막는다.

기존 원문 X → 새 근거 Y
- X(노트 초안 10/22 16:40): 기본은 A(에이전트마다 자기 폴더에서 설치), B(환경변수 선택)는 실측 뒤 보강.
- Y(탐 우편 10/22 16:45, 실측): 탐·노트·지투·마야·핏 세션이 전부 같은 폴더(cwd)에서 열려서 A는 워크트리를 전 세션에 강제해야 해 비현실적이다. B는 앱이 세션마다 환경변수를 바꾸지 못하고 `.mcp.json`과 local 범위에 같은 이름이 두 주소로 정의돼 충돌 경고가 떠서 앱 세션에서 에이전트별 선택이 안 된다. D는 이미 `carvit`와 `carvit-jitu`가 한 폴더에서 같은 주소로 공존하며 둘 다 연결 상태로 실측됐다.

## 문제
- `claude mcp add --scope local`은 폴더 기준이라, 같은 이름의 연결은 폴더에 하나이고 신원도 하나다. 같은 폴더에서 여러 에이전트가 세션을 열면 모두 같은 이름으로 나온다(탐 10/22 11:20 실측).
- 알림기도 같은 구조였다(10/22 사고). 알림기는 0.1.3(R13ⓐ)에서 시작 때 코드의 주인을 확인하고 다르면 멈춘다.

## 후보와 판정
- A 에이전트마다 자기 폴더: 사용 방식에 맞지 않아 기본에서 제외. 다른 컴퓨터를 쓰는 에이전트에는 그대로 쓸 수 있다.
- B 환경변수로 선택: 앱 세션에서 안 된다. 제외.
- C 서버에 호출자가 에이전트를 고르는 인자: 사장님 10/18 "보낸 이는 연결이 정한다"(시험 `test_dm_requirements` 2번)와 충돌. 제외(탐·지투 동의).
- **D 에이전트별 서버 이름: 채택.** 같은 폴더에 `carvit-<에이전트 이름>`처럼 이름이 다른 서버를 각자 등록한다. 서버 이름 자체가 신원이다. 도구 이름도 서버 이름을 따라가므로(`mcp__carvit-jitu__dm_send`) 호출하는 쪽이 신원을 섞어 쓰지 않는다. 서버 코드 변경이 없다.

## 구성
1. **연결 이름**: 에이전트 추가 설치 문장이 서버 이름에 에이전트 이름을 넣는다(담당 지투, 문장). 이미 등록된 `carvit`(기본)와 공존한다.
2. **세션이 쓸 서버**: 세션카드가 "내 서버 이름"을 알려 준다(우리 팀은 이미 세션카드가 있다). 사용자 팀에는 설치 문장이 마지막에 "이 세션에서 Carvit은 carvit-<이름> 서버만 쓴다"를 한 줄로 알린다.
3. **안전장치(강제)**: 세션 시작 훅이 연결 확인 줄의 "내 에이전트 이름"과 세션카드 이름을 대조해 다르면 멈추고 사용자에게 알린다. 문서가 아니라 훅이 강제한다(CLAUDE#4e7b). 설치 문장에도 같은 한 줄을 넣는다(담당 지투, 훅은 탐).
4. **알림기**: 0.1.3의 `agent_name` 설정과 시작 때 신원 확인이 이미 막는다. 알림기 설정 폴더는 에이전트별(`.carvit/<이름>/`, 지투 ⓑ)로 둔다.

## 담당과 순서
- 탐: D의 두 이름 동시 사용 실측(`carvit-tam` 추가 시험), 세션 시작 훅(연결 확인 줄 대 세션카드 대조).
- 지투: 에이전트 추가 문장에 서버 이름과 확인 한 줄, ⓑ 폴더 이름. 이 문서가 근거.
- 노트: 합본 스펙 R13 갱신, 알림기 쪽(0.1.3 완료), 실측 결과 기록.
- 주의(탐 지적): 이 폴더의 `.mcp.json`에 옛 이름 환경변수가 남아 있다. 새 코드는 `CARVIT_` 이름만 쓴다(탐 영역 옛 이름 소거 프로젝트).

## 닫는 기준(실측)
- 같은 저장소 폴더에서 서로 다른 이름의 서버 두 개를 동시에 쓰고, 각 서버의 연결 확인 줄이 서로 다른 에이전트 이름을 보여 준다(탐 실측).
- 세션카드와 다른 이름의 서버를 부르면 훅이 멈춤을 낸다(탐 실측).
- 지투의 에이전트 추가 문장으로 새로 추가한 에이전트가 `carvit-<이름>` 서버로 연결되고 DM을 주고받는다(지투·노트 실측).
