# N112 AB 시험 1회차: 비티 대 덱스, 같은 질문(2026-10-03)

> 사장님 지시: 아침 백로그 피드백을 비티·덱스에게 같은 질문으로 던져 AB 시험. 10/10 판정 자료.

## 조건

- 같은 카드: 탐 업무대장 전문 + 세 문서(탐 백로그 피드백, 자기 역할노트, 자기 업무대장)를 한 번 호출로 쓰기.
- 차이: 덱스는 기존 역할노트를 입력으로 받았고 비티는 역할노트가 없어 새로 썼다(비대칭, 다음 회차에 맞출 것).
- 비용: 비티 58초(구PC agy), 덱스 37초·15,226토큰(codex exec, 읽기 전용). 둘 다 한도 신호 없음.
- 실패 3건(한도 소모 없음): 카드의 한글 첫 글자를 바이트로 잘라 비티가 거절, 덱스는 긴 카드를 인자로 넘겨 명령줄 길이 초과, 작업 폴더가 git 저장소가 아니라 거절. `ask_dex.sh`를 표준입력 방식으로 고침.

## 탐 판정

### 비티: 6건 중 채택 3, 반려 3

- 채택: N108 개인 계정은 게시 후 6·24·48시간 스냅샷만(덱스 추가안과 합침). N31 10/10 판정 지표 자동 집계. N31 로그인 체계 변경 시 키 복원 검증.
- 반려: N112 한도 가드 충돌(전제가 낡음, 10/2에 가드 폐지. 대신 대장 N71의 낡은 문장을 찾아 줌 → 고침). 구PC 하트비트 추가(이미 있음, 상태판 "구PC 감시"). B51 미루기(대장에 "10월 안" 기한).

### 덱스: 6건 중 채택 1, 보류 1, 반려 4

- 채택: N108 게시물별 수집 성공·누락 표시 기준.
- 보류: N103 체크 항목 분리(덱스 스스로 확신 가장 낮다고 표시).
- 반려: N112 행 분리(이미 다음 ①②③으로 나뉨), N110 같은 모델·블라인드(이미 설계), 한도 리셋 기준(N112 ②와 중복), B50 미루기(사장님 결정 대기라 탐 자원을 이미 안 씀).

## 색깔 차이(관찰)

- 비티: 대담하고 새 정보가 많다. 숫자 효과를 [추정]으로 크게 붙이고, 대장 문장을 사실 확인 없이 믿어 낡은 전제에서 틀린다. 역할노트에 사장님 결정(아침 피드백, 일괄 작성)을 스스로 넣었다.
- 덱스: 보수적이고 사실 위주다. 대장 내용을 다시 말하는 제안이 많아 새 정보가 적고, 역할노트는 기존 노트를 거의 그대로 두어 사장님 결정(정기 피드백)을 반영하지 못했다(탐이 보정). 확신 낮은 항목을 정직하게 짚었다.
- 서로 다른 데서 같은 결론: 둘 다 N108 수집 기준을 짚었다. B51은 비티가 미루자, 덱스는 못 미룬다고 했고 대장 근거는 덱스 쪽.
