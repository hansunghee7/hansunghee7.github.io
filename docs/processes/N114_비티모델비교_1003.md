# N114 비티 제미나이 대 비티 Sonnet 비교(2026-10-03)

> 사장님 지시: 제미나이 한도 소진 동안 비티를 Sonnet(`agy --model claude-sonnet-4-6`)으로 계속 쓸 수 있는지, 차이가 있는지. 같은 카드 3장을 Sonnet에 다시 시키고 덱스(다른 회사 모델)가 사실 확인.

## 결과

### 1. 시험 문제 출제(N110)
- 둘 다 12문항+역효과 2문항을 형식대로. Sonnet은 채점표를 표로 짜고 유형 분포 요약을 붙여 더 정돈됨(203초).
- 둘 다 병합 문항에서 fail-open 형태를 정답으로 씀. 카드 자료가 고치기 전 기억 파일이었기 때문이라 모델 차이 아님.

### 2. 탐 백로그 피드백(N112), 덱스 검증
- 제미나이: 6건 중 전제 맞음 0, 낡은 대장 문장을 믿은 전제 틀림 1, 나머지 일부 확인 불가·중복.
- Sonnet: 6건 중 **전제 맞음·새 정보 4**, 전제 틀림(이미 있는 린트 계획) 1, 일부 확인 불가 1. 대장 문장을 정확히 인용해 근거가 구체적(82초).
- 주의: Sonnet은 탐과 같은 클로드 계열이라, 탐이 판정하면 편향 가능. 그래서 판정은 덱스 결과만 썼다.

### 3. 아파트 주제 추천(N113), 덱스 검증
- 제미나이: 출처 URL 12개 모두 열림, 그러나 최근 90일 사건 0건(2024년 위주), 덱스 확인 12개 중 8개 틀림.
- Sonnet: **2026년 7월~10월 1일의 아주 최근 사건**을 찾음, 주제 다양. 그러나 **원문 URL 0개**(검색 요약만, 웹페이지 읽기를 못 함). 덱스 확인 12개 중 확인됨 1·틀림 7·확인 불가 4. 틀림 7개 대부분은 사건 자체는 실재하고 세부(날짜·금액·원인)가 틀린 경우(예: 원주 아파트 화재 실재, "빈집·감지기 경보 없음"은 근거 없음).

## 결론
- **Sonnet으로 비티 업무를 계속할 수 있다.** 백로그 검토·출제처럼 출처가 필요 없는 일은 Sonnet이 제미나이와 같거나 낫다.
- 출처가 중요한 주제 추천은 둘 다 단독으로 못 쓴다. 제미나이는 오래된 자료에 출처가 있고, Sonnet은 최신이지만 출처가 없다. 어느 쪽이든 덱스 확인이 필요하다.
- 잃는 것: Sonnet은 탐과 같은 회사 모델이라 "다른 회사 모델의 독립 시각"이 약해진다. 독립 검증이 핵심인 일(보안 검토 등)은 제미나이가 풀린 뒤 제미나이로.
- 비용: Sonnet 3회 호출, 한도 오류 없음(한도 아직 모름, 대장 `quota.py`의 `비티-sonnet` 풀로 세는 중).
