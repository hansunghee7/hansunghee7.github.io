# 비티 상시 검토 루프 (2026-10-01 신설, 사장님 지시, 업무대장 N71)

> 비티(Antigravity·Gemini)가 가진 무료 한도 안에서 우리의 발전을 최대한 돕는 정기 루프. 비티 본인 제안(역할 회신 [processes/비티_역할회신_1001.md](비티_역할회신_1001.md))을 따른다: 상시 감시가 아니라 "필요할 때 소환해 한 번 깊이 검토하고 퇴장".

## 구조 (한 줄 요약: 큐 → 비티 → 탐 실측 → 기록)
- **큐**: `C:\work\_ops\bt\queue.md`(상태 정본). 항목은 `### B<n> [상태] 제목` + `대상`(비밀값·고객정보·가격·전략 없는 파일) + `질문`(반증 가능한 한 줄). 상태는 `대기`/`비티답변`/`채택`/`반려`/`보류`.
- **루프**: 작업 스케줄러 `simplifier-bt-loop`(월·목 10:00)가 `scripts/ops/bt_loop.py`를 숨김 실행. `대기` 첫 항목을 구PC `agy -p`로 보내고 답을 `replies/`에 저장, 큐를 `비티답변`으로 바꾸고 탐에게 우편 "비티 답 도착".
- **한도 가드**: 7일 최대 2회, 호출 간격 36시간 이상, 실패(한도·빈 답)면 24시간 쉼. 가드로 건너뛰어도 `last_run`은 갱신(감시는 `cron:bt-loop`, 4일).
- **판정은 탐이 한다**: 무료 엔진은 판정하지 않는다(CLAUDE.md). 탐 세션이 시작되면 `비티답변` 항목을 코드·실측으로 대조해 `채택`/`반려`를 큐에 적고, 의미 있는 건 `docs/processes/비티_검토_기록/`에 원문+판정을 저장한다.
- **채택률**은 비티가 제안한 평가 기준 ①(실측 후 채택된 비율). 첫 기록: B1 6/7.

## 큐에 넣을 만한 것 (탐이 채운다, 한 번에 하나)
- 되돌리기 어려운 보안·구조 설계 문서(소셜 로그인, Carvit Pass 금고, 권한·키 처리).
- 탐이 막힌 기술 난제의 "다른 모델 시각" 교차 검증.
- 넣지 않는 것: 일상 구현, 상시 감시, 비즈니스·가격·전략, 고객 정보·비밀값.

- **한도 조건**: [비티_한도_조건.md](비티_한도_조건.md) (비티 답은 추측 포함, 실측 0건 오류).
- **채택률 기록**: B1 6/7, B2 5/6, 한도 질문에서 비티 오류 1건(토큰 기록 위치).

## 수동으로 지금 바로 보내고 싶을 때
`python scripts/ops/bt_loop.py --force`(한도 가드 무시) 또는 질문 파일 한 장은 `bash scripts/ops/ask_bt.sh <질문.md> [출력.md]`.

## 실패했을 때
- 큐 상태는 그대로 두고 24시간 쉬었다 다시 시도한다. 계속 실패하면 구PC에서 `~/.local/bin/agy -p "Reply with the single word OK"`로 응답 여부부터 본다(한도·로그인).
- 비티의 답이 이상하면 큐에서 `보류`로 돌리고 질문을 더 좁혀 새 항목을 만든다.
