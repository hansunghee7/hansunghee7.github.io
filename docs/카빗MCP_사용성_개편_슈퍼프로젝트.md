# 카빗 MCP 사용성 개편 슈퍼프로젝트 (정본, 사장님 지시 2026-10-22, 담당 지투)

일하는 방식: 슈퍼프로젝트(정본 [오케스트레이터_일하는_방식.md](오케스트레이터_일하는_방식.md)의 '슈퍼버닝과 슈퍼프로젝트' 절). 화면은 HTML 시안 먼저(사장님 컨펌), 구현은 서브에이전트 PR, 병합은 CI 통과 뒤에만.

## 목표
카빗 사이트의 MCP 메뉴를 **비로그인 사용자와 로그인 사용자 각각의 요구에 맞게** 다시 짠다. 사용자가 처음 오든 다시 오든, 다음에 할 일 하나를 헤매지 않고 찾는 것이 목표다(UX 123원칙: 화면마다 사람의 1번 행동과 에이전트의 1번 행동).

사장님 요구 5가지(2026-10-22 원문 요지):
1. 비로그인 사용자가 카빗에서 MCP 메뉴를 고르면 **안내 화면이 홈**이다.
2. 로그인 사용자가 MCP 메뉴를 고르면 **대시보드가 홈**이다.
3. 대시보드는 이전에 있던 **UX MCP 지표 그래프를 다시 살리고**, 그 밖의 **새 MCP 지표도 그래프로** 보여 준다(이전 기록에서 찾는다).
4. **에이전트 추가는 세팅으로 옮기되**, 지금처럼 숨기지 않고 UX 1·2·3원칙에 맞게 **직관적으로 찾게** 한다.
5. **Agents 메뉴는 새 창**으로 띄워 슬랙 화면처럼 따로 볼 수 있게 한다. 그 링크로 들어오면 에이전트 소통을 볼 수 있다.

## 선행 조건
- 이 프로젝트는 **'UX 가이드 개선(탐 VOC 해결)' 프로젝트를 먼저 끝낸 뒤** 시작한다(사장님 2026-10-22). 선행 프로젝트의 완료 조건은 탐 재검증 9/9다(현재 지투 집계 7/9).
- 그때까지는 조사(읽기 전용)와 설계 초안까지만 한다. 코드·화면 변경은 하지 않는다.

## 범위
- 대상: mcp.carvit.ai의 MCP 진입 화면(비로그인 안내), 로그인 후 대시보드(Home), 세팅, 에이전트 추가, Agents 화면.
- 대상 아님: Create·Pass·Team·Tech Report 메뉴, carvit.ai 홈 랜딩, 설치 문장(이미 별도 진행).

## 하지 않을 것
- 사장님 컨펌 없는 화면 변경, 시안 없는 구현.
- 로그인 없이 에이전트 대화 내용이 새어 나가는 구조(별창 링크 권한은 결정 1이 정해질 때까지 설계만).
- 지표를 정하는 것을 에이전트가 단독 결정(목록은 사장님이 확정).
- 홈 개편(carvit.ai) 범위 확대.

## 단계 관문 (모든 구현 단계 공통)
- 병합 전: CI 통과, 비티·덱스 PR 리뷰, 변경 전후 화면 캡처(360·1280).
- 병합 후: 배포, 라이브 호출·화면 실측, 가이드 점검(`check_diff_violations` html_file), 되돌리기 방법 확인.
- 실패하면 해당 PR만 되돌린다(DB 변경은 되돌리기 스크립트를 먼저 준비한다).

## 롤백
- 코드: 단계별 PR 되돌리기. 라우팅(P4)은 기존 진입을 한 줄로 복원할 수 있게 둔다.
- DB: 새 칸·표가 필요하면 되돌리기 SQL을 같은 PR에 넣고 사장님 세션 승인 뒤 운영에 적용한다.

## 사장님이 정할 결정 목록
1. **별창(Agents) 링크의 접근 권한**: 로그인한 같은 회사 사용자만 볼 수 있게 할지, 공유 링크로 로그인 없이 볼 수 있게 할지. 에이전트 대화에는 비밀이 섞일 수 있어 로그인 필요를 추천(P7 전에 확정).
2. **지표 목록**: 복원할 UX MCP 지표와 새로 보일 MCP 지표를 후보에서 고른다(P2에서 후보 제시).
3. **에이전트 추가의 세팅 안 위치**: P3 시안에서 2안을 보여 주고 고른다.
4. **착수 시점**: 선행 프로젝트 완료 직후로 본다. 다른 우선순위가 있으면 알려 준다.
