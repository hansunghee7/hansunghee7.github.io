# 자동 로드 문서의 다이어트 기준 <!-- id: a18e -->

CLAUDE.md와 역할 노트는 매 세션 자동 로드되므로 그 자체가 토큰 비용입니다. 한 줄마다
"**이 줄을 지우면 클로드가 실수하는가?**"를 물어서 아니면 지우고, 상황별 절차는
`.claude/skills/`로 옮깁니다(필요할 때만 로드됨). 목표: CLAUDE.md 200줄 이하, 역할 노트 80줄 이하.

**"감"이 아니라 실측으로 판단하세요.** 이 문서와 `simplifier-way.md`도 UX_GUIDE.md와 같은 방식으로
절별 id가 있습니다(`<!-- id: xxxx -->`). 어떤 원칙을 근거로 고쳤으면 커밋 메시지에 `CLAUDE#<id>` /
`WAY#<id>`(UX_GUIDE.md 절이면 `UX_GUIDE#<id>`)를 남기세요. `saegim.py report --doc CLAUDE.md
--tag CLAUDE`로 쓰이는 절과 휴면 절을 볼 수 있습니다.
