# 자동 로드 문서의 다이어트 기준 <!-- id: a18e -->

CLAUDE.md와 역할 노트는 매 세션 자동 로드되므로 그 자체가 토큰 비용입니다. 한 줄마다
"**이 줄을 지우면 클로드가 실수하는가?**"를 물어서 아니면 지우고, 상황별 절차는
`.claude/skills/`로 옮깁니다(필요할 때만 로드됨). 목표: CLAUDE.md 200줄 이하, 역할 노트 80줄 이하.

**"감"이 아니라 실측으로 판단하세요.** 이 문서와 `simplifier-way.md`도 UX_GUIDE.md와 같은 방식으로
절별 id가 있습니다(`<!-- id: xxxx -->`). 어떤 원칙을 근거로 고쳤으면 커밋 메시지에 `CLAUDE#<id>` /
`WAY#<id>`(UX_GUIDE.md 절이면 `UX_GUIDE#<id>`)를 남기세요. `saegim.py report --doc CLAUDE.md
--tag CLAUDE`로 쓰이는 절과 휴면 절을 볼 수 있습니다.

**격주 폴리싱 때 반드시 볼 것(2026-09-23 추가, 재발방지)**: 진행상황.md 이력 절에
`[본문 반영 대기]` 표시가 남은 공지가 있는지 훑고, 있으면 이번 폴리싱에서 CLAUDE.md·
역할 노트·rules 중 해당 문구를 고치고 표시를 뗍니다. 근거: 공지는 확정됐는데 본문
(진입점 표 등)에 반영을 안 해서 옛 문구와 공존하다 실제 업무에서 혼선을 준 사고
(2026-09-23, 새김 MCP 실사용 필수 공지 vs CLAUDE.md의 "로컬 파일 지름길 허용" 잔존
문구). 자동 대조 스크립트는 만들지 않습니다 — 공지 빈도가 주 1~3건 수준인 지금
규모에서는 격주 폴리싱 때 사람이 훑는 것으로 충분하고, 자동화는 과잉입니다. **뒤집을
신호**: 이 방식으로도 반영 누락이 2회 이상 반복되면 그때 스크립트(전체공지 제목의
`[본문 반영 대기]` 태그 잔존 기간을 감시 대장에 등록하는 정도)를 추가합니다.
