# 마야 글별 좋아요 화면 수집 절차 (2026-10-06 실측)

> 목적: 마야 KPI(게시물별 좋아요·조회수, [마야_KPI.md](마야_KPI.md))의 수집 중 자동화가 안 되는 4곳을 하루 1회 크롬으로 읽는다. 인스타그램은 탐의 Composio 자동 수집(`C:/work/_ops/n152/maya_metrics.json`)이 대신한다. 프로세스표 [8-2 1단계](마야_프로세스표.md)의 수동 대체다. 자동화가 생기면 이 문서를 접는다.
> 전제: 사장님 크롬(프로필 직장)에 Claude in Chrome이 연결돼 있고 링크드인·리멤버·로켓펀치·페이스북에 로그인돼 있다. 로그인은 사장님 몫이다.
> 저장: 읽은 숫자는 `assets/data/post_reactions.json`에 날짜별로 쌓는다(같은 날 다시 읽으면 덮어쓴다).

## 1. 링크드인 (개인 한성희) — 좋아요·댓글·퍼감·노출

1. `https://www.linkedin.com/in/me/recent-activity/all/` 을 연다. 4초 기다린다.
2. 아래 코드를 `javascript_tool`로 실행한다(끝까지 스크롤한 뒤 글 카드의 끝 문구를 읽는다).

```js
for(let i=0;i<5;i++){window.scrollTo(0,document.body.scrollHeight);await new Promise(r=>setTimeout(r,2200));}
[...document.querySelectorAll('[role="article"], .feed-shared-update-v2')].slice(0,16).map(e=>{const t=e.innerText.replace(/\s+/g,' ');const i=t.search(/(수정됨 • )?\d+(일|주|개월) 전/);return t.slice(i,i+85)+' ... '+t.slice(-60)})
```

3. 각 줄 끝의 `<좋아요> 회원님 외 N명 댓글 n 퍼감 n 노출 n`에서 좋아요는 "회원님 외 N명"의 N+1이다(예: "회원님 외 28명"이면 29). 영상은 "재생 n"이 따로 있다.

## 2. 리멤버 커넥트 — 좋아요·댓글

1. `https://connect.rememberapp.co.kr/profile/1582110/posts` 를 연다. 3초 기다린다.
2. 아래 코드를 실행한다.

```js
window.scrollTo(0,0);[...document.querySelectorAll('*')].filter(e=>e.children.length==0&&/^(좋아요|댓글)\s*\d+$/.test((e.innerText||'').trim())).slice(0,40).map(e=>e.innerText.trim()+' | '+(e.closest('[class*=post],[class*=Post],li,article')?.innerText||'').replace(/\s+/g,' ').slice(0,50))
```

3. 줄마다 "좋아요 n"과 게시 날짜·첫 문장이 나온다. 숫자가 붙지 않은 글은 0이다.

## 3. 로켓펀치 — 반응·댓글

1. `https://www.rocketpunch.com/@simplfier/post` 를 열고 **8초 기다린다**(처음에는 회색 막대로 로딩 중이다).
2. 아래 코드를 실행한다.

```js
const t=document.body.innerText.replace(/\s+/g,' ');t.slice(Math.max(0,t.indexOf('게시물 저장됨'))).slice(0,3500)
```

3. 글마다 "… 더보기 [숫자들] 재게시 공유"에서 숫자가 없으면 0, 있으면 앞 숫자가 반응이다(숫자 둘이면 반응, 댓글 순으로 추정, 불확실하면 비워 둔다).

## 4. 페이스북 개인 프로필 — 부분만 읽힌다(한계)

- `https://www.facebook.com/simplifier.seoul/` 목록은 가상 스크롤이라 맨 위 글 1~2개만 읽힌다. 읽은 글의 "좋아요 n"만 기록하고, 읽지 못한 글은 `null`로 둔다(0으로 쓰지 않는다). 전체 읽기 방법은 N14에서 계속 찾는다(Composio는 개인 프로필 불가).

## 5. 저장 형식

```json
{"date":"2026-10-06","channel":"linkedin","post":"631","title":"토큰을 아끼려다 기술이 늘었다","likes":29,"comments":2,"impressions":3760}
```

- 한 줄 = 한 글 × 한 채널 × 하루. 읽지 못한 값은 `null`.
- 글 번호는 제목으로 홈페이지 글(`assets/data/posts.json`)과 맞춘다. 맞는 글이 없으면(예: Carvit 로고 글) `post`를 `null`로 둔다.
