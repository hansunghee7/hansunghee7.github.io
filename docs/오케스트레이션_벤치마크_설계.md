# 에이전트 오케스트레이션 벤치마크 설계 (N90)

> 상태: 설계안 + 러너 1회 실행 검증(2026-09-30). Claude 계획자 모드는 아직 실행하지 않았다(API 키 없음, 호출 비용은 사장님 확정 뒤).

## 무엇을 재는가

단일 에이전트의 가드레일(N88)을 넘어, 두 에이전트가 이어서 일하는 사슬을 잰다. 클라우드 계획자(Claude Sonnet 5.5)가 린트 결과를 보고 위임장을 만들고, 로컬 작업자(Ollama의 qwen2.5-coder:14b, 기존 `actor_critic_loop.py`)가 고치고, 오케스트레이터가 결과를 다시 확인한다.

## 인터페이스 파이프라인

1. **위임장(계획자 → 작업자)**: JSON Schema로 고정한다. 필드는 `task_id`, `target`, `rule_family`, `flagged_lines`, `instruction`, 그리고 `additionalProperties: false`.
   - Claude 쪽은 도구 정의에 `strict: true`를 걸어 스키마에 맞는 인자만 나오게 한다(공식 문서로 확인한 기능).
   - 이 모델은 도구 강제 호출(`tool_choice` any/tool)이 400이라 `auto`로 부르고 프롬프트에서 도구를 지목한다.
2. **관문 1(위임 직후)**: 스키마 검사에 더해 의미 검사를 한다. `flagged_lines`가 린트가 실제 지적한 줄의 부분집합이어야 한다. 위반하면 사유를 계획자에게 돌려 한 번 재시도시키고, 그 횟수를 "관문1 개입"으로 센다.
3. **작업자 실행**: 기존 루프가 그대로 돈다. 루프 안의 가드(호출 줄 삭제 금지 등)가 거절한 횟수는 "가드 거절"로 센다.
4. **관문 2(결과 수신)**: 결과 봉투(`status`, `iterations`, `guard_rejects`)를 스키마로 검사하고, 오케스트레이터가 ruff를 직접 다시 돌려 작업자의 PASS 주장이 사실인지 대조한다. 어긋나면 "관문2 개입"이다.

**용어 정정**: 지시서의 `between_tools`는 "도구 간 실행 검증"이 아니다. API의 `thinking: {type: "between_tools"}`는 Sonnet 5.5에서 추론을 끄는 방법이다(effort high 이하에서만 허용, 다른 필드와 함께 못 씀). 러너는 계획자를 값싸게 쓰려고 이것을 켠다. "도구 사이의 검증"은 위 관문 1·2가 우리 쪽 코드로 하는 일이다.

## 측정 항목

- 종합 완수율: 사슬이 끝까지 가서 오케스트레이터의 ruff 재검사까지 통과한 비율.
- 관문 개입 수: 관문1, 관문2 각각과 작업자 가드 거절 수(어느 층이 실수를 잡았는지).
- 토큰: 계획자(입력·출력, API 사용량)와 작업자(Ollama의 입력·출력 토큰)를 따로 센다. 달러 환산은 모델 단가표가 바뀌므로 분석 때 한다.
- 지연: 계획 구간과 작업자 구간을 초 단위로 따로 잰다.

## 러너

`scripts/ops/orchestrate_bench.py`가 1회를 실행하고 JSON 지표 한 줄을 출력한다.

```
ACL_BACKEND=ollama:qwen2.5-coder:14b python scripts/ops/orchestrate_bench.py --target bench/hard_mixed.py [--planner mock|claude] [--inject-fault]
```

- `mock`(기본): 무료·결정적 계획자. 파이프라인 검증용이다.
- `claude`: `ANTHROPIC_API_KEY`가 필요하고 호출마다 비용이 든다.
- `--inject-fault`: 첫 위임장에 지적되지 않은 줄을 섞어 관문 1이 잡는지 본다.

## 1회 실행 결과 (mock 계획자 + 로컬 14B, 2026-09-30)

- 정상 실행: 완수, 작업자 2회차 통과(가드 거절 1), 작업자 토큰 2137 입력 / 106 출력, 지연 2.5초.
- 결함 주입 실행: 관문 1이 1회 개입해 재시도 후 완수, 나머지는 같다.

한계: 계획자가 mock이라 Claude의 위임장 품질과 API 비용·지연은 아직 측정한 것이 없다. 표본은 각 1회다.
