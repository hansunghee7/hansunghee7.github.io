## 세 영역

- **1 가입**: 사용자가 carvit.ai에 로그인해 에이전트 신원(이름)을 등록하고 설치 문장을 받는다.
- **2 설치**: 사용자가 직접 카빗 MCP(와 플러그인)를 설치한다(사장님 10/20: MCP와 플러그인은 사람이 설치).
- **3 통신**: 설치한 에이전트가 Carvit Help와 소통하고, 그 소통 결과가 우리에게 전달되면 된다. 지투라는 신원은 필요 없다(사장님 10/20, 이름은 "Carvit Help" 채널). 송신은 실측 완료, 수신은 환경별로 나뉜다.

- 1단계 카빗 MCP 사용자 설치: 사용자가 직접 설치(MCP와 플러그인을 하나의 묶음으로).
- 2단계 에이전트 호출 프롬프팅: 페르소나 호출 → 필수문서 세팅 → Carvit Help와 소통.

## 정해진 결정

- 설치 배포 순서(사장님 2026-10-20, 노트#104): uvx 한 줄(PyPI 정본 패키지 하나) → 플러그인(얇은 껍데기) → zip 폴백. 섞어서 같이 설치하지 않는다.
- 수신 방식(사장님 10/20, 지투-카빗DM#1과 정정): 터미널은 채널(실측 완료). **Monitor 도구와 플러그인 monitors는 후보에서 제외**(사장님 10/20: 에이전트가 쓸지 자율이라 잊고 30분 만료가 있어, 세션 실행 때 기본으로 실행되는 방식만 후보). 훅(asyncRewake)은 아래 훅 타임아웃 실측으로 "기본값이면 10분 넘게 쉰 세션에서 죽는다"가 확인됐고, 사장님이 훅을 후보에서 제외했다. [실측: 아래 "실측: 훅 타임아웃" 절, 3600초 지정 시 7초 기상]
- 에이전트 간 연락은 카빗DM만 쓴다. 세션메시지는 장애 때 사장님 승인으로만(PR 2490).
- 평가 기준(노트#101): 자동 모드 통과 여부, 사람이 불안하지 않은지, 설치 단계 수. 셋 다 잰다.
- 실험 순서 기본(노트#132): 내부 서브에이전트 1차 → 내부 에이전트 2차 → 실측되면 외부 에이전트 3차.
- 이어가기: 새 세션은 대화 기억이 없다. 사장님께 "새 세션에서 이어서 해줘만 입력하세요"라고 안내하지 않는다. 역할·직전 작업·다음 단계는 공정 카드에 남기고 시작 훅이 식별한다.

## 실측 완료 (2026-10-20 기준, 10/21 갱신)

가입
- 에이전트 신원 등록: 사장님이 대시보드에서 등록하고, 재시작한 세션의 `agents`에서 `me`가 해당 에이전트로 나온다.
- 설치 문장 발급: 대시보드 Copy message와 `autoreceive_setup`이 문장과 해시를 발급한다.

설치
- MCP 연결: `claude mcp add` 성공. 처음엔 자동 모드가 거부했고 같은 문장을 다시 붙이자 통과했다. 원인은 맥락 추정이다(노트#144·#145).
- 재시작 뒤 신원 확인, zip 내려받기·해시 대조·압축 해제: 확인됨.
- uvx 한 줄: 거절 0·0, 승인 0, 오류 0, 사람 1단계·에이전트 1단계. 한계: 헤드리스·로컬호스트·2회, 깨우기는 시험하지 않음.
- 플러그인: 거절 0, 오류 1(턴 한도), 훅이 세션 시작·종료 때 실제 실행됨. 에이전트 약 6단계, 불안 요소 2개(전역 설치, 상시 대기 훅). 같은 한계.
- 서버가 푸시하는 설치 문장: 거절 0(헤드리스·로컬호스트·2회, 10/20 밤).

통신
- DM 송신: 확인됨.
- 앱에서 감시가 없을 때: 상대 답이 도착해도 세션이 알아채지 못했다(1회).
- 앱에서 도우미(Monitor)를 켠 뒤: 상대 DM이 약 7초 만에 신호로 도착했다. 한계는 감시가 최대 30분 뒤 만료되어 다시 걸어야 한다는 점이다.
- 서버 푸시로 쉬는 세션 깨우기: 헤드리스에서 4번 중 4번 실패.
- `dm_read` 분류기 거절: 이전 헤드리스 2/2 거절은 재현되지 않았다. 도구 이름 2종 × 본문 성격 2종, 알림 문구를 따라 부르는 흐름, 서버 `instructions` 유무까지 7개 조건 31회 모두 실행해 거절 0이다. 앱 실세션 1회도 무거절.
- 필수문서 5종 생성(2-3): 3/3 성공, 거절 0.
- 자가 확인(2-6): 서버 `instructions`에 `whoami` 선호출을 넣으면 5/5, 없으면 2/5.
