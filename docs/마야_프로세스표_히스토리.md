정본은 [마야_프로세스표.md](마야_프로세스표.md)와 공정 카드(`proc.py`)다. 이 문서는 바뀐 방식의 기록이라 작업 때 검색하거나 따르지 않는다.

## 링크드인 게시: Claude in Chrome 방식(2026-10-15 구PC 무인 크롬으로 대체)

- **링크드인(한성희)**: AItoEarn은 이미지 1장을 거부해 쓰지 않는다(2026-10-02). Claude in Chrome으로 `linkedin.com/feed` → 글 올리기 → 본문 붙여넣기 → **빈 줄이 사라지므로** 원문의 빈 줄 자리에 Enter를 한 번씩 다시 넣고(자리 지정 뒤 1초 기다렸다 Enter, 문단 패턴을 원문과 대조) → 링크 미리보기 카드 X로 제거(있으면 미디어 버튼이 숨음) → 미디어: 표지는 LinkedIn이 외부 이미지 fetch를 막으므로 base64를 클립보드로 넘겨 `File`을 만들고 파일 입력의 click을 가로채 넣는다 → 다음 → 시계 아이콘 → 날짜는 달력에서 클릭(직접 입력은 거부됨), 시간 선택 → 확인 → 일정 예약 → 예약함 목록에서 썸네일 확인. 탭이 화면 뒤에 있으면 붙여넣기가 안 되므로 사장님께 탭을 앞으로 띄워 달라고 한다. 페이스북·인스타는 표지를 저장소 파일(`log_assets/images/…_cover.jpg`)로 넣는다(URL을 넣으면 .bin으로 올라가 실패). 실패한 항목은 `content.media`를 비우고 status를 pending으로 되돌려 재시도한다. 초안은 `scripts/sns_queue_draft.py`로 만든다.
