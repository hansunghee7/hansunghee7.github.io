## 0. 결론
현재 576줄(42,578바이트, 상시 로드 약 1.3만~1.9만 토큰)을 **200줄 이하**로 줄인다. 규칙은 지우지 않고 위치만 옮긴다. 정책 변경은 없지만, 오퍼스 검토가 짚은 "이동만으로도 기본 동작이 약해질 수 있는 지점"은 7절에 모두 적고 KEEP으로 되돌렸다. 1판의 "170~190줄"은 제목·빈 줄을 세지 않은 과소 추정이었다. 정직한 예상은 **190~205줄**이고, 초과하면 5절 순서대로 더 줄이며 그래도 200을 넘으면 사장님께 먼저 묻는다.

## 3. 새로 만들 것
- 스킬 3개: `session-start`, `session-end`, `hermes-delegate` (기존 7개 + 3개). description은 상시 로드되므로 각 200자 이내(오퍼스 확인: 상시 로드 비용은 무시 가능). **`model-routing` 스킬은 만들지 않는다**(1판에서 삭제): 모델 선택은 "스킬을 열자"는 판단이 먼저 서지 않는 순간이라 껍데기가 될 위험이 크다.

- `@import`는 쓰지 않는다(공식 문서: 시작 시 함께 로드되어 절감 없음).

## 6. Subagent 후보
`.claude/agents/` 정의 파일은 만들지 않는다. 실측(2026-09-20)에서 일반 서브에이전트가 CLAUDE.md를 상속했고 고정비는 약 5.7만 토큰이었다. **CLAUDE.md가 줄면 모든 서브에이전트 호출이 함께 싸진다**(가장 큰 효과). 정의 파일이 필요한 신호는 같은 검토 지시문이 세 번 이상 반복될 때.

## 7. 정책 변경 여부와 "이동만으로 약해질 수 있는 지점"
정책 변경이 필요한 항목은 없다(권한, 승인 횟수, Hermes 역할, 모델 등급, 글쓰기 단계, 공개/비공개, main push 문구는 바꾸지 않는다). 아래는 단순 이동이 아니라 **의미나 기본값에 영향이 갈 수 있어** 설계에서 명시하고 완화한 지점이다(오퍼스 B1~B7).
1. **가격표 삭제**(B5): 지시서 9-3이 허용. 남기는 "단가가 가장 높다"는 문장이 "위 표"를 참조하므로 표 없이도 읽히게 문구를 다시 쓴다. 이 손질은 문구 변경이라 근거 이력에 원문을 남긴다.
2. **튜터 원칙 압축**(B1): ⚠️ 블록은 그대로 두고, 날짜·사례 문장과 6, 7번 예시만 옮긴다. 옮기는 문장은 1:1 목록으로 Phase 3 첫 작업에서 근거 이력 문서에 적고 독립 검토를 다시 받는다.
3. **Hermes 위임 대상 목록 이동**(B3): 기본 동작이 "위임 우선"에서 "직접 실행"으로 기울 수 있다. 위임 판단 1줄과 금지 목록은 CLAUDE.md에 남기고, 재시도 3회 자율 권한은 스킬로 옮기되 문구 그대로 유지한다(권한 변경 아님을 시험 S08로 확인).
4. **경험DB 트리거**(B4): "작업 완료를 보고하기 전에"라는 발동 시점이 바뀌면 안 되므로 원문 그대로 CLAUDE.md에 남긴다.
5. **아침 의식에 딸린 우편함 확인, 세션 메시지 뒤 우편함 한 줄**(B6): "하이~" 없이 시작한 세션이 못 보는 위험. SessionStart 훅 출력에 포함한다.
6. **커밋 인용 태그**(B2): 새김 측정의 유일한 데이터원이라 KEEP.
7. **"공유 폴더 주의"**(B7): 현재 CLAUDE.md 529-555에는 "스레드마다 영역을 나누라"만 있고 "공유 폴더 주의" 문구는 없다. 새로 쓰지 않는다.

## 8. Phase 3 실행 순서
1. 튜터 원칙에서 옮기는 문장을 1:1로 나열해 근거 이력 문서에 보존하고 오퍼스 재검토(오퍼스 조건 C2).
2. 근거 이력과 나머지 문서 4개를 작성(원문을 그대로 옮기고 참조 줄만 추가).
3. 스킬 3개와 rule 2개 작성. rule은 `paths:`가 있는지 정적 시험에 검사를 추가한다(없으면 상시 로드가 되어 절감이 사라짐).
4. `docs/claude_md_golden_test.md`의 "열기" 열과 `scripts/golden_test_claude_md.py`의 사실 수준(A/R)을 이동에 맞게 갱신한다(안 하면 개편 후 시험이 전건 FAIL로 보임).
