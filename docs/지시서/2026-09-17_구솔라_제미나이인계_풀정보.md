### Task 03. 설치 (사장님 직접, 화면 앞에서)

1. USB(G)를 구PC에 꽂고 전원 켜기
2. 부팅 로고 뜨자마자 **F12** 연타 → 부팅 메뉴에서 USB 이름 선택
3. "Try or Install Ubuntu Server" → 언어 English, 키보드 기본값(US)
4. 네트워크: 유선 랜 자동 IP 받으면 통과, Wi-Fi 무시
5. **디스크 선택 (가장 중요): "SAMSUNG 470 Series SSD, 약 60GB"만 선택.
   다른 디스크는 절대 건드리지 않음.** "Use An Entire Disk"로 그 디스크
   하나만.
6. 사용자명/컴퓨터명/비밀번호 설정 (SSH 로그인에 그대로 사용, 기록해둘 것)
7. **"Install OpenSSH server" 체크박스 반드시 체크**
8. 나머지 기본값으로 계속 진행
9. 설치 완료 → "Reboot Now" → USB 뽑고 Enter
10. 재부팅 후 검은 화면에 `login:` 뜨면 설치 성공

멈추거나 에러 화면이 뜨면 캡처해서 판단, 임의로 재시도하지 않기.
