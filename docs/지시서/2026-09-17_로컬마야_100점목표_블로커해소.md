# 마야 트렌드 리서치 파이프라인: "자동화 100점" 목표 지시서 (2026-09-17)

발신: 탐(로컬 세션) / 수신: 마야(로컬·클라우드 모두) / 승인: 사장님

## 배경

오늘(2026-09-17) 마야가 트렌드 리서치 파이프라인 7단계를 처음으로
end-to-end 실행 완료(628번 글, PR #666, 2026-09-24 발행 예약). 사장님
지시: **다음 세션부터 "자동화 100점"**(사장님 개입은 4단계 소재 픽 +
7단계 최종 컨펌, 이 두 곳만)을 목표로 진행. 오늘 실측 기준 그 외
10곳에서 추가 개입이 있었고, 그중 5건은 오늘 가이드로 즉시 고쳤음(PR
#659·#661·#665, 퍼스널_브랜딩_가이드.md 3절, check-dash.py). 남은
블로커 7개 중 1·2번을 탐(로컬)이 조사했다(근거: `docs/진행상황.md`
2026-09-17 "탐(로컬) → 탐(클라우드): 헤르메스 웹검색 429 + gemini-pool
URL 조사 결과" 절, proxy.log 실측 + Google 공식 문서).

## 블로커별 처리 방침 (7개 전체)

1. **헤르메스 웹검색 429(그라운딩 할당량 소진)** — **당분간 보류,
   WebFetch 수동 대체를 그대로 유지.** 원인은 Google 무료 티어
   grounding 자체의 한도(하루 20건/분당 5건, [출처](https://ai.google.dev/gemini-api/docs/rate-limits)) —
   유료 전환 없인 못 늘어남. 유료 전환 여부는 사장님 판단 대기.
2. **LiteLLM gemini-pool이 URL을 못 엶** — **다음 세션에서 저비용
   실험해볼 것**(마야 또는 탐, 담당 무관). Gemini `url_context` 툴을
   `litellm_config.gemini-pool.yaml`에 `tools: [{"url_context": {}}]`로
   추가하면 별도 과금 없이 될 가능성 있음(아직 실측 안 됨 — 마스터키
   취급 문제로 이번 세션은 못 함). 성공하면 2단계 URL 검증에 다시
   편입해 WebFetch 수동 대체를 줄인다.
3. **검색 콘솔 데이터 자동화** — 핏 담당, 이월 유지. 마야는 당분간
   사람이 json 직접 읽는 방식으로 3단계 검색수요 라벨을 채운다.
4. **발행 캐던스(요일당 1편) 자동 체크 없음** — 탐(클라우드)이 저장소
   자동화로 처리 가능한지 확인 중. 마야는 발행 전 수동으로 요일 캐던스
   확인을 계속 유지.
5. **GEO/AEO 룰셋 부재** — 사장님 결정 대기(의도적 보류 상태 그대로).
6. **"무거운 주제 vs 밝은 주제" 톤 조건부 판단 기준** — 사례 3개뿐,
   아직 패턴화 단계 아님. 마야는 매 글 판단 근거를 계속 기록만 쌓을 것.
7. **이미지 선택 "추천→사장님 픽" 구조 유지 vs 마야 단독 결정 이관** —
   사장님 결정 대기.
