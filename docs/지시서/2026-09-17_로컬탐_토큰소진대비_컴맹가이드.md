# 토큰 소진 대비: 사장님 직접 헤르메스 운전 환경 + 컴맹 가이드 (2026-09-17)

발신: 탐(클라우드 세션) / 수신: 탐(로컬, 신PC)

## 배경

클로드 코드(이 세션들)의 사용량이 소진되거나 접속이 안 되는 상황에도,
사장님이 헤르메스만으로 과제를 계속 진행할 수 있어야 한다. 다행히
헤르메스의 메인 모델은 애초에 Claude가 아니다(config.yaml
`model.provider`가 openai-codex → nous → opencode-free로 바뀌어왔고,
지금은 무료 provider). **즉 클로드 코드 사용량과 헤르메스 자체 동작은
원래 독립적이다.** 문제는 지금까지 "헤르메스에게 뭘 시킬지"를 전부
클로드 코드 세션이 판단해서 지시해왔다는 것뿐이다. 이 지시서의 목표는
그 판단 없이도 사장님이 직접 헤르메스를 켜고, 일을 시키고, 결과를
확인할 수 있게 만드는 것이다.

## 절대 원칙

이 문서 자체가 "완료했습니다"로 끝나면 안 된다(CLAUDE.md
DONE=VERIFIED). **아래 모든 단계는 로컬 탐이 실제로 처음부터 끝까지
한 번 그대로 따라 해보고**, 화면에 실제로 뜨는 문구·메뉴 이름으로
고쳐서 확정한다. 추측이나 "아마 이렇게 될 것"으로 남기지 않는다.

## 1. 환경 확인 (로컬 탐이 할 일)

1. **독립 실행 확인**: 클로드 코드 세션을 하나도 안 띄운 상태에서,
   순수하게 터미널만 열고 `hermes` 실행이 되는지 확인한다(당연히
   될 것으로 보이지만, 혹시 어떤 설정이 클로드 코드가 켜져 있어야만
   동작하게 돼 있는지 실제로 검증한다).
2. **바로가기 확인/생성**: 사장님이 "터미널을 연다"는 것 자체가 이미
   진입장벽일 수 있다. 바탕화면이나 시작 메뉴에 헤르메스를 바로 여는
   아이콘(배치 파일 더블클릭으로 터미널+`hermes` 실행)이 있는지 확인하고,
   없으면 만든다. 파일 이름은 예: `헤르메스 열기.bat`(내용:
   `@echo off` 다음 줄에 `hermes`, 필요하면 작업 디렉터리 `cd` 포함).
3. **평소 모델 확인**: `hermes config get model --json`으로 현재
   provider/model이 무엇인지 확인하고, 그게 실제로 인터넷 연결만
   있으면 동작하는 무료/이미 인증된 provider인지 재확인한다(사장님
   개인 계정 로그인이 만료돼 있으면 무용지물이니, 만료 여부도 같이
   확인).
4. **크론(예약 작업) 생존 확인**: `hermes cron list`로 지금 도는
   예약 작업이 클로드 코드 없이도 계속 동작 중인지 확인한다(이미
   상시 가동이라 별도 조치 없이 될 가능성이 높지만 확인은 필요).

## 2. 컴맹 가이드 초안 (로컬 탐이 실제로 검증 후 확정할 것)

아래는 오늘 밤 이 지시서들에서 실제로 검증된 명령어들을 바탕으로 한
초안이다. **로컬 탐이 처음부터 끝까지 실제로 따라 해보고, 화면에 뜨는
정확한 문구로 고쳐서 확정한다.** 확정되면 이 절을 그대로
`docs/컴맹가이드_헤르메스_직접운전.md`(신규 파일, 공개 저장소 문서라
인증정보는 절대 안 들어감)로 옮기고, 링크를 진행상황.md 상단에 남긴다.

---

### 헤르메스 직접 쓰는 법 (클로드 코드가 안 될 때)

**1단계: 헤르메스 열기**
1. 바탕화면(또는 시작 메뉴)에서 "헤르메스 열기" 아이콘을 더블클릭한다.
   (아이콘이 없으면: 시작 메뉴에서 "cmd" 또는 "PowerShell"을 검색해서
   열고, `hermes`라고 입력한 뒤 Enter.)
2. 검은 화면(터미널)이 뜨고 잠시 후 헤르메스가 준비됐다는 표시가
   나오면 성공이다.

**2단계: 일 시키기**
3. 화면 맨 아래 입력할 수 있는 줄에, 하고 싶은 일을 그냥 한국어
   문장으로 입력하고 Enter를 누른다. 예:
   - "docs/진행상황.md 맨 위를 읽고 지금 다음에 뭘 해야 하는지 알려줘."
   - "PR 목록 확인해서 병합 안 된 게 있으면 알려줘."
4. 헤르메스가 스스로 판단해서 파일을 읽거나 명령을 실행하고 답을
   보여준다. 답이 이상하면 "다시 설명해줘" 또는 더 구체적으로 다시
   물어보면 된다.

**3단계: 잘 되고 있는지 확인하고 싶을 때**
5. 같은 입력줄에 `/model`이라고 입력하면 지금 어떤 AI 모델을 쓰고
   있는지 보여준다.
6. 문제가 있어 보이면 `hermes doctor`라고 입력해서 자가진단 결과를
   본다(어떤 문제가 있는지 문장으로 알려준다).

**4단계: 끝내기**
7. 다 됐으면 `exit`라고 입력하고 Enter를 누르거나, 키보드에서
   Ctrl과 C를 동시에 눌러서 닫는다.

**뭔가 이상할 때**
- 화면에 빨간 글씨로 에러가 뜨면, 그 화면을 그대로 캡처해서 나중에
  클로드 코드(탐)나 로컬 탐에게 보여주면 된다. 지금 당장 못 고쳐도
  캡처만 해두면 나중에 원인 파악이 된다.
- 아무 반응이 없으면 5분 정도 기다려본다(생각보다 시간이 걸리는
  작업일 수 있다). 그래도 안 되면 Ctrl+C로 멈추고 다시 시작한다.
