# 헤르메스 → 제미나이 웹 딥리서치 브라우저 자동화 PoC 지시서 (사장님 2026-09-21, 요약본)

> 사장님이 채팅으로 준 지시서(전문)를 실행에 필요한 항목만 옮긴 것이다. 백로그 "토큰 아끼기 방안 1"의 성공 목표: **핏이 Claude 브라우저 컨트롤로 하던 제미나이 딥리서치를 헤르메스가 대체**한다.

## 목적과 구조
헤르메스가 사용자의 제미나이 웹 구독 계정(Google AI Pro) 로그인 세션으로 gemini.google.com의 Deep Research를 브라우저 조작으로 실행하고 보고서를 Markdown으로 저장한다.
흐름: 주제 입력 → 조사 계획 생성 → 연구 시작 → 완료 대기(보통 5~10분) → 보고서 열기 → 본문 추출 → Markdown 저장.

## 금지
Gemini API 사용·API 키 생성·과금 구조 도입, Gemini CLI를 딥리서치 호출 수단으로 쓰기, 구글 비밀번호를 코드·설정에 저장, 실제 크롬 프로필 직접 조작, 기존 헤르메스 운영환경 대규모 변경, 검증 안 된 selector 하드코딩, UI를 확인하지 않고 "동작한다"고 판단, 공식 문서에 없는 기능을 공식 지원으로 표현.

## 기록 원칙 (세 가지를 구분해 적는다)
A 공식 문서에서 확인된 사실 / B 기술적 가능성(공식 통합 문서 없음) / C 실제 검증 결과(PASS·FAIL·부분, 실패 단계, 원인, 재현 방법). 추측을 사실처럼 쓰지 않는다.

## 먼저 할 일: 현재 환경 조사(구현 전)
헤르메스 실제 버전, 설치 경로, browser 툴 활성 여부, agent-browser 설치, 브라우저 설치, backend 설정, `browser.use_real_profile`, `browser.headed`, `browser.cdp_url`, 제미나이 로그인에 쓸 브라우저, 실행 머신. **임의로 헤르메스를 업그레이드하지 않는다.**

## 단계별 PoC (각 단계 PASS/FAIL 기록, 스냅샷 보관)
1. 제미나이 웹 접속(TEST-01). 2. 기존 로그인 세션 유지(TEST-02, 2단계 인증·CAPTCHA 유무). 3. Deep Research UI 탐색(텍스트 검색 → 접근성 스냅샷 → 비전 순, ref 값은 실제 화면에서 발견). 4. 단순 질문으로 실제 실행(선택, 입력, 제출, 계획 생성, 연구 시작). 5. 30초 간격 스냅샷으로 완료 자동 감지(sleep 통째로 금지). 6. 보고서 추출(스냅샷 텍스트 → 주요 텍스트 영역 → 비전/CDP → 복사 기능). 7. Markdown 저장(주제, 요약, 전문, 출처, 메타데이터).

## 성공 기준 (연속 7개)
접속 / 로그인 유지 / UI 자동 탐색 / 질문 입력 / 실행 / 완료 감지 / 추출·저장. 전부 성공 = `PROVEN BY PoC`, 사람이 중간에 손대면 `PARTIAL`, 기술적으로 가능하나 미구현이면 `FEASIBLE / NOT IMPLEMENTED`.

## 우선순위
1 로컬 브라우저 + real profile, 2 headed 모드, 3 CDP(`/browser connect`는 대화형 명령이라 게이트웨이 경유 전제 금지), 4 기타. 성공한 뒤에만 텔레그램·게이트웨이·스케줄러로 확장한다.

## 보안·약관
real profile은 격리 경계가 아니라 실제 로그인 상태를 쓰는 편의 기능이다. 검토: 전용 구글 계정 가능성, Gmail·Drive 접근 가능성, 접근 가능한 탭·URL 제한, 세션 정보가 로그에 안 남는지. 구글 이용약관·제미나이 약관의 자동화 제한은 추측하지 말고 현재 공식 문서를 직접 확인해 별도 보고한다.

## 2026-09-21 탐 메모 (실측 상황)
- 수집 프로필(Chrome `Profile 15`)에 제미나이 업무·Pro 로그인 완료(사장님). 헤르메스 전용 프로필 `collector`(real profile 고정, `restrict_evaluate`)를 만들었다.
- 헤르메스 브라우저 도구가 안 보이던 원인: 기본 설정이 Browser Use CLI 모드(`browser_exec`)였고 CLI가 없었다. `collector`에 `browser.backend=off`와 `AGENT_BROWSER_EXECUTABLE_PATH`를 넣어 내장 도구를 켰다(가용 확인). 이후 첫 실행은 브라우저를 띄우는 단계에서 2분 넘게 멈췄다(원인 조사 중, 수집 프로필 창이 열려 프로필이 잠겼을 가능성).
- 같은 날 서브에이전트(클로드 브라우저 컨트롤)가 같은 계정으로 딥리서치를 3번 시도해 "저는 언어 모델일 뿐" 거부 응답을 받았다. 질문 표현("Claude Code" 등)이 원인일 수 있으나 미확인이라, 헤르메스 시험은 표현을 바꾼 단순 질문으로 시작한다.
