## Task 03. 설치 — 사장님이 구PC 앞에서 직접 (컴맹 가이드)

USB를 다 구우신 뒤 진행하세요.

1. 구PC에 USB를 꽂고 전원을 켠다.
2. 부팅 로고가 뜨자마자 **F12**를 연타한다 (Gigabyte 보드 기준).
   → 부팅 메뉴가 뜨면 성공, 그냥 윈도우가 켜지면 재시작해서 다시 시도.
3. 부팅 메뉴에서 USB 이름(제조사명이 붙은 항목, 보통 "UEFI: 〈USB
   브랜드〉")을 선택한다.
4. "Try or Install Ubuntu Server" 화면이 뜨면 언어(English) → 키보드
   레이아웃은 기본값(US) 그대로 진행.
5. 네트워크 설정 화면: 유선 랜선이 꽂혀 있으면 자동으로 IP를 받는다
   (화면에 IP 주소가 보이면 성공). Wi-Fi는 이 PC에서 연결 이력이 없으니
   무시하고 넘어간다.
6. 디스크 선택 화면(Storage configuration)이 가장 중요한 단계:
   **"SAMSUNG 470 Series SSD, 약 60GB"라고 표시된 디스크만 선택.**
   다른 디스크(용량이 더 큰 것)는 절대 건드리지 않는다.
   → "Use An Entire Disk" 옵션에서 그 디스크 하나만 고르고 계속 진행.
7. 사용자 이름·컴퓨터 이름·비밀번호 설정 — 나중에 SSH 로그인에 그대로
   쓰이니 기억하기 쉬운 값으로 정하고 어딘가에 적어둔다.
8. **"Install OpenSSH server" 체크박스가 뜨면 반드시 체크한다.**
   (Import SSH key 옵션은 건너뛰어도 됨.)
9. 나머지 화면(추가 패키지 등)은 전부 기본값으로 "Done"/"Continue".
10. 설치가 끝나고 "Reboot Now" 안내가 뜨면 USB를 뽑고 Enter.
11. 재부팅 후 로그인 프롬프트(`login:`)가 검은 화면에 뜨면 설치 성공.

**실패 시**: 어느 단계에서 멈추거나 에러가 뜨면 그 화면을 캡처해서
알려주세요. 임의로 다시 시도하지 말고 캡처부터.

## Task 04. 네트워크 구성 — 설치 중 자동, 로그인 후 확인만

로그인 프롬프트에 방금 만든 사용자명/비밀번호로 로그인한 뒤:

```
ip a
```

`eth0` 또는 비슷한 이름 옆에 `inet 172.30.1.x` 형태의 IP가 보이면 성공.
이 IP를 사장님께 보고 — 다음 단계(SSH)에 씁니다.

## Task 05. Tailscale — 이번 범위 제외

기존 Tailscale 주소(`100.83.83.53`)는 이번 윈도우 설치에 묶인 상태라
우분투로 갈아엎으면 사라진다(구솔라 실측으로도 확인됨 — 우분투 설치
전 시점에도 여전히 그 윈도우에서만 살아있었음). 지금은 집 안 LAN에서만
쓰므로 재설치 안 해도 SSH로 충분. 집 밖에서 접속해야 할 필요가 생기면
그때 새로 설치.

## Task 06. SSH 확인 — 신PC에서 사장님이 직접

1. 신PC에서 PowerShell(또는 명령 프롬프트)을 연다.
2. 아래 명령을 입력 (IP는 Task 04에서 확인한 값으로 교체):
   ```
   ssh 사용자명@172.30.1.x
   ```
3. "fingerprint를 확인할 수 없다"는 경고가 뜨면 `yes` 입력 후 Enter
   (처음 접속할 때만 나오는 정상 경고).
4. 설치 때 만든 비밀번호 입력.
5. `사용자명@컴퓨터이름:~$` 같은 프롬프트가 뜨면 SSH 접속 성공.
