# 딥리서치 의뢰서: 마야 "얇은 글" 리서치용 로컬 한국어 모델 선정

## Objective

로컬(무료, GPU 로컬 실행) LLM 중 한국어 텍스트 리서치 작업(사실 추출,
콘텐츠 품질 판단)에 실사용 가능한 수준의 모델을 찾는다. 목적은 마야의
"얇은 글"(thin content) 판단 리서치를 로컬 무료 모델에 위임하는 것.

## Context

이 PC(Windows, Ollama 로컬 서버, OpenAI 호환 엔드포인트
`http://127.0.0.1:11434/v1`)에 이미 받아져 있는 모델 3개를 같은
2개 과제로 직접 테스트했고 전부 실패했다(2026-09-17 로컬 탐 실측):

1. **qwen2.5-coder:14b**: 한국어로 답하라는 지시를 무시하고 영어로 답변,
   질문 취지 오해(사용자가 "얇은 콘텐츠를 써달라"고 요청한 것으로 잘못
   이해), 숫자 환각("월 24~32건"을 "나이 24~32세"로 읽음).
2. **qwen2.5vl:7b**(비전 모델, 웹툰 OCR 용도로는 검증됨): 한국어 지시
   무시, 존재하지 않는 이모지를 봤다고 환각. 두 번째 테스트에서는
   완전히 깨진 반복 출력(3373토큰짜리 의미 없는 문자 반복).
3. **hermes3:8b**(Llama-3 기반, Nous Research): 완전히 깨진 mojibake성
   출력, 숫자 전부 환각, 문장 구조 붕괴.

세 모델 다 한국어 코퍼스 비중이 낮은 범용/코드/비전 특화 모델이라
한국어 자연어 추론에서 붕괴하는 것으로 추정.

**과제 예시(실제 테스트에 쓴 것)**:
- 과제 A: "다음 글이 SEO 관점에서 얇은 콘텐츠로 분류될 만한지 판단하고
  이유를 한국어로 2~3문장으로 설명" (판단형)
- 과제 B: "다음 한국어 텍스트에서 핵심 사실 3개를 한국어 번호 목록으로
  추출" (추출형)

## 조사해줄 것

1. **한국어 특화 또는 한국어 벤치마크 상위권 오픈웨이트 모델**을
   찾는다. 후보 예시(확인 필요, 추측 금지): EXAONE(LG AI), Kanana(카카오),
   Llama-3-Korean-Bllossom, HyperCLOVA X 오픈 배포판(있다면), Qwen
   2.5의 더 큰 버전(32B 이상, 한국어가 더 나은지). **최근 한국어
   벤치마크(KMMLU, LogicKor, Ko-Arena 등) 순위와 출처를 같이 밝힐 것.**
2. **Ollama로 실제 받아 쓸 수 있는지** 확인(Ollama 모델 라이브러리에
   등록돼 있는지, 아니면 GGUF 변환본을 수동으로 받아야 하는지).
3. **이 하드웨어에서 돌릴 수 있는 크기**인지 참고 정보로 밝힌다(정확한
   VRAM/RAM 사양은 이 조사에서 확정하지 말고, 파라미터 수와 양자화
   옵션만 밝히면 로컬 탐이 직접 실측한다).
4. 위 과제 A·B 같은 **한국어 판단·추출형 작업에 강점이 있다고 알려진
   모델**을 우선순위로 제시.

## Constraints

- 회사 자체 통계나 출처 없는 정밀 수치는 인용하지 말 것(정성적 표현
  사용).
- 이 문서에 나온 실패 사례는 참고 배경일 뿐, 그대로 재검증할 필요는
  없음(로컬 탐이 후보를 받으면 직접 재현 테스트함).

## Acceptance Criteria

- 후보 모델 2~3개, 각각 (a) 왜 한국어에 강한지 근거·출처, (b) Ollama
  입수 가능 여부, (c) 대략적 파라미터 규모를 표 또는 목록으로 정리.
- "확실한 정답 없음/후보 없음"이라는 결론도 유효한 결과다(있는 것처럼
  꾸미지 말 것).

---

결과는 목적에 맞는 최소 표현으로 작성해줘. 산문·설명은 순수 마크다운,
표·레코드 데이터는 JSON(납작한 표는 CSV), 코드는 원본 코드 그대로,
API 스키마는 JSON/OpenAPI. HTML이나 장식용 포맷은 쓰지 마.
맨 앞에 "[반입용 요약]" 한 문단(결론 우선, 5문장 이내)을 두고,
본문은 근거와 출처 위주로.
특정 회사·플랫폼의 자체 통계(가입자 수, 카테고리별 정확한 개수·비율
등)는 출처 URL이나 발표 문서명을 못 대면 절대 인용하지 마. 숫자
대신 "다수", "상당수" 같은 정성적 표현을 써.
