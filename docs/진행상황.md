**한 것**: ① 세 후보(절 번호/절 제목/안정 id) 비교 후 **안정 id**로 결정 —

`report`는 `<TAG> §번호` 대신 `<TAG>#<id>` 인용을 집계 (커밋
[`80c73f0`](https://github.com/hansunghee7/simplifier-saegim/commit/80c73f0)).
③ 구현 검증 중 **실제 버그 발견·수정** — 헤딩 정규식(`\s*$`, MULTILINE)이
헤딩 뒤 빈 줄의 개행까지 삼켜, id 주석이 헤딩 줄이 아니라 다음 줄에 따로
떨어져 써지고 재실행마다 새 id가 계속 발급되는 문제. `[ \t]*$`로 수정하고
재실행 멱등성·인용 집계까지 실측으로 재검증. ④ `docs/UX_GUIDE.md`·
`docs/WRITING_GUIDE.md`(총 22개 절) 마이그레이션 + 인용 관행 안내를
`#id` 형식으로 갱신, `insight-7b3e9f2c/style-guide.html` 동기화 사본도
갱신 (PR [#244](https://github.com/hansunghee7/hansunghee7.github.io/pull/244)).
⑤ cxo-db 인박스 등록:
[#26](https://github.com/hansunghee7/simplifier-cxo-db/issues/26)
(구조적 키 전환 결정 + 실제 버그 발견/수정, 뒤집을 신호 포함). ⑥ 설계

"인용 관행" 절에 있음).

**다음 것** — 아래 셋은 제품 스코프 판단이라 탐이 임의로 정하지 않고
