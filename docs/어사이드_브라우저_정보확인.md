# 어사이드 브라우저로 정보 확인하기

사장님이 로그인한 화면에서만 보이는 정보를, 사장님 PC의 어사이드 브라우저에 있는 Claude 에이전트에게 읽혀 가져오는 방법이다. 2026-10-07 사장님 지시로 실측 내용을 모아 둔 공용 문서이며, 모든 에이전트가 사장님께 확인을 부탁하기 전에 먼저 읽는다.

## 이게 무엇인가

- Claude 데스크톱 앱 오른쪽 옆 창(어사이드)에 Claude 에이전트가 있다. 여기에 주소(URL)나 메뉴 경로와 지시문을 주면, 사장님이 이미 로그인한 화면에서 정보를 읽어 문서·텍스트·캡처로 돌려준다.
- 우리 에이전트가 직접 못 가는 곳(계정 설정, 결제, 앱 연결 화면)의 상태를 가져오는 길이다.
- 사람 개입 4종 중 "자격증명이 걸린 화면"에서만 쓴다. 에이전트가 직접 읽을 수 있으면 쓰지 않는다.

## 사장님 실측 사례

### 사례 1. 클라우드 세션의 저장소 접근 확인 (10/7 09:03)

- 배경: 클라우드 세션이 shorts-lab에 접근하는지 핏이 확인해야 했고, 핏이 사장님께 "복붙 한 줄"로 부탁했다.
- 사장님이 어사이드에 넣은 지시문 원문: `claude.ai/code → 설정 → GitHub 연결에서 Claude 앱이 shorts-lab에 접근하는지 체크 여부를 알려 주세요`
- 어사이드 에이전트의 첫 응답: "현재 Claude 탭에서 GitHub 연결 설정을 확인하겠습니다. 저장소 접근 권한은 변경하지 않고 확인만 할게요."
- 약 1분(Worked for 1m 0s) 뒤 응답: "네, Claude 앱은 hansunghee7/shorts-lab 에 접근할 수 있습니다. 설정 → 커넥터 → GitHub 통합에서 저장소 상태를 검사했고, 다음 메시지를 확인했습니다. Claude Code 클라우드 세션은 hansunghee7/shorts-lab 저장소에서 작업할 수 있습니다. 권한 설정은 변경하지 않았습니다."
- 화면 캡처가 함께 왔다. 캡처에는 GitHub 계정 연결됨, Claude GitHub App 설치됨(개인 계정, 클라우드 세션만), 저장소 상태 확인 항목이 보였다.
- 결과: 핏이 세운 원인 후보 (a)가 해소됐다.

### 사례 2. 웹 텔레그램으로 봇 응답 읽기 (2026-09-21)

- 사장님 PC의 어사이드 브라우저에 웹 텔레그램 즐겨찾기가 있어, 폰 캡처를 부탁하지 않고 봇 응답을 읽기 전용으로 직접 확인할 수 있다고 사장님이 알려 주셨다.
- 주의 사항: 컴퓨터 사용 도구로 열면 브라우저는 읽기 권한이라 클릭·입력이 막힌다. 사장님 이름으로 메시지를 보내는 일은 허락 없이 하지 않는다. 같은 즐겨찾기에 개인 SNS 탭이 섞여 있으니 필요한 대화창만 본다.
- 어사이드가 두 번째 모니터에 있어 화면 전환을 시도했다가 승인되지 않아 중단된 이력이 있다. 같은 시도를 반복하지 않는다.

### 사례 3. 구글 크레딧 확인 (10/7 00:38)

- 사장님이 어사이드 브라우저에서 두 계정의 구글 크레딧을 확인해 공유하셨다.
- 같은 날 사장님 팁: 어사이드 프롬프트 창에 URL과 명령을 넣으면 해당 페이지로 이동해 잔액·만료일 같은 값까지 읽어 준다.
- 구체적 수치는 이 문서에 옮기지 않았다. 필요하면 사장님 말 원장과 계정 현황표에서 찾는다(미확인).

## 에이전트가 쓰는 법

### 복붙 한 줄 템플릿

사장님께는 한 번에 한 가지만 부탁한다. 형식은 아래와 같다.

- 주소 또는 메뉴 경로 + 확인할 것 + "변경하지 말고 확인만 해주세요" + "결과는 화면 문구를 그대로 인용하고 캡처도 붙여 주세요".

예시 1, 앱 연결 상태:
`claude.ai/code → 설정 → GitHub 연결에서 Claude 앱이 <저장소 이름>에 접근하는지 체크 여부를 알려 주세요. 변경하지 말고 확인만 해주세요. 화면 문구를 그대로 인용하고 캡처도 붙여 주세요.`

예시 2, 잔액과 만료일:
`<콘솔 주소>에 들어가서 크레딧 잔액과 만료일을 알려 주세요. 변경하지 말고 확인만 해주세요. 화면 문구를 그대로 인용하고 캡처도 붙여 주세요.`

예시 3, 계정 설정 상태:
`<서비스 이름> 설정 → <메뉴 이름>에서 <항목>이 켜져 있는지 알려 주세요. 변경하지 말고 확인만 해주세요. 화면 문구를 그대로 인용하고 캡처도 붙여 주세요.`

### 결과를 받으면

- 어사이드가 돌려준 문구는 원문 그대로 기록한다. 요약하다 뜻이 바뀌는 것을 막기 위해서다.
- 해석은 원문 아래에 따로 적는다.
- 확인하지 못한 것은 지어내지 않고 "미확인"으로 쓴다.
- 어사이드가 읽은 화면 문구는 근거로 인용할 수 있다(업무대장·보고에 출처로 단다).

## 언제 쓰고 언제 쓰지 않나

### 쓴다

- 사장님 로그인 세션이 있어야 보이는 설정, 앱 연결, 계정 화면의 상태를 읽을 때.
- Chrome 확장이 끊겨 에이전트가 로그인된 콘솔 값을 못 읽을 때.

### 쓰지 않는다

- 에이전트가 스크립트, ssh, 서브에이전트로 직접 읽을 수 있는 것(핏 #52 순서를 먼저 따른다).
- 비밀번호나 키 입력. 어사이드에도 시키지 않는다.
- 설정 변경, 삭제, 결제, 발송. 어사이드에 시키는 일도 읽기만 허용한다.

## 안전

- 화면에 비밀값(키, 토큰, 비밀번호)이 보이면 그 부분이 캡처에 들어가지 않게 요청 문구에 적는다.
- 사장님이 한 번에 한 가지만 부탁받게 한다. 여러 개를 묶어 보내지 않는다.
- 같은 질문을 반복하지 않는다. 사장님이 이미 준 답은 이 문서, 메모, 말 원장에서 먼저 찾는다(기록 찾기는 에이전트 몫).

## 한계

- 사장님이 직접 지시문을 어사이드에 붙여넣어야 해서 자동화되지 않는다.
- 읽는 데 약 1분이 걸린다(사례 1 실측).
- 서비스 화면 구성이 바뀌면 메뉴 이름이 달라질 수 있다. 메뉴 경로가 안 맞으면 어사이드가 찾은 실제 경로를 기록해 이 문서를 고친다.
- 원격 접속 중에는 브라우저 창이 줄어드는 문제가 있다. 별도 메모(원격 접속 시 브라우저가 작아짐, 핏 공정 카드 #35·#37)를 본다.
