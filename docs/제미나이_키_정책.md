# 제미나이 키·경로 정책 (정본, 2026-10-03 사장님 결정, 탐 정리)

모든 에이전트는 제미나이를 부르기 전에 이 문서로 어느 경로를 쓸지 정한다. [AI_ROUTING_POLICY.md](AI_ROUTING_POLICY.md)의 제미나이 항목과 어긋나면 **이 문서가 정본**이다(그쪽 줄은 이 문서를 가리킨다). 키 값은 어디에도 쓰지 않고 이름만 적는다.

## 한 줄 원칙

**무료 AI Studio 키를 먼저 쓰고, 막히면 개인 GCP 무료 크레딧으로 넘어간다. 카빗 GCP 계정은 에이전트 리서치에 쓰지 않는다.** (사장님 2026-10-03: "무료 키 먼저, 막히면 GCP 좋아요", 크레딧은 적어도 2달 넉넉히 쓴다.)

## 경로 세 가지와 쓰임

- **① 무료 AI Studio 키** (`GOOGLE_API_KEY`, 헤르메스 `.env`). 에이전트 리서치의 기본 경로. 횟수 제한이 있으니 질문은 한 번에 몰아 넣고, 항목마다 원본 출처(전체 주소)를 요구한다. 단건 사실 확인은 `scripts/ops/gemini_fast.py`. 한도는 모델에 따라 다르다(AI_ROUTING_POLICY 참고, 실측 2026-09-23). TTS는 하루 10회.
- **② 개인 GCP 무료 크레딧** (Vertex AI, 프로젝트 `My First Project`, 사장님 개인 구글 계정의 결제 계정). 인증은 `gcloud auth print-access-token`이라 키 값이 없다. 쓰는 곳: 검색 연동이 필요한 리서치(`C:/work/_ops/tools/vertex_research.py`), 비티가 막혔을 때의 대체 호출(`scripts/ops/ask_vertex.py`, `ask_bt.sh`가 자동 전환), 긴급 영상(편당 ₩15,000~25,000이라 **긴급할 때만**). 무료 체험 크레딧이라 **유료로 올리지 않는다**(만료 12/23, 10/3 잔액 ₩326,145).
- **③ 카빗 GCP 계정** (회사 구글 계정, 프로젝트 `saegim-mcp`). 카빗 서버 운영 전용. 에이전트 리서치·실험에는 쓰지 않는다.

## 언제 어느 경로인가

- 검색 연동이 필요 없는 일(요약·분류·검증 보조·단건 확인): ①.
- 검색 연동이 필요한 리서치: 9/26 실측으로 ①은 검색 연동이 429였고, 훅(`research-gate.sh`)이 검색 연동 제미나이를 `vertex_research.py`로만 허용하므로 **②로 직행**한다. 이 줄은 [재실측 필요]다(무료 키 검색 연동이 풀렸는지, 탐이 훅 허용 범위와 함께 확인).
- ①이 429로 막힌 일: ②로 넘어간다. 한도 기록은 `python scripts/ops/quota.py status`.
- 비티: 안티그래비티 제미나이 → ② Vertex → Sonnet 순(`ask_bt.sh`).

## 쓰지 않는 것·미확인

- `GEMINI_VERIFY_KEY`(선불 유료): 에이전트는 쓰지 않는다. 현재 쓰는 곳은 `gemini_ping.py` 하나뿐인 것으로 보이고 정리 여부는 사장님 결정 사항이다 [미확인].
- 로컬 `gemini-pool`(localhost:4000)과 구PC 공식 CLI(`goosolar/gemini_cli_ask.py`): 용도 불명확 [미확인], 새 작업에 쓰지 않는다.
- 다이얼로그 키(`role=dialog`)는 코드가 제외한다. 그대로 둔다.

2. ①이 막혔으면 ②를 쓴다(하루 상한 안). ②도 상한이면 다음 날 또는 탐에게 우편.
3. 카빗 계정(③)은 어떤 경우에도 쓰지 않는다.
4. 정책을 바꾸고 싶으면 사장님께 묻고, 바뀌면 이 문서를 먼저 고친다.
