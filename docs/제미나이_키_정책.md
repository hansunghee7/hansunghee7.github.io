# 제미나이 키·경로 정책 (정본, 2026-10-03 사장님 결정, 탐 정리)

모든 에이전트는 제미나이를 부르기 전에 이 문서로 어느 경로를 쓸지 정한다. [AI_ROUTING_POLICY.md](AI_ROUTING_POLICY.md)의 제미나이 항목과 어긋나면 **이 문서가 정본**이다(그쪽 줄은 이 문서를 가리킨다). 키 값은 어디에도 쓰지 않고 이름만 적는다.

## 한 줄 원칙

**무료 AI Studio 키를 먼저 쓰고, 일반 대화는 옴니라우터 콤보, 그다음 GCP Vertex로 내려간다. Vertex는 회사 결제 프로젝트 크레딧을 먼저 태우고 개인 크레딧은 폴백이다. 카빗 서버 운영 프로젝트는 에이전트 리서치에 쓰지 않는다.** (사장님 2026-10-03: "무료 키 먼저, 막히면 GCP 좋아요", 크레딧은 적어도 2달 넉넉히 쓴다.)

## 경로 세 가지와 쓰임

- **① 무료 AI Studio 키** (`GOOGLE_API_KEY`, 헤르메스 `.env`). 에이전트 리서치의 기본 경로. 횟수 제한이 있으니 질문은 한 번에 몰아 넣고, 항목마다 원본 출처(전체 주소)를 요구한다. 단건 사실 확인은 `scripts/ops/gemini_fast.py`. 한도는 모델에 따라 다르다(AI_ROUTING_POLICY 참고, 실측 2026-09-23). TTS는 하루 10회.
- **② GCP Vertex (두 크레딧 풀)**. 인증은 로그인 토큰이라 파일에 키 값이 없다. 쓰는 곳: 검색 연동이 필요한 리서치(`C:/work/_ops/tools/vertex_research.py`), 비티가 막혔을 때의 대체 호출(`scripts/ops/ask_vertex.py`, `ask_bt.sh`가 자동 전환), 긴급 영상(편당 ₩15,000~25,000이라 **긴급할 때만**). 무료 체험 크레딧이라 **유료로 올리지 않는다**.
  - 회사 결제 프로젝트: 약 ₩408,000, 12/10 만료. 회사 계정 토큰으로 호출하며 **먼저 쓴다**. 로그인이 만료되거나 실패하면 개인 쪽으로 자동 폴백한다.
  - 개인 프로젝트(`My First Project`): 약 ₩303,000, 12/23 만료. 회사 쪽이 막혔을 때 쓴다.
  - 만료가 빠른 회사 크레딧부터 소진해야 낭비가 적다.
- **②-0 옴니라우터 콤보**: 일반 대화 성격의 호출은 이 콤보를 쓴다(②보다 먼저).
- **③ 카빗 서버 운영 프로젝트** (`saegim-mcp`). 카빗 서버 운영 전용. 에이전트 리서치·실험에는 쓰지 않는다. 회사 결제 계정은 서버와 같은 결제 계정이라 서버 요금(월 약 ₩4,000~13,000)도 같은 회사 크레딧에서 나가지만, Vertex 전용 프로젝트와 분리돼 있어 요금이 섞여 보이지는 않는다.

## 언제 어느 경로인가

- 검색 연동이 필요 없는 일(요약·분류·검증 보조·단건 확인): ①.
- 검색 연동이 필요한 리서치도 **①을 먼저 시도하고, 429나 차단이면 ②(Vertex)로 자동 전환**한다(사장님과 탐 합의 2026-10-03). 도구(`vertex_research.py`)가 이 순서대로 움직인다(10/3 보정, 기본 `--route auto`). 훅(`research-gate.sh`)은 도구 이름만 보므로 그대로 통과한다. **10/3 21시 실측: 무료 키 검색 연동은 아직 429였고 곧바로 Vertex로 넘어가 200**(경로는 stderr 한 줄과 `research_log.jsonl`의 `route`에 남는다). 무료 키 한도가 풀리면 코드 수정 없이 무료로 간다.
- ①이 429로 막힌 일: ②로 넘어간다. 한도 기록은 `python scripts/ops/quota.py status`.
- 비티: 안티그래비티 제미나이(무료) → ② Vertex → Sonnet 순(`ask_bt.sh`). 남은 2달(~12/23) 동안 비티와 적극 협업하며 이 경로의 사용량·쓸모를 실측한다(합의 2026-10-03, 대장 N120).

- 특별시기(~10/10)는 일 상한 **₩20,000이 기준선**, 코드 차단선은 ₩25,000이다(목표 ₩20,000, 조금 넘는 것은 허용).

- 호출 수 상한과 사람별 몫 상한은 두지 않는다. 전체 금액 상한만 코드(`ask_vertex.py`)로 강제한다.
- 호출 기록 `C:/work/_ops/vertex_usage.csv`(토큰·검색 횟수·추정 비용), 리서치 기록 `C:/work/_ops/research_log.jsonl`.
- 월 예산 알림 ₩150,000 (`탐-리서치 월 예산 알림(10/3)`, 결제 관리자 이메일). 크레딧 소진·만료 임박은 탐이 감시한다(대장 N119·N120).
- 단가는 가정값이다. 결제 보고서(프로젝트별)와 대조해 고친다(N120).

## 쓰지 않는 것·미확인

- `GEMINI_VERIFY_KEY`(선불 유료): 에이전트는 쓰지 않는다. 현재 쓰는 곳은 `gemini_ping.py` 하나뿐인 것으로 보이고 정리 여부는 사장님 결정 사항이다 [미확인].
- 로컬 `gemini-pool`(localhost:4000)과 구PC 공식 CLI(`goosolar/gemini_cli_ask.py`): 용도 불명확 [미확인], 새 작업에 쓰지 않는다.
- 다이얼로그 키(`role=dialog`)는 코드가 제외한다. 그대로 둔다.
- **AI Studio의 Gemini API에는 무료 체험 크레딧이 적용되지 않는다.** 체험 크레딧은 Vertex에서만 소진된다. "무료 키 한도가 차서 크레딧으로 넘어간다"는 말은 곧 Vertex 경로로 넘어간다는 뜻이다.
- 무료 등급 한도는 일반 모델 분당 5회·하루 20회 수준이라(9/23 확정), 경량 모델은 수집·분류용, 일반 모델은 몰아서 한 번에 묻는 용도로 나눈다.

## 막힌 에이전트가 할 일

1. `quota.py status`로 한도·막힘을 본다.
2. ①이 막혔으면(429·403·503) ②를 쓴다(하루 상한 안). 회사 로그인이 만료되거나 실패하면 개인 쪽으로 자동 폴백한다. ②도 상한이면 다음 날 또는 탐에게 우편.
   - 크레딧이 끝나면 Vertex 호출은 403으로 막힌다. 그때는 옴니라우터와 무료 키로 복귀한다.
3. 카빗 서버 운영 프로젝트(③)는 어떤 경우에도 쓰지 않는다. 키·토큰 값은 금고(Carvit Pass)로만 다루고 문서·로그·대화·우편에는 참조 이름만 쓴다.
4. 정책을 바꾸고 싶으면 사장님께 묻고, 바뀌면 이 문서를 먼저 고친다.
