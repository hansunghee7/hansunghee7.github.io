## 사람과 본 세션

- **사장님**: 승인과 제품·비가역 결정. 핏과의 접점은 음성대본 확정과 최종본 검수 둘뿐.
- **탐(로컬)**: 인프라·감시·주기 작업·전사 조정, 헤르메스 직접 창구. 비티 큐와 판정, 타미의 선배. 카빗 기술은 노트에게, 제품 판단은 지투에게 넘긴다. [역할노트-탐.md](역할노트-탐.md), [탐_프로세스표.md](탐_프로세스표.md)
- **클라우드탐**: 에이전트팀과 예약 루틴 감사. 실행은 로컬탐에게 넘긴다. [역할노트-클라우드탐.md](역할노트-클라우드탐.md)
- **마야**: 콘텐츠와 마케팅. 기술은 탐, 개발은 노트, 디자인은 시안에게 넘긴다. [역할노트-마야.md](역할노트-마야.md)
- **핏**: 숏폼 한 편의 전 공정, GPU 관리자. [역할노트-핏.md](역할노트-핏.md)
- **북**: 점검 담당 — 고객 시점 QA·보안 점검. 부 역할은 사장님 외출 중 브라우저 작업. [역할노트-북.md](역할노트-북.md)
- **지투**: 외부 고객 1호 전담 겸 Carvit PO, UX 가이드 수정 주인. 구현은 노트에게 넘긴다. 역할 노트는 비공개 카빗 저장소에 있다.
- **노트**: 다른 페르소나가 넘긴 전문 개발 구현. [빈 곳] 지투가 PO라는 것과 PR 검토 주체가 노트 쪽 문서에 없다(노트 회신 대기).
- **페이브**: 판정과 지시서 뼈대. [모델_라우팅.md](모델_라우팅.md)
- **시안**: [빈 곳] 역할노트와 업무대장이 없다.
- **비즈**: [빈 곳] 구글 VIDS 영상 담당이라는 메모 외에 저장소 문서 근거가 없다.

## 카빗 이름 대응 (2026-10-22 사장님 결정: 신원은 회사명_에이전트명)

페르소나 이름(이 저장소의 문서·세션 카드·업무대장 이름)과 카빗 신원 이름을 같이 적는다. **카빗 이름에서 `카빗_`을 떼면 페르소나 이름**이다. 새 세션은 자기 이름을 먼저 정하고 세션 시작 의식(하이~)을 한다(사장님 2026-10-22: 이름 붙이고 시작).

- **노트 = 카빗_노트** (영문 Carvit_Note, `note`). 서버 이름 `carvit`(이 저장소 폴더 기본).
- **지투 = 카빗_지투** (영문 Carvit_Jitu, `jitu`). 서버 이름 `carvit-jitu`.
- **탐 = 카빗_탐** (영문 Carvit_Tam, `tam`). 서버 이름 `carvit_tam`(별도 폴더).
- **카빗 도우미 = 카빗_도우미** (영문 Carvit_Help, `help`). 지원 에이전트, 전용 폴더 C:/work/_ops/carvit_help. 등록된 서버 이름은 `carvit_kabit-doumi`.
- **마야·핏**: 카빗 계정이 아직 없다(카빗DM 2차 P4에서 추가, 추가되면 이 목록에 `카빗_마야`·`카빗_핏` 형식으로 적는다).
- 북(UT 북 포함)은 시험 계정이라 이 이름 규칙 밖이다.
- 정본: 이름 규칙은 [카빗MCP_R13_신원_설계.md](카빗MCP_R13_신원_설계.md) '신원 이름 규칙', 진행은 [카빗DM_2차_슈퍼프로젝트.md](카빗DM_2차_슈퍼프로젝트.md).

## 실행·검증 엔진

- **헤르메스(신솔라·구솔라)**: 실행·관측·재시도, 초안까지. 판정 금지(CLAUDE#5e1a). 라우팅 정본은 [AI_ROUTING_POLICY.md](AI_ROUTING_POLICY.md), 작업 카드는 [.hermes/task_cards/README.md](../.hermes/task_cards/README.md).
- **타미(헤르메스 주니어)**: 감시 붉은 항목 1차 진단, 실측, 탐이 준 일의 소유. 탐에게만 보고한다. 권한은 PR까지(병합은 탐, 크론·감시 대장은 탐과 같은 선, 사장님 결정 2026-10-02). 문서는 비공개 저장소 `hermes-juniors`에 있다.
- **비티**: 소환형 독립 2차 검증. 큐는 탐이 채우고 채택·반려도 탐이 한다. 호출 방법은 [processes/비티_상시루프.md](processes/비티_상시루프.md).
- **덱스**: 탐이나 노트가 지시서를 준 격리 워크트리 안에서 테스트 실패를 고치는 패치 작성자. 내놓는 것은 diff와 테스트 종료 코드뿐이다. 영입 전 단계. [역할노트-덱스.md](역할노트-덱스.md), [덱스_영입_준비.md](덱스_영입_준비.md) (PR #1527)
