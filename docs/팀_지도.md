# 팀 지도

팀 명단의 정본. 다른 문서의 명단은 이 문서를 가리킨다.

> 근거: 2026-10-02 F3 전체 에이전트 감사. 근거 없는 자리는 [빈 곳]으로 남긴다(채우는 쪽이 이 문서를 고친다).

## 사람과 본 세션

- **사장님**: 승인과 제품·비가역 결정. 핏과의 접점은 음성대본 확정과 최종본 검수 둘뿐.
- **탐(로컬)**: 인프라·감시·주기 작업·전사 조정, 헤르메스 직접 창구. 비티 큐와 판정, 타미의 선배. 새김 기술은 노트에게, 제품 판단은 지투에게 넘긴다. [역할노트-탐.md](역할노트-탐.md), [탐_프로세스표.md](탐_프로세스표.md)
- **클라우드탐**: 에이전트팀과 예약 루틴 감사. 실행은 로컬탐에게 넘긴다. [역할노트-클라우드탐.md](역할노트-클라우드탐.md)
- **마야**: 콘텐츠와 마케팅. 기술은 탐, 개발은 노트, 디자인은 시안에게 넘긴다. [역할노트-마야.md](역할노트-마야.md)
- **핏**: 숏폼 한 편의 전 공정, GPU 관리자. [역할노트-핏.md](역할노트-핏.md)
- **지투**: 외부 고객 1호 전담 겸 Carvit PO, UX 가이드 수정 주인. 구현은 노트에게 넘긴다. 역할 노트는 비공개 새김 저장소에 있다.
- **노트**: 다른 페르소나가 넘긴 전문 개발 구현. [빈 곳] 지투가 PO라는 것과 PR 검토 주체가 노트 쪽 문서에 없다(노트 회신 대기).
- **페이브**: 판정과 지시서 뼈대. [모델_라우팅.md](모델_라우팅.md)
- **시안**: [빈 곳] 역할노트와 업무대장이 없다.
- **비즈**: [빈 곳] 구글 VIDS 영상 담당이라는 메모 외에 저장소 문서 근거가 없다.

## 실행·검증 엔진

- **헤르메스(신솔라·구솔라)**: 실행·관측·재시도, 초안까지. 판정 금지(CLAUDE#5e1a). 라우팅 정본은 [AI_ROUTING_POLICY.md](AI_ROUTING_POLICY.md), 작업 카드는 [.hermes/task_cards/README.md](../.hermes/task_cards/README.md).
- **타미(헤르메스 주니어)**: 감시 붉은 항목 1차 진단, 실측, 탐이 준 일의 소유. 탐에게만 보고한다. 권한은 PR까지(병합은 탐, 크론·감시 대장은 탐과 같은 선, 사장님 결정 2026-10-02). 문서는 비공개 저장소 `hermes-juniors`에 있다.
- **비티**: 소환형 독립 2차 검증. 큐는 탐이 채우고 채택·반려도 탐이 한다. 호출 방법은 [processes/비티_상시루프.md](processes/비티_상시루프.md).
- **덱스**: 탐이나 노트가 지시서를 준 격리 워크트리 안에서 테스트 실패를 고치는 패치 작성자. 내놓는 것은 diff와 테스트 종료 코드뿐이다. 영입 전 단계. [역할노트-덱스.md](역할노트-덱스.md), [덱스_영입_준비.md](덱스_영입_준비.md) (PR #1527)
