# 퍼스널 브랜딩 가이드 — 한성희 (마야, CMO)

> 왜 있나: `docs/브랜딩_가이드.md`는 **Simplifier가 무엇을 파는지**(서비스)를 다룬다.
> 이 문서는 **한성희가 어떤 사람인지**(캐릭터·자기 노출·화법 습관)를 다룬다. 개인
> SNS 계정(링크드인 등)에 새로 쓰는 글, 재유통 캡션의 말투가 이 문서를 본다 — 서비스
> 소개나 강연 페이지 같은 "회사 언어"는 여전히 브랜딩_가이드.md를 본다. 새로 지어내지
> 않고 이미 발행된 587편(특히 심플리파이어 라이프·기획일상·잉크드인대 기획학과)에서
> 반복되는 패턴을 재료로 정리했다.

## 1. 캐릭터

- **가르치길 좋아하는 사람** — "그럴 때 제가 설명을 드리는 내용입니다"(CPO 글 도입부)
  처럼, 질문을 받으면 설명하고 싶어하는 게 기본 태도다. 잘난 척이 아니라 티칭 본능.
- **실패를 먼저 꺼낸다** — 홈페이지 원점 서사가 성공담이 아니라 "2001년 첫 회사에서
  수익화 모델을 끝내 찾지 못해 동료들을 떠나보내야 했던 날"로 시작한다. 자기 노출은
  성공보다 실패·반성에서 먼저 열린다.
- **형식으로 노는 걸 겁내지 않는다** — 웹툰 형식을 두 번, 그것도 짧게 끝내지 않고
  써봤다. **"코치S"**(17편, 2024-04~08 약 4개월 연재 — 더 오래, 더 본격적으로 끌고
  간 쪽)와 "잉크드인대 기획학과"(8편, 2024-02~03 약 1개월, 말장난스러운 이름)가
  같은 시기 공존한다. 진지한 프레임워크 글과 이런 만화 시리즈가 나란히 있다 —
  하나의 톤·형식에 갇혀 있지 않다.

## 2. 자기 노출 수준

- **여는 것**: 실패·감정·구체적 규모("50→1,000명")로 말하는 경험담, 일상 관찰
  (영화·책 감상 등 "심플리파이어 라이프" 117편이 이미 이걸 하고 있다).
- **닫는 것**: 진행 중인 계약·고객사 실명·수익 수치 — CLAUDE.md의 "사업 정보는 공개
  저장소에 안 쓴다" 원칙과 같은 선. 개인 브랜드도 이 경계 안에서 움직인다.
- 기준: **"교훈이 남는 실패"까지는 개인 브랜드, "진행 중인 사업 정보"는 아니다.**

## 3. 화법 습관 (브랜딩_가이드.md 5절에서 이관)

- **질문형 진입** — 제목·도입이 "~할까요?", "~인가요?"로 시작해 실제로 받았던 질문을
  그대로 옮겨놓는다.
- **왜 → 무엇 → 어떻게 → 반성**(ps1·ps2) 구조 — 마지막에 한 번 더 정리하거나 실행
  환경까지 짚는 postscript로 끝나는 게 시그니처. 짧은 SNS 글에선 이 구조를 다 못
  넣지만, "반성 한 줄"만은 살릴 수 있다(SNS_라이팅_가이드.md 참고).
- **경력을 앞세우지 않고 증거로만 쓴다** — "제가 25년 했으니까"가 아니라 "요기요에서
  50→1,000명 겪어보니"처럼 구체적 규모·사례로 말한다.
- **조언이 아니라 같이 겪은 사람의 말투** — "~하세요"보다 "~하다 보니 이렇게
  되더라고요".

## 4. "저는" vs "Simplifier는" — 언제 어느 쪽으로 말하나

| 상황 | 주어 | 참고 문서 |
|---|---|---|
| 개인 SNS 계정 신규 글, 재유통 캡션 | "저는"(한성희 1인칭) | 이 문서 |
| 서비스 소개, 강연 소개 페이지 | "Simplifier는" | `브랜딩_가이드.md` |
| ask.html 챗봇 답변 | 질문 성격에 따라 혼용 — "한성희는 누구인가" 류는 이 문서, "서비스는 뭘 하나" 류는 브랜딩_가이드.md | 둘 다(내용만, 형식은 UX_GUIDE.md) |

## 지금 하지 말 것

- **성공담만 골라 쓰기** — 이 캐릭터의 신뢰는 실패를 먼저 꺼내는 데서 온다. 성공만
  나열하면 다른 "스타트업 코치" 콘텐츠와 구분이 안 된다.
- **모든 SNS 글에 웹툰·시리즈 포맷을 강제하기** — "형식으로 노는" 건 캐릭터 특성이지
  의무가 아니다. 매번 새 포맷을 만들면 재유통(원문 인용) 원칙과 충돌한다.
- **회사 언어와 개인 언어를 같은 문서로 관리하기** — 이번에 나눈 이유 그대로, 다시
  합치지 않는다.
