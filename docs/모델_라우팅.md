# 모델 고르기: 세션과 서브에이전트 <!-- id: 5e1a -->

기준은 토큰 단가가 아니라 **실수했을 때 되돌리는 비용**입니다. 단가는
하이쿠 4.5 $1/$5, 소넷 5 $2/$10, 오퍼스 5 $5/$25, 페이블 5.1 $10/$50
(입력/출력 100만 토큰당)이지만, 이 회사 비용을 키우는 건 등급보다 세션
길이입니다([세션_운영_실측.md](세션_운영_실측.md)의 실측 감사). 등급을 낮출수록 안전은 모델이 아니라 **지시서**
(읽기 전용 범위, 멈춤 조건)가 지켜야 합니다. 지시서 없는 작업은 등급이
아니라 지시서부터 만드세요.

**세션(페르소나) 모델**: 사장님이 세션 만들 때 고릅니다.
- 기본 **소넷**: 코드 수정, 문서 초안, 진행상황.md 갱신, 카탈로그 구축.
  PR과 build-check가 안전망이라 틀려도 되돌립니다.
- **페이블**: 되돌리기 어려운 실행(사장님 PC 파일 이동·분류, 노출 승격,
  계정·구조 변경)과 여러 문서를 종합하는 판단(조직 재편, 인수인계
  교통정리, 원인 조사). 탐 허브 세션이 주로 여기.
- **하이쿠**: 정해진 스크립트를 돌리고 표만 만드는 읽기 전용 진단
  (예: 로컬핏 Phase 1 브리프).

**서브에이전트 모델** (`Agent` 도구의 `model`, 부모 세션이 고릅니다):
원칙은 "수집·초안은 서브에이전트, 최종 판단은 부모 세션". 부모보다 높은
등급을 서브에이전트에 줄 일은 거의 없습니다.
- **하이쿠**: 파일 여러 개 훑고 요약, 검색, 목록 수집(Explore 유형),
  스크립트 실행. 빠르고 싸며 결과를 부모가 다시 보므로 틀려도 됩니다.
  **리서치·자료수집(웹 조사, 문서 발췌, 출처 목록 만들기)은 하이쿠가
  기본입니다.** 출처의 신뢰도 판별이나 요약에 판단이 섞이면 소넷까지.
  오퍼스·페이블은 수집에 쓰지 않습니다. `create_session`으로 띄우는 보조
  세션도 같은 기준. 판단은 부모 세션이 원문 인용을 보고 합니다
  (2026-09-13 사장님 지시. 그날 페이브가 리서치 3갈래를 전부 소넷으로
  돌린 것이 계기).
- **소넷**: 병렬 구현, 문서 초안, 테스트 작성 등 산출물을 만드는
  일반 작업. 서브에이전트 기본값.
- **오퍼스**: 판단이 섞인 리뷰(코드 리뷰, 설계 검토)와 페르소나
  시뮬레이션 토론처럼 관점을 종합해야 하는 것.
- **페이블**: 서브에이전트로는 쓰지 않습니다. 그 판단은 부모 세션 몫.

**검토 단계 서브에이전트 필수 + 상위 모델 사전 컨펌 (2026-09-15 사장님 지시,
전체 페르소나·세션 필수)**:
- 작업 중 검토·확인(코드 리뷰, 결과 검증, 리서치 정리, 초안·표 만들기 등)
  단계마다 본 세션이 직접 다 처리하지 말고, 위 기준에 맞는 토큰 최적화
  서브에이전트(하이쿠·소넷·오퍼스 중 작업 성격에 맞는 등급)를 우선
  활용한다. 페르소나 세션은 판정과 지시서 뼈대만 직접 한다. 페이브뿐 아니라
  탐·마야·시안·노트·핏 전원 예외 없음. 세션이 혼자 다 하면 컨텍스트가
  커져서 이후 모든 호출이 비싸진다([세션_운영_실측.md](세션_운영_실측.md)의 실측 감사).
- **페이블을 생각 없이 서브에이전트·검토 단계에 쓰지 않는다.** 단가가 가장
  높고(위 표), 서브에이전트로는 원칙적으로 쓰지 않는 등급이다.
- 자기 세션 등급보다 높은 모델(오퍼스·페이블)이 꼭 필요한 예외 상황이면
  **먼저 사장님 컨펌을 받은 뒤에만** 쓴다(어느 단계에 왜 필요한지 한 줄로
  물어본다). 임의 격상 금지.
- 계기: 2026-09-15 페이브 세션이 ep09 전면 재검토를 혼자 진행하다 사장님이
  중단시킴.

**페이브 기본 지침 (2026-09-13 사장님 지시)**: 페이브(페이블) 세션은
판정(통과/반려, 갈림길)과 지시서 뼈대만 직접 하고, 오퍼스·소넷·하이쿠가
해도 효과적인 일은 **하위 세션을 열어 맡기는 것이 기본값**이다. 수집·
리서치·표 만들기는 하이쿠, 지시서 손질·아티팩트 재발행·핏 📤 형식 확인은
소넷, 리뷰·페르소나 시뮬레이션은 오퍼스(`Agent` 서브에이전트 또는
`create_session` 보조 세션). 근거: 2026-09-13 페이브 세션 실측 $24.3(작업
단위 3개, 캐시 재전송이 비용의 2/3, 소넷 환산 약 $5). 뒤집을 신호는 아래와
같다(하위 세션 산출물이 재작업으로 두 번 이어지면 그 유형을 페이블로).

**뒤집을 신호**: 소넷 세션 산출물이 재작업(PR 되돌림, 사장님 재지시)으로
두 번 이상 이어지면 그 작업 유형을 페이블로 올립니다. 페이블 세션이 단순
실행만 하고 끝나는 게 반복되면 내립니다. 이건 경험칙이지 정책 인프라가
아닙니다. 자동 라우팅·모델 등급 정책은 [문서_다이어트_기준.md](문서_다이어트_기준.md)의 "다음 단계 신호"가 올 때.
