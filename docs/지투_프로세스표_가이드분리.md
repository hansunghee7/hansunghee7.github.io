4. **노트 PR 검토·병합**: [지투_프로세스표_노트PR검토.md](지투_프로세스표_노트PR검토.md) 순서. 지투가 같이 정하는 것: 치환 방침(다른 표면 이름 말은 고친다, 없는 절 번호 참조는 번호만 지운다), 홈 판에서 뺄 절(1.17·1.27·1.29·1.38).
