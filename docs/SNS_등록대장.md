# SNS 등록대장

> 무엇이 어느 채널에 발행됐고, 무엇이 예약 중이고, 무엇이 막혔는지 한 표로 관리한다(2026-09-24 사장님 지시). 정본은 이 표다. AItoEarn 자체 대시보드에도 기록이 남지만, 마야가 직접 관리하는 곳은 여기다.

> ⚠️ **이 프로젝트(SNS 등록 자동화)의 KPI는 "사장님이 손 하나도 안 대는 등록 프로세스"다**(2026-09-24 사장님 원문: "이 프로젝트의 목표는 최초에 밝혔듯이 사장 손이 하나도 안 타는 등록프로세스를 만드는게 마야의 KPI입니다"). 어딘가 막혀서 "사장님이 대신 클릭해 주세요"로 넘기면 그 순간 기존 스튜디오 멀티퍼블리싱(복붙 도구)과 다를 게 없어져서 이 프로젝트를 할 이유가 사라진다. 막히면 사장님께 대신 시키지 말고 다른 실행 경로(헤르메스 위임 등)부터 찾는다.
