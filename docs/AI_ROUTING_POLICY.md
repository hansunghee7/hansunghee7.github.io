## 3. 폴백·승격 규칙
1. **4090 실패**(응답 없음, 형식 위반, 오류) → 헤르메스 → 하이쿠. 로컬 결과의 판정은 하지 않는다.
2. **헤르메스 웹 조사 부족**(인용 불일치, 결과 파일 없음, 하루 한도 소진) → 소넷 서브에이전트 수집 → 그래도 부족하면 제미나이 딥리서치.
3. **하이쿠 부족**(요약이 근거를 빼먹음, 원인을 놓침) → 소넷. 이번 세션 실측: 하이쿠 진단이 2차 원인을 놓쳐 부모가 이어 확인함(표본 1건).
4. **소넷으로 해결 안 됨**(2회 반려) → Claude 본 세션. 오퍼스·페이블은 사장님 컨펌 뒤에만.
5. **승격 신호는 결과로 판단**한다: 원문 표본 대조 실패, 형식 위반, 같은 실패 재발. 처음부터 상위 모델을 쓰는 것은 되돌리기 어려운 일과 판정에 한정한다.
6. 모든 무료·로컬 결과는 원문과 함께 보존하고 채택은 부모가 원문 표본으로 확인한다.

## 4. P0 (이번에 적용)
1. **웹 조사·수집을 Claude 본 세션이 직접 하지 않는다.** 로그 기준 WebSearch·WebFetch 결과 566건, 브라우저 조작 4,560호출(도구 결과의 52%)이 본 세션 또는 소넷 서브에이전트에서 나갔다. 수집은 `collector`(하이쿠)나 헤르메스, 화면 조작은 서브에이전트가 한다. 적용: 이 문서 + CLAUDE.md 링크 1줄.
2. **읽기 전용 탐색·큰 파일 훑기는 `explorer`(하이쿠)에 맡긴다.** 서브에이전트 호출의 79%가 소넷이던 것을 하이쿠 기본으로 바꾼다. 적용: 이미 병합된 `explorer` 사용을 이 정책으로 의무화. 효과는 사용 후 측정(측정 대기).

## 5. 백로그
- **P1**: ① 헤르메스 브라우저가 실제로 페이지를 여는지 확인(수집 프로필 창을 닫고 재시도) 후 제미나이 딥리서치 PoC 재개. ② 헤르메스 `delegation`에 로컬 모델 연결 시험(작은 반복 작업 1종으로). ③ 로컬 14B 생성 속도(9.6 tok/s)가 GPU 공유 때문인지 확인(측정만).

## 7. 적용 방법과 측정 (2026-09-21 사장님 지시: 성능은 적용 전과 유사, 토큰은 감소)

- **강제 방식:** 지금은 문서와 공지만. 훅 차단(예: 본 세션의 WebSearch·브라우저 직접 호출 막기)은 **위반이 측정으로 확인될 때** 검토한다.

- **"성능 유사" 기준 제안(탐 작성, 사장님 확정 대기):**

| # | 대표 작업 | 새 경로 | 고정 입력 | 통과 기준(옛 경로와 비교) |
