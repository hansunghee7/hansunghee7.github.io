
## 7. 외부 고사용자 사례 반영 (사장님 제공 2026-09-21)
목표: **비슷한 성능(같은 업무량, 원문 표본 검수 통과)을 유지하면서 Claude 사용량을 줄인다.** 아래 사례는 외부 경험이라 **이 환경에서 1회 시험을 통과해야** 위 2절 표의 기본 경로로 올린다(시험 전은 [미검증]). 이미 2절에 있는 것은 중복하지 않는다.

| 사례 항목 | 우리 환경 반영 | 상태 |
|---|---|---|
| 결정론 작업 → 스크립트·훅 | 2절 첫 행과 같음 | [커스텀] 적용 중 |
| 대량 검색·분류, 로그·문서 요약 → 4090 | 2절 둘째 행. 분류·요약 초안만, 판정 금지 | 품질 표본 1건, 시험 세트 필요 |
| 일반 웹 검색 → 헤르메스 | 2절 웹 조사 행(`collector` 또는 헤르메스 + 코드 대조) | 헤르메스 웹 조사는 신뢰 낮음(0/16), 대조 필수 |
| 대량 웹 조사 → 헤르메스 `execute_code`(중간 결과를 컨텍스트에 안 넣는 패턴) | P1 시험: 지원사업 수집 1건에 적용해 결과 파일과 코드 대조로 확인 | [공식] 패턴, 이 환경 [미검증] |
| 병렬 웹 리서치 → 헤르메스 delegation, 종합은 본 세션 | P1 시험: 독립 주제 2~3개로 1회. 이 환경에는 delegation 설정이 없어 먼저 설정 필요 | [공식], [미설정] |
| 조사 결과 종합 → 헤르메스 서브에이전트 | **초안 종합만** 맡긴다. 채택·판정은 부모(우리 확정 규칙: 무료 엔진 판정 금지) | [미검증] |
| 고급 최신 조사 → 헤르메스 → 제미나이 웹 딥리서치 | 2절 장시간 조사 행 | [커스텀], PoC 대기 |
| 알려진 범위의 간단한 수정 → 하이쿠 또는 4090 | 조건: 변경 범위가 명확하고, 위험이 낮고, **테스트나 스크립트로 검증 가능**할 때만. 실패하면 소넷 | 시험 1건 필요 |
| 병렬 독립 작업 → 헤르메스 delegation | 2절 병렬 행과 동일 조건 | [미검증] |
| Agent Teams | **예외로만**(독립 병렬 Claude 추론이 꼭 필요할 때, 사장님 컨펌). 일상 라우팅에서 제외 | 기본 금지 유지 |

**적용 순서(최소 범위)**: ① 2절·3절과 P0(웹 수집·탐색을 하이쿠로, 화면 조작은 서브에이전트로)를 즉시 적용한다. ② 위 표에서 "시험 필요"인 것은 한 번에 하나씩 P1으로 시험하고, 통과한 것만 2절로 올린다. ③ 효과 판단은 새 세션 시작값 기록과 다음 주 A/B로 한다(캐시 읽기·컨텍스트·도구 정의 감소를 주간 사용량 감소와 같다고 보지 않는다).
