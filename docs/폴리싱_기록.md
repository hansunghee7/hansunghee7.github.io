# CLAUDE.md 폴리싱 기록

> 사장님 결정(2026-09-20): CLAUDE.md는 **상한 250줄**(CI가 초과 PR을 막음), **목표 200줄 이하**는 **격주 폴리싱**으로 지킨다. 폴리싱이 실제로 도는지는 감시가 이 파일의 마지막 수정일로 확인한다(**14일**이 지나면 🔴 알림). 그래서 폴리싱을 하면 **반드시 아래 표에 한 줄을 추가하고 커밋**한다(그 커밋이 "폴리싱 완료" 표시다).

## 절차
1. `python scripts/golden_test_claude_md.py`로 기준선을 잡는다(정적 시험, 토큰 0).
2. `<!-- 임시 날짜 -->`가 붙은 줄을 먼저 스킬, rule, docs로 옮기거나 지운다. 급한 규칙은 원래 진행상황.md 맨 위 `📢 전체 공지`에 먼저 쓰고 폴리싱 때 자리를 정한다.
3. 줄 수가 200을 넘으면 "이 줄을 지우면 실수하는가?"로 절별 KEEP/MOVE를 정한다. 판단이 많으면 서브에이전트에 맡기고 판정만 직접 한다.
4. 정적 시험을 다시 돌린다(규칙 손실이 없어야 함). 구조를 크게 바꿨으면 동적 시험(docs/claude_md_golden_test.md)도 돌린다.
5. 이 표에 한 줄을 추가하고 커밋한다. 커밋 메시지 앞에 `폴리싱:`을 붙인다.
