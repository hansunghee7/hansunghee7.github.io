## 3. 이번에 찾은 라우팅 후보 (본 세션이 하고 있었는데 더 싼 곳으로 갈 수 있는 일)

각 항목: 지금 경로 → 권장 경로 → 상태. 상태가 "실측"이면 10/18에 직접 쟀고, "제안"이면 아직 만들지 않았다(자산으로 치지 않는다, 튜터 원칙 5).

- **컨펌 댓글 점검(30분마다)**: 지금 본 세션 크론이 도구를 9번 불러 닫힌 스레드를 읽었다 → 대기가 0건이면 컨펌 대장 확인 1번만 하고 끝(**절약판 적용, 실측: 호출 9→1**). 더 싸게 하려면 새 세션이나 스크립트로 옮기는데, 막힌 곳이 둘이다. ① 클로드 예약 세션은 첫 Bash 승인에서 멈춘 적이 있다(10/5 시험, `morning_brief.py` 머리말). ② 댓글 읽기 도구가 본 세션 안에서만 부를 수 있어 스크립트로는 못 읽는다 [미검증: claude.ai 댓글을 스크립트로 읽는 길 조사 필요]. 이 둘이 풀릴 때까지는 절약판을 유지하고, 주 경로는 컨펌 버튼 자동 깨우기(첫 겹)다.
- **컨펌 접수 4동작**(대장 reply + 음성 관문 동기화 + 텔레그램 접수 확인 + 스레드 답글·resolve): 지금 본 세션이 따로따로 부른다 → 앞의 셋을 `confirm_ack.py` 한 줄로 묶고 본 세션은 스레드 답글·resolve만 한다. 상태: 제안.
- **현황판 표 만들기**: 지금 명령 여러 개의 출력(수백 줄)을 본 세션이 읽고 표로 다시 쓴다 → 스크립트가 최종 표(롱폼·쇼츠 구분, 컷 있음/필요, 발행 예정)까지 만들어 본 세션은 그대로 보여 주기만 한다. 상태: 제안.
- **음성 품질 측정**(말끝 소리 크기, 원본 대비 목소리 유사도, 받아쓰기): 10/18에 사장님 목소리 3판을 만들며 같은 측정을 즉석 파이썬으로 네 번 손으로 짰다 → `voice_qc.py <조각 폴더> <기준 음성>`으로 도구화한다. 상태: 제안.
- **기록 카드 전문 읽기**: `proc.py show`가 긴 카드의 본문을 잘라 보여 줘 본 세션이 우회로 여러 번 읽었다 → 카드 전문 출력 옵션이 필요하다(탐 영역, 개선 과제로 올림). 상태: 제안.
- **공장 이상 1차 진단**: 지금 본 세션이 로그를 직접 읽는다 → 타미 감시(60분 주기)의 보고서(`C:/work/_ops/tami_watch/report_*.md`)를 먼저 읽고 핏은 "남은 일(핏)" 칸만 본다. 10/18 u0 건은 보고서가 원인의 절반(휴식 규칙)까지 확인했다. 상태: 운영 중, 습관으로 못박기.
- **외부 단가·사실 조사**: 제미나이 API(`gemini_route.py --search`) + 원문 curl 대조로 이미 싸다. 10/18 클라우드 가격 조사에서는 영상 단가만 원문과 대조했고 나머지는 못 해 "확정값 아님"으로 보고했다 → 대조까지 하는 습관을 지키고, 대조 못 한 값은 보고에 표시한다. 상태: 운영 중.

## 4. 규칙으로 못박을 것

- **같은 측정·정리를 손으로 두 번 하면 그 자리에서 도구로 만든다.** 사람이나 상위 모델이 매번 메우지 않는다(핏 역할노트 8절 "도구 결함은 도구를 고친다"와 같은 방향).
- **주기 작업은 살아 있는 본 세션에 묶지 않는 것이 원칙이다**(CLAUDE.md 세션 운영). 단 새 세션 예약이 승인에서 멈추는 문제가 풀리기 전까지 본 세션 크론은 "일이 있을 때만 읽는 절약판"으로만 둔다.
- **라우팅 규칙이 바뀌면 옛 줄에 "대체됨, 현행 위치"를 단다**(cxo-db #488: 최신 지시가 반영되지 않고 옛 방식을 참조한 사고).
- **판정은 본 세션이 한다.** 이 문서의 싼 경로는 수집·측정·실행·초안에 한정한다.

- 하지 않을 것: 컨펌 판정을 무료 엔진에 맡기기, 브라우저 조작을 서브에이전트로 옮기기, Artifact 게시를 스크립트로 우회하기, 새 서비스를 만들어 해결하기(지금 규모에 안 맞는다).
