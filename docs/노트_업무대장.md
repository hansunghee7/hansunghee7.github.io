> 노트가 맡은 할 일 전부를 한 표에 둔다. 방법은 [노트_프로세스표.md](노트_프로세스표.md), 업무 방식 원칙은 [역할노트-노트.md](역할노트-노트.md). **상태는 이 표가 정본이다.** 인수인계 "다음 것"에는 목록을 다시 쓰지 않고 이 표를 가리킨다.
> - 번호: `N<n>`. 우편·세션 메시지·사장님 지시가 오면 착수 전에 여기에 행부터 만든다.
> - 상태(여섯 개만): `대기`(노트 혼자 할 수 있고 아직 안 함) / `진행` / `사장님`(사장님 결정·행동 대기) / `보류`(시작 신호 대기) / `확인필요`(상태를 모름) / `이관`(다른 세션 몫). 끝난 것은 "닫힌 항목"으로 옮긴다(`완료`/`드랍`).
> - **세션 시작 때 할 일 = 상태 `대기`·결정자 `노트`인 행을 위에서부터.**
> - 고객 실명·키 값·호스트명은 쓰지 않는다(공개 저장소). 고객은 "외부 고객 1호", 세부는 비공개 `simplifier-saegim/customers/` 경로로만 가리킨다.
