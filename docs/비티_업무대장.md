# 비티 업무대장

> 비티가 2026-10-03 N112 시험 호출 1회로 직접 쓴 초안이다(탐 판정 반영: 아래 탐 주석). 상태 정본은 탐 업무대장이고, 이 문서의 채택·반려는 탐이 정한다.

> 탐 주석: BT2(Pass 전용 MCP 명세)는 10/10 판정 전이라 보류로 내림. 진행 상한은 탐과 같이 정한다.


### [진행] BT1: 에이전트 셋업 테크리포트(N110) 2차 평가 문항 및 채점 기준안 출제
- 결론: 1차 12문항 및 역효과 2문항 출제에 이어, 실제 세션 대화 기반의 2차 평가 문항과 객관적 채점 기준 초안을 준비한다.
- 다음 행동: 탐이 기본 설정 조(빈 CLAUDE.md) 환경을 확정하면 실무 오류 패턴을 반영한 2차 평가 문항 5개를 작성해 제안한다.

### [보류] BT2: Carvit Pass 세션 카드 효과 분석 및 전용 MCP 아키텍처 초안 검토(N31)
- 결론: 10/10 판정을 위해 세션 카드가 에이전트 실수 방지에 미친 영향을 분석하고, UX 가이드와 분리된 Carvit Pass 전용 MCP 인터페이스 초안을 검토한다.
- 다음 행동: 10/10 실측 데이터(연결정보 요청 수 변화)를 전달받아 Pass MCP의 도구 명세(Tool Spec) 초안을 작성한다.

### [진행] BT3: 일일 백로그 피드백 템플릿 표준화 및 diff 파서 최적화(N112)
- 결론: 1회 호출로 3개 문서를 일괄 생성하는 구조를 유지하며, 전일 대비 변경분만 주입받는 초경량 프롬프트 규격을 정립한다.
- 다음 행동: 10/10 자동화 등록 전까지 회신 분량과 형식 준수율을 점검하고 입력 토큰 절감 스크립트 규격을 탐에게 제안한다.

### [대기] BT4: 구PC 이관 작업 보안 및 장애 격리 구조 검토
- 결론: N105 및 N103에 따라 구PC로 이전된 배치 작업의 토큰 노출 위험과 크론 실패 시 알림 누락 취약점을 독립적으로 점검한다.
- 다음 행동: 탐의 구PC 첫 자동 실행 결과가 공유되면 rclone 및 스크립트 내 키 관리 취약점 점검 체크리스트를 제출한다.

### [보류] BT5: 새김 백업 대책(B50) 3개 안 비용 및 복구 시간 비교
- 결론: 사장님 결정 대기 중인 GCP 만료 대책 3안에 대해 월 유지비용과 장애 복구 시간 관점의 기술 비교표 초안을 준비한다.
- 다음 행동: 사장님의 세팅 방향(멘토링 여부) 확정 신호가 오면 방안별 구체적 마이그레이션 단계 초안을 제시한다.
