# 숏폼 자동화 파이프라인 v2 — 시안(튜터 of CXO / UX) 크리틱

읽은 것: `insight-7b3e9f2c/shorts-automation.html` (2026-09-02, PR #137)
관점: ① 사람이 손대는 4자리의 UX(폰·시트·거울 페이지) ② 이 파이프라인이
회사 KPI(홈페이지 방문)와 어디서 만나는가. 전제: 1인 + AI, S1.

---

## 1. 동의하는 것

- **상태 열 한 칸이 유일한 조종간** — 사장님 개입 방법이 항상 같아서 배울 게
  하나뿐. 진행상황.md에 기록된 "색깔 표시는 기계가 못 읽는다"도 실제로 겪은 일.
- **판단 단순한 일은 API, 창작은 하루 한 번 세션** — 세션 상주 비용($303짜리
  세션 실측)을 이미 치렀으니 근거가 있음.
- **사람은 돈 나가기 직전과 밖으로 나가기 직전** — 관문 위치를 비용 구조로
  정한 것이라 취향이 아니라 원칙. 이미지(싸다)와 영상(비싸다)의 비대칭을 그대로 씀.
- **한 계단씩, 두 계단 동시 금지** — 2026-08-29 노출 사고가 "여러 변경을 한 PR에"
  에서 났음. 같은 교훈.
- **출처 URL 있는 사실만** — ep07 지어낸 숫자 실사례가 근거.
- **시트를 정본, 파일을 공책으로 안 쓰기** — 뒤집을 신호(타인 접근)를 미리 적어둔 점.
- **절대 안 빼는 자리: 주제 픽·업로드** — 취향과 공개 책임은 자동화하면 채널이 죽음.

## 2. 반대하거나 우려되는 것

### 2-1. 파이프라인에 홈페이지가 없다 (가장 큰 것)

17단계 어디에도 simplifier.co.kr이 안 나온다. 릴스 1편이 52,000명을 만나는데
홈페이지는 월 73명이다. 사장님이 오늘 확정한 KPI는 "홈페이지 방문 수"인데,
이 파이프라인은 그 KPI에 0을 기여하는 구조로 설계됐다. 숏폼은 지금 회사가
가진 **유일하게 규모가 있는 유입 엔진**이고, 이걸 홈페이지와 연결하지 않으면
자동화가 잘될수록 홈페이지와 무관한 채널만 커진다.

대안 (3줄, 새 단계 없이):
- **1번 주제 후보의 원료에 기존 블로그 587편을 넣는다.** 성과 탭만이 아니라
  "옛글 중 조회 상위·시그니처 표현 있는 글"을 후보로 올려 숏폼마다 **부모 글**이
  생기게 한다. 새 글을 안 쓰는 지금 재고를 다시 파는 유일한 길.
- **발행 패키지에 부모 글 링크(UTM 포함)를 자동으로 넣는다.** 설명란·고정 댓글.
  `utm_source=instagram&utm_medium=reels&utm_campaign=ep07` 식 규칙은 시안이 정함.
- **17번 성과 기록에 "사이트 세션(UTM)" 한 칸을 더한다.** 조회수와 사이트 방문을
  같은 줄에 두면 "어떤 숏폼이 홈페이지에 사람을 보내는가"가 열 줄이면 보인다.

### 2-2. 발행 패키지(제목·설명·해시태그·고정 댓글)를 만드는 단계가 없다

14 조립 → 15 업스케일 → 16 업로드 사이에 제목·설명·해시태그·썸네일 문구를 누가
만드는지 표에 없다. 지금은 사장님이 업로드하면서 즉석에서 쓰거나 숏감독 세션에
따로 시킨다(ep01 "제목 후보" 기록). 즉 **표의 30분에 안 잡힌 손 시간**이 있고,
2-1의 링크가 들어갈 자리도 없다. 대안: 14번 조립이 끝날 때 PC 세션이 같은 자리에서
`final/ep07_publish.md`(제목 후보 3·설명·해시태그·고정 댓글·부모 글 UTM 링크)를
함께 쓴다. 새 관문이 아니라 16번 업로드에서 **복사해 붙이는 재료**.

### 2-3. 상태 드롭다운 11단어를 사장님 폰에 다 보여주면 오조작이 난다

"사장님이 바꾸는 단어 4개"와 "기계만 켜는 단어 7개"가 같은 드롭다운에 있다. 폰에서
스크롤하다 `영상`을 누르면 기계가 비싼 단계를 시작한다. 대안: 데이터 검증 목록에는
사람 단어 4개 + 되돌리기용 앞 단어만 넣고, 기계 단어는 우편함(스크립트)이 검증을
우회해 쓴다. 시트에선 "선택 불가"가 가장 싼 오조작 방지다.

### 2-4. 5번 대본 확정을 시트 셀에서 하면 10분이 아니라 30분이 된다

폰에서 시트 셀 안의 긴 글을 고치는 UX는 최악이다. 리서치 보고서는 이미 드라이브
구글 문서로 저장한다(3번). 대본 초안도 **구글 문서**로 쓰고 시트에는 링크와 상태만
둔다. 문서 앱은 폰 편집·댓글·버전이 공짜로 따라온다. 거울 페이지 "검토 모드"를
따로 만들 이유가 사라진다(계단 2 축소, 아래 3번 표 참고).

### 2-5. "출처 URL 있음"은 검증이 아니다

ep07 사고의 본질은 "숫자를 지어냄"이고, URL은 지어내기 더 쉽다. 4번 아침 세션이
**URL을 실제로 열어 그 숫자가 본문에 있는지 확인**하고, 못 찾으면 대본에 `[미확인]`
표시를 남기는 한 줄을 더한다. 웹 페치 한 번이라 비용이 거의 없고, 5번에서 사장님이
볼 곳이 "표시된 줄"로 좁혀진다.

### 2-6. 15번 업스케일이 사람 자리인 건 원칙 2와 모순

"돈 나가기 직전도, 밖으로 나가기 직전도" 아닌 순수 기계 작업이다. Video2X는
명령줄로 돌고 PC 세션이 14번 직후 이어서 하면 된다. 문서가 "지금은 안 함"이라고
한 이유가 안 적혀 있다 — 이유가 있으면 적고, 없으면 계단 6에 넣는다.

### 2-7. 0·17번 성과 기록을 손으로 하는 건 이미 있는 것과 중복

`content-insight.html`이 크롬 확장으로 인스타·틱톡 게시물 성과를 이미 모은다
(탐, PR #119~126). 시트에 손으로 다시 적으면 두 곳이 어긋난다. 마야에게 중복
확인을 맡긴 건 맞고, 시안 의견은 "시트 성과 탭은 그 JSON에서 채우는 파생본"으로
못 박는 것. 사람이 적는 건 사이트 세션(UTM) 한 칸뿐이면 된다.

## 3. 시안 관점의 최선안 — 17단계 표에서 바꿀 줄

| 번호 | 지금 → 제안 |
|---|---|
| 1번 | 원료 "성과 탭 + 기존 후보" → **"성과 탭 + 기존 후보 + 블로그 587편(조회 상위·미숏폼화)"**. 후보 줄에 `부모 글 URL` 열 추가 |
| 4번 | 어떻게 "출처 있는 사실만 사용" → **"출처 URL을 열어 숫자 확인, 미확인은 `[미확인]` 표시"**. 나오는 것에 **구글 문서(대본)** 추가, 시트엔 링크 |
| 5번 | 어떻게 "읽고 고치고 상태 바꾸기" → **"구글 문서에서 `[미확인]` 표시 줄 위주로 고치고, 시트 상태만 `대본`으로"** |
| 12번 | 거울 페이지 3모드 중 **이미지 모드만** 먼저. 폰 폭에서 씬당 후보를 가로 스와이프, 한 번 탭 = 확정. 드라이브 이미지는 Apps Script가 썸네일 URL로 내려줄 것(권한 "나만" 배포에서 깨지기 쉬움 — 계단 2 통과 기준에 "폰에서 그림이 보인다" 추가) |
| 14번 | 나오는 것 "초벌 영상" → **"초벌 영상 + `final/epNN_publish.md`(제목 후보 3·설명·해시태그·고정 댓글·부모 글 UTM 링크)"** |
| 15번 | 누가 "사장님" → **"자동 (PC), 14번 직후"**. 사람 자리에서 제거 |
| 16번 | 어떻게 "끝까지 보고 올리기" → **"끝까지 보고, publish.md 붙여넣어 올리기"**. 관문 이름을 "확인·업로드"에서 **"공개 확인"**으로 — 제목·설명도 밖으로 나가는 것 |
| 17번 | 성과 탭 → **content-insight JSON에서 자동 채움 + 사람이 적는 건 "사이트 세션(UTM)" 한 칸** |
| 상태 열 | 드롭다운 11단어 → **사람 단어 4개(+되돌리기 앞 단어)만 검증 목록에**, 기계 단어는 스크립트가 씀 |
| 계단 2 | "거울 페이지 3모드" → **"이미지 모드 1개"** (검토는 구글 문서, 영상 모드는 계단 5에서 필요해질 때) |
| 계단 6 | 추가: **업스케일 자동 + publish.md 생성** |

바꾸지 않는 줄: 2, 3, 6, 7, 8, 9, 10, 11, 13. 원칙 다섯 가지도 그대로.

## 4. 사람이 남는 4자리에 대한 의견

| 자리 | 의견 |
|---|---|
| 주제 픽 | **유지.** 단, 고르는 화면에 "부모 글 조회수·시그니처 표현 유무"를 같이 보여주면 취향에 근거가 붙는다 |
| 대본 확정 | **유지, 위치 이동.** 시트 셀 → 구글 문서. 사람이 볼 곳을 `[미확인]` 표시로 좁혀야 10분이 진짜 10분이 된다 |
| 이미지 확정 | **유지, 출구 조건 동의.** 검수 AI 일치율 20장 기준은 좋다. 다만 "일치"의 정의를 먼저 적을 것 — 사장님이 고른 1장이 AI 통과 후보 안에 있으면 일치인지, 순위까지 같아야 하는지 |
| 확인·업로드 | **유지, 범위 확대.** 영상만이 아니라 제목·설명·링크까지 이 관문에서 본다(위 16번) |
| 업스케일 (15) | **빼기.** 기계 작업 |
| 더할 자리 | **없음.** 새 관문을 더하면 편당 30분이 깨진다. 2-1·2-2는 관문이 아니라 기계가 만드는 재료다 |

## 지금 하지 말 것 (시안 관점)

- 거울 페이지 3모드를 한 번에 만들기 — 이미지 모드 하나로 ep07 한 편을 끝내고 판단.
- 시트 성과 탭을 손으로 채우는 습관 만들기 — 두 정본이 되는 순간 둘 다 못 믿는다.
- 숏폼 전용 사이트 페이지·랜딩 만들기 — 부모 글이 이미 있다. 링크만 걸면 된다.
- 검수 AI 일치율을 재기 전에 이미지 확정에서 사람 빼기.
- 홈페이지 GNB·홈 개편을 이 파이프라인 핑계로 같이 하기 — 유입 없이 구조 손보기.
