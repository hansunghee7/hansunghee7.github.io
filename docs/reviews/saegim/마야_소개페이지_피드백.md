# 새김 소개 페이지 — 마야(CMO 튜터) 피드백

> 대상: 탐이 만든 새김(saegim) 소개 아티팩트
> (https://claude.ai/code/artifact/42058292-0765-46c4-9253-5f6d7ee76297)
> 요청: 사장님이 카피·타겟·포지셔닝·CTA 관점 의견을 요청, 탐에게 전달 예정.

## 총평

정직한 증빙 방식(부풀리지 않은 인용 리포트 5건, 실제 발견·수정한 버그 3건 노출)과
"디자이너가 사라지는 게 아니다" 포지셔닝은 브랜드 화법과 잘 맞고 유지할 만하다.
아래 네 항목은 실제로 외부 발송하기 전에 정리가 필요한 지점.

## 카피

서브카피("AI가 만든다 + 사람은 완성품만 검수 + 안 쓰이는 규칙은 자동 정리")가 세 주장을
한 문장에 압축해 첫 스캔에서 핵심이 안 읽힌다. 진짜 차별점은 4단계 다이어그램의
4번째("가이드가 스스로 정리된다" = 인용 기반 스코어링)인데 서브카피에 묻혀 있다.
→ **이 한 문장을 헤드라인급으로 끌어올릴 것을 제안** — "AI가 만든다"는 이제 차별점이 아님.

## 타겟

"스타트업 파운더"와 "대기업 프로덕트·브랜드 리드"는 셀즈모션이 다른 타겟(셀프서브 vs
엔터프라이즈)인데 같은 카피·같은 증빙으로 한 카드씩만 배치돼 있다. 지금 증빙(1인, 문서
1개, 인용 5건)은 파운더 타겟엔 신뢰가 가지만 대기업 리드가 원하는 건 거버넌스·감사추적·
여러 팀 워크플로 얘기라 지금 카피로는 안 움직인다.
→ **이 페이지를 두 타겟 다 겨냥할지, 파운더 하나로 좁힐지는 사장님이 정할 몫.** 좁힌다면
대기업 카드는 이번 버전에서 빼거나 "다음 단계 예고"로 톤을 낮추는 게 지금 증빙 수준과
더 맞음.

## 포지셔닝

첫 스크린만 보면 "스타일가이드 관리 툴"인지 "AI 디자인 생성 툴"인지 "문서 거버넌스
툴"인지 셋 다처럼 읽힌다. Figma AI·v0·Cursor 같은 익숙한 카테고리와 뭐가 다른지가 안
나와 있어서, "인용 기반 자기 정리"라는 진짜 차별점이 카피 위계에서 너무 아래에 있다.

## CTA

"베타 문의하기"가 유일한 CTA인데 지금 증빙 두께(하루, 문서 1개)에 비해 마찰이 크다.
문의를 실제로 받았을 때 응대 프로세스도 아직 없을 텐데, 지금 단계엔 마찰 낮은 CTA(데모
영상, 대기 명단, 뉴스레터)가 더 맞을 수 있다. 목적지도 문제 — `simplifier.co.kr`은 새김
전용 안내가 없는 일반 홈페이지라, 실제 발송 전에 최소 새김 전용 섹션·폼이 필요하다.
세컨더리 CTA "작동 방식 보기 ↓"는 마찰이 낮아 그대로 두면 됨.
