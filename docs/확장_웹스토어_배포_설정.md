# SNS 확장을 Chrome 웹스토어로 옮기기 (설정 가이드)

> 2026-09-03 결정. 배경: `docs/진행상황.md` 탐 인수인계, cxo-db 인박스 #19 참고.
> 목표: 지금은 코드가 바뀔 때마다 사장님이 zip을 새로 받아 폴더를 통째로
> 교체해야 하는데, 이걸 없애고 크롬이 알아서 최신 버전을 받아가게 만든다.

이 문서는 **사장님이 지금 할 수 있는 부분(Phase 1)**까지만 다룹니다.
Phase 1이 끝나면 저(탐)에게 알려주세요 — 그다음(GitHub Actions 자동 배포)은
실제 계정으로 API를 직접 테스트하면서 제가 이어서 진행합니다.

## Phase 1 — 사장님이 할 일

### A. 확장 폴더를 zip으로 압축하기

1. `hansunghee7.github.io` 저장소를 최신으로 받은 폴더에서 **`_sns-extension`
   폴더 안**으로 들어가세요 (폴더 자체가 아니라 그 **안**입니다 — 중요).
2. 안에 있는 파일들(`manifest.json`, `background.js` 등)을 **전부 선택**한
   다음 압축(zip)하세요.
   - Windows: 전체 선택(Ctrl+A) → 우클릭 → "압축(ZIP) 폴더로 보내기"
   - Mac: 전체 선택(Cmd+A) → 우클릭 → "N개 항목 압축"
   - ⚠️ `_sns-extension` 폴더 자체를 통째로 압축하면 안 됩니다. 압축 파일을
     열었을 때 바로 `manifest.json`이 보여야 합니다 (폴더 한 겹 감싸여
     있으면 안 됨) — 크롬 웹스토어가 이 형식만 받습니다.

### B. Chrome 웹스토어 개발자 등록 (최초 1회, $5)

1. `https://chrome.google.com/webstore/devconsole` 접속 (평소 쓰시는
   구글 계정으로 로그인).
2. 화면 안내에 따라 **개발자 등록**을 진행하고, **$5 결제**를 완료하세요
   (카드 정보 필요). 등록은 한 번만 하면 다음부터 다시 안 해도 됩니다.

### C. 첫 업로드 (수동)

1. 개발자 대시보드에서 **"새 항목"**(New Item) 버튼을 누르세요.
2. A에서 만든 zip 파일을 업로드하세요.
3. 스토어 등록정보 화면에서 최소한으로 채우면 됩니다(설명은
   `manifest.json`의 description을 그대로 써도 됩니다). 아이콘은 이미
   `_sns-extension/icons/`에 있는 걸 씁니다.
4. **"게시 형태" 또는 "공개 상태"(Visibility) 설정에서 "미등록(Unlisted)"을
   선택하세요.** "공개(Public)"로 두면 검색에 노출됩니다 — 미등록이어야
   링크를 아는 사람만 설치할 수 있습니다.
5. 저장하고 **게시(Publish)**를 누르세요. (미등록 항목은 보통 검수가 빠르거나
   즉시 반영되지만, 며칠 걸릴 수도 있습니다 — 안 되면 잠시 기다렸다 확인.)
6. 게시가 완료되면 대시보드에 **항목(확장) ID**가 보입니다(URL이나 항목
   상세에 긴 영문/숫자 문자열로 표시됩니다). **이 ID를 저에게 전달해주세요.**

### D. Google Cloud 프로젝트 준비 (다음 단계용)

이 부분은 제가 나중에 자동 배포를 만들 때 쓸 열쇠를 준비하는 단계입니다.
지금 만들어두시면 다음 단계가 빨라집니다.

1. `https://console.cloud.google.com/` 접속 (같은 구글 계정).
2. 화면 위쪽에서 **"프로젝트 만들기"**로 새 프로젝트를 하나 만드세요
   (이름은 자유롭게, 예: `simplifier-sns-ext`).
3. 왼쪽 메뉴 또는 검색창에서 **"API 및 서비스" → "라이브러리"**로 이동해
   **"Chrome Web Store API"**를 검색해서 **사용 설정(Enable)**하세요.
4. **"API 및 서비스" → "사용자 인증 정보(Credentials)"**로 이동해
   **"사용자 인증 정보 만들기" → "OAuth 클라이언트 ID"**를 선택하세요.
   - 동의 화면 설정을 먼저 하라고 나오면, **"외부(External)"**로 만들고
     앱 이름 등 최소 정보만 채우면 됩니다(테스트 사용자에 본인 이메일
     추가).
   - 애플리케이션 유형은 **"데스크톱 앱"**을 선택하세요.
5. 생성되면 **클라이언트 ID**와 **클라이언트 보안 비밀(Client Secret)**이
   보입니다. **이 둘을 저에게 전달해주세요** (비밀번호처럼 다루되, 이
   대화창에 붙여넣는 건 안전합니다 — GitHub Actions Secrets에만 저장하고
   코드에는 안 남깁니다).

## 여기까지 하시면

C의 **항목 ID**, D의 **클라이언트 ID·클라이언트 보안 비밀** 3가지를 저에게
주시면, 이어서 제가:

1. 실제 API로 접근 토큰을 발급받는 절차를 검증하고,
2. GitHub Actions 워크플로를 작성해 앞으로 `_sns-extension` 코드가
   바뀔 때마다 자동으로 웹스토어에 새 버전을 올리도록 만들고,
3. 실제로 한 번 돌려서 검증한 뒤 알려드리겠습니다.

그 뒤로는 **사장님이 확장 파일을 다시 만질 일이 없습니다** — 며칠 안에
크롬이 알아서 최신 버전을 받아갑니다.
