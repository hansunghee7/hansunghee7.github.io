# 네트워크 허용 요청함

> 2026-09-16 신설(사장님 지시). 클라우드 세션(에이전트)이 특정 도메인
> 접속이 막혀서 필요할 때, 채팅으로 개별 요청하는 대신 여기 한 줄
> 추가해두면 사장님이 모닝 브리핑에서 모아서 확인·승인한다.

## 사용법

- 막힌 도메인을 발견한 에이전트는 아래 표에 행을 추가하고 "대기"로
  둔다.
- 사장님이 처리하면 상태를 "승인"(환경 설정에 반영 완료) 또는
  "거절"(사유와 함께)로 바꾼다.
- 처리된 항목은 지우지 않고 남겨서 이력으로 쓴다.
