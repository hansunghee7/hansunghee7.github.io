# 홈페이지에서 글쓰기 — 로그인 연결하기

`/admin/`에서 브라우저로 바로 글을 쓰려면, GitHub한테 "이 사람이 진짜
사장님 맞다"는 걸 확인시켜주는 절차가 한 번 필요합니다. 복잡한 부분은
전부 제가 처리하고, 사장님이 하실 일은 아래 **1단계**와 **3단계** 두
가지뿐입니다. 각각 3분 정도 걸립니다.

## 1단계 (사장님이 하실 일)

Cloudflare에서 열쇠(토큰)를 하나 발급받아서 저한테 주세요.

1. 이 주소로 들어가서 가입하세요 (신용카드 필요 없음): https://dash.cloudflare.com/sign-up
2. 로그인 후, 화면 오른쪽 위 프로필 아이콘을 누르고 "My Profile"을 클릭하세요.
3. 왼쪽 메뉴에서 "API Tokens"를 클릭하세요.
4. "Create Token" 버튼을 누르세요.
5. 목록에서 이름에 "Workers"가 들어간 항목을 찾아 "Use template"을 누르세요.
6. 그대로 아래로 내려가서 "Continue to summary" → "Create Token"을 누르세요.
7. 화면에 뜨는 긴 문자열이 열쇠입니다. **이 화면을 벗어나면 다시 못 보니,
   지금 바로 복사해서 저한테 주세요.**

이 열쇠는 이 로그인 서버 하나만 만들 수 있는 제한된 권한이라 안전합니다.
다 쓰고 나면 같은 화면에서 언제든 삭제할 수 있습니다.

## 2단계 (저)

받은 열쇠로 로그인 중계 서버를 만듭니다. 사장님이 하실 일은 없습니다.
완료되면 서버 주소를 알려드릴게요.

## 3단계 (사장님이 하실 일)

2단계에서 받은 서버 주소로 GitHub에 출입증을 하나 만들어서 저한테 주세요.
(2단계 완료 후에 진행해주세요.)

1. 이 주소로 들어가세요: https://github.com/settings/developers
2. "New OAuth App" 버튼을 누르세요.
3. 아래 칸을 채우세요.
   - Application name: 아무 이름이나 괜찮습니다. 예: Simplifier Log
   - Homepage URL: 제가 드린 서버 주소를 그대로 넣으세요 (홈페이지 주소가 아닙니다)
   - Authorization callback URL: 서버 주소 뒤에 /callback을 붙여서 넣으세요
4. "Register application" 버튼을 누르세요.
5. 화면에 뜨는 Client ID를 복사해서 저한테 주세요.
6. "Generate a new client secret" 버튼을 누르면 Client Secret이 한 번
   나타납니다. **이것도 화면을 벗어나면 다시 못 보니 바로 복사해서
   저한테 주세요.**

## 4단계 (저)

받은 값들을 서버에 등록하고, 홈페이지 설정을 마무리해서 커밋·푸시까지
합니다. 다 되면 말씀드릴게요.

## 5단계 (사장님이 하실 일)

1. https://simplifier.co.kr/admin-legacy/ 접속
   (평소 쓰시는 주소는 https://simplifier.co.kr/admin/ 입니다.
   이 문서는 그게 문제 생겼을 때 쓰는 예전 화면 안내입니다.)
2. "Login with GitHub" 버튼 클릭
3. 로그인 창이 뜨면 로그인 후 "Authorize" 클릭
4. 글쓰기 화면이 뜨면 성공입니다.

## 막히면

어느 단계에서든 화면이 설명과 다르거나 뭘 눌러야 할지 모르겠으면, 지금
보이는 화면을 그대로 캡처해서 저한테 보여주세요. 다음에 뭘 누르면 되는지
알려드리겠습니다.

- 가입할 때 회사 정보나 결제를 물어보면: 그 화면을 캡처해서 보여주세요.
- GitHub이 휴대폰 인증 등을 요구하면: 정상입니다. 안내대로 진행하시면 됩니다.
- 복사해야 할 값을 놓치고 화면을 닫아버렸으면: 그 단계로 다시 들어가서
  새로 만들면 됩니다. 말씀해주시면 다시 안내해드릴게요.

## 참고 — 이건 지금 안 만들었습니다

- 링크드인/페이스북/인스타그램/스레드 자동 발행: 로그인 연결이 끝나고
  실제로 글을 한 번 써서 잘 되는 걸 확인한 다음에 만드는 게 안전합니다.
- 브런치/네이버블로그/리멤버 커넥트/로켓펀치: 자동 발행 통로가 없어서,
  글쓰기 화면의 "수동 발행 채널용 복사 텍스트" 칸에 써둔 내용을 그대로
  복사해서 직접 올리시면 됩니다.
