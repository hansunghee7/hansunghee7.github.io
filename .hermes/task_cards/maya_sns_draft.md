# 카드: 홈페이지 글에서 SNS 채널별 초안 문장 만들기

> 상태: **정식(Active, 검증기 통과 기준)**. 2026-09-30 실측 통과, 탐이 정리. 마야의 초안 검토 회신이 오면 한도·검증 규칙을 조정한다. 실행: `python scripts/ops/delegate_sns_draft.py <글 번호>`.

- 호출자: 마야
- Tier: Local (왜: 발행 전 미공개 원고가 입력이라 장비 밖으로 나가면 안 됨)
- 입력: 홈페이지 글 markdown 1편(`log_assets/markdown/`, 4000자 이하)과 채널 목록(링크드인·페이스북·인스타·스레드)
- 출력: 채널별 초안 텍스트 JSON(`channel`, `text`). 스키마 고정, 채널 4개 이외 키 금지
- 검증기: 코드가 판정하는 것만. 채널별 글자수 한도(링크드인 1500·페이스북 1000·인스타 1500·스레드 500, 마야가 조정), 괄호 없음, 긴 줄표 없음, 글 URL 포함과 다른 URL 없음, 원문에 없는 숫자 금지, 채널끼리 같은 초안 금지(1회 실측 후 추가). 문장 품질·톤은 검증기가 없어 "초안 전용"
- 호출자의 최종 판단: 마야가 초안을 읽고 고친 뒤 사장님 승인을 받는다. 엔진 출력은 `sns_queue_draft.py`의 status=draft 항목 옆에 두는 제안일 뿐이며, 승인 전에는 큐에 못 들어간다(publish 스크립트가 `approved_by` 없는 항목을 무시)
- 실패하면: 검증기 미통과 채널은 제안 없이 거절로 표시하고 마야가 직접 쓴다
- 빈도: 주 2회(월·수 글 후 화·목 SNS)

## 1회 실측 (2026-09-30, 글 629번, `qwen2.5-coder:14b` Local)

- 1차 실행: 4채널 모두 1회차 통과(17.1초, 입력 1481·출력 749토큰). 그러나 페이스북과 인스타 초안이 글자까지 같았다. 검증기가 못 본 결함이라 "채널끼리 같은 초안 금지" 규칙을 추가했다.
- 2차 실행(규칙 추가 후): 3회 시도 끝에 4채널 통과(자율 교정 2회, 13.9초, 입력 4350·출력 1062토큰). 초안 내용은 원문에 있는 용어만 썼다(탐이 예산·이해관계자·모듈·Product Lead 등을 원문에서 대조).
- 한계: 검증기는 "글자까지 같음"만 막아서 링크드인과 페이스북 초안은 여전히 거의 비슷하다. 톤·설득력은 검증기 밖이라 마야의 판단 몫이다. 표본은 글 1편이다.
