# 카드: 새김(Carvit) PR 설명 초안

> 상태: 초안(2026-09-30 노트 제안, 탐 정리). 아직 실행하지 않았다. 첫 실측은 실제 PR 3건으로 한다.

- 호출자: 노트
- Tier: Local (왜: 대상이 비공개 저장소의 코드 diff라 장비 밖으로 나가면 안 됨)
- 입력: PR 하나의 diff 요약(변경 파일 목록과 patch), 800줄 이하. 넘으면 파일 단위로 쪼개 넘김
- 출력: JSON `{title(60자 이하), what(변경 불릿 3~6개), how_to_verify(불릿 1~3개), touched_files(배열)}`, `additionalProperties: false`
- 검증기: 스키마 + `touched_files`가 실제 diff 파일 목록의 부분집합인가 + 제목 길이. 내용의 정확성은 코드가 못 봐서 "초안 전용"
- 호출자의 최종 판단: 노트가 diff와 초안을 나란히 읽고 고쳐서 PR 본문으로 쓴다. 수용 기준과 검증 증거 문장은 노트가 직접 쓰고 엔진 초안에는 쓰지 않는다
- 실패하면: 스키마·검증기 실패 시 초안 없이 실패만 돌려받고 노트가 직접 쓴다
- 빈도: PR을 하루 여러 건 올림(9/26 하루 15건 안팎)
