# 카드: 우편·알림 초안의 고객명 노출 검사와 치환

> 상태: 초안(2026-09-30 지투 제안, 탐 정리). 아직 실행하지 않았다. 남은 협의: 금칙어 목록을 둘 비공개 저장소 경로.

- 호출자: 지투
- Tier: Local (왜: 검사 대상 초안에 고객 실명이 들어 있을 수 있어 문장이 장비 밖으로 나가면 안 됨)
- 입력: 보내기 전 우편·알림 본문 1건, 5천 자 이하
- 출력: 고객명으로 의심되는 구간 목록(원문 구간, 치환 제안 "외부 고객 1호")과 치환된 본문
- 검증기: 코드가 확인한다. (a) 치환본에 금칙어 목록(비공개 저장소의 고객명 목록, 카드에는 쓰지 않음)이 0건 (b) 치환한 곳 말고는 원문과 글자가 같다. 통과 못 하면 결과를 버린다
- 호출자의 최종 판단: 지투가 치환본과 원문의 차이를 읽고 문맥이 어색하지 않은지 본 뒤 발송한다
- 실패하면: 검증 실패 표시와 함께 원문을 그대로 돌려주고 지투가 손으로 치환한다(현행 방식)
- 빈도: 우편·알림을 보낼 때마다(하루 여러 건)

탐의 설계 메모: 금칙어 목록에 있는 이름은 엔진 없이 문자열 치환 스크립트가 더 정확하고 빠르다. 엔진이 더하는 가치는 목록에 없는 변형(호칭, 줄임말, 오타)을 의심 구간으로 찾아내는 것뿐인데, 이 부분은 검증기 (a)가 목록 밖은 못 잡는다. 그래서 실측은 "스크립트 치환 단독"과 "엔진 의심 구간 추가"를 비교해, 엔진이 실제로 놓친 변형을 몇 개 더 찾는지로 정한다.
