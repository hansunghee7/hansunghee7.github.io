# 작업 카드 (Task Card)

헤르메스(공용 고속 실행 엔진)에 일을 맡길 때 쓰는 카드다. **페르소나 문서는 없다.** 카드 하나 = 파일 하나 = 반복 과업 하나.
확정: 2026-09-30 사장님. 설계와 근거: [docs/에이전트_헤르메스_위임_설계.md](../../docs/에이전트_헤르메스_위임_설계.md)

## 규칙

- **Tier 명시는 의무다.** `Local`(RTX 4090 Ollama, 문장이 장비 밖으로 나가지 않음) 또는 `Hosted`(Upstage API, 나감). 고객 정보·미공개 콘텐츠·비공개 저장소 내용은 `Local`만. 애매하면 `Local`.
- **엔진은 제안만 만든다.** 저장소 파일·발행물은 호출자가 결과를 검토한 뒤 직접 적용한다.
- **검증기는 결정적이어야 한다**(코드가 참/거짓을 판정). 검증기를 못 쓰는 과업(문장 품질 등)은 "초안 전용"으로 표시하고 판정은 호출자가 한다.
- 엔진이 낸 결과 봉투는 출력 스키마(`additionalProperties: false`)로 검사한다. 못 지키면 내용은 버리고 실패만 알린다.
- 공개 저장소다. 카드에 고객 실명·키·호스트명·IP를 쓰지 않는다.

## 카드 양식 (복사해서 채운다)

```
# 카드: <과업 이름>
- 호출자: <탐/마야/핏/지투/노트>
- Tier: Local | Hosted   (왜: <한 줄>)
- 입력: <무엇을 넘기는가, 크기 한도>
- 출력: <어떤 모양으로 받는가(스키마 요지)>
- 검증기: <코드가 확인하는 것 / 없으면 "초안 전용">
- 호출자의 최종 판단: <누가 무엇을 보고 적용하는가>
- 실패하면: <엔진이 못 하면 어떻게 되돌아오는가>
- 빈도: <얼마나 자주 하는 일인가>
```
