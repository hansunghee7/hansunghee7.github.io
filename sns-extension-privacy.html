SNS 인사이트 수집기 개인정보처리방침

시행일: 2026-09-03

"SNS 인사이트 수집기"(이하 "이 확장 프로그램")는 심플리파이어(Simplifier)가 내부 운영 목적으로 사용하는 개인용 크롬 확장 프로그램입니다. 일반 사용자 배포용이 아니며, 사용자 본인이 직접 설치해 본인의 브라우저에서만 동작합니다.

수집하는 정보

  • 사용자가 로그인한 상태로 방문한 SNS 프로필 페이지 화면에 표시된 공개 지표(팔로워 수, 게시물 조회수 등)
  • 사용자가 직접 입력한 GitHub 개인 액세스 토큰(수집한 값을 사용자 본인의 GitHub 저장소에 기록하기 위한 인증 정보)

이 확장 프로그램은 이름·이메일·비밀번호 등 개인 식별 정보를 별도로 수집하지 않습니다. 화면에 보이는 숫자(지표)만 읽습니다.

정보의 사용 목적

수집한 지표를 사용자 본인이 지정한 GitHub 저장소에 자동으로 기록하는 용도로만 사용합니다. 그 외 목적(광고, 프로파일링, 분석 등)으로는 사용하지 않습니다.

정보의 저장 위치

  • 브라우저 로컬 저장소(chrome.storage.local) — GitHub 토큰, 최근 수집 기록
  • 사용자 본인이 소유·관리하는 GitHub 저장소 — 수집된 지표 값

이 확장 프로그램을 만든 개발자를 포함해 어떤 외부 서버로도 데이터를 전송하지 않습니다.

제3자 제공

사용자 데이터를 제3자에게 판매, 공유, 전송하지 않습니다. 신용평가나 대출 심사 등 다른 목적으로도 사용하지 않습니다.
