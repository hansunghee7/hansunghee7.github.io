# 저녁 의식 (세션 종료, 개시어 "바이~") <!-- id: 22b0 -->

사장님이 **"바이~"**라고 하면 아래 순서로 마무리하세요. 원칙: **새 파일을
읽지 않습니다** — 이 의식은 컨텍스트가 아직 뜨거울 때 아는 것을 기록하는
절차이지, 조사가 아닙니다. 쓰는 곳은 아침 의식이 읽는 두 곳뿐입니다.

1. **산출물 회수** — 이 세션에서 승인된 산출물이 아티팩트·대화에만 있으면
   지금 저장소로 옮기고 인덱스에 등록 (2026-08-30 유실 사고 재발 방지).
2. **작업 마감** — `git status`로 미커밋 변경 확인, 열린 PR은 병합하거나
   상태를 인수인계에 적기. **push까지 끝나야** 내일 다른 기기 세션이 봅니다.
   - **탐은 종료 때도 `get_usage` 값을 `scripts/ops/pace_log.py`로 한 번 기록한다**(세션 시작 절 참고, 2026-09-22 사장님 지시).
3. **인수인계 3~5줄** — 을 진행상황.md 또는 자기 역할 노트에. **모든
   페르소나가 아래 템플릿을 그대로 씁니다** (`[페르소나]`만 자기 이름으로
   바꿀 것, 해당 없는 칸은 생략):

   ```
   [페르소나] 상태: 🟢정상 / 🟡주시 / 🔴불안정

   한 것: (이번 세션에서 실제로 끝낸 것 — PR 번호·커밋으로)
   막힌 것 / 비정상 상태: (없으면 "없음". 있으면 버린 길과 이유도 같이)

   다음 것:
   * 사장님: (사장님이 직접 손대야 하는 몫만 — 없으면 이 줄 생략)
   * [페르소나](다음 세션): (내일 세션이 첫 지시로 그대로 쓸 문장)

   우선순위 작업 (담당 O, 문서에 이미 합의됐으나 미착수)
   1. ...
   2. ...

   손대지 말 것: (건드리면 위험한 것 — 없으면 이 줄 생략)
   ```

   - "한 것"과 "다음 것"을 섞지 않습니다 — 이미 끝낸 일은 "한 것"에만,
     아직 안 한 일은 "다음 것"/"우선순위 작업"에만.
   - "다음 것"은 **누가 하는지 주체를 반드시 표기**합니다. 사장님이
     직접 손대야 하는 절차(클릭·설정 변경 등, CLAUDE.md 원칙3)와
     클로드 세션이 할 일을 한 줄에 섞지 않습니다.
   - **버린 길**(시도했다 안 된 접근과 이유)은 "막힌 것" 칸에 — 안 적으면
     다음 세션이 같은 막다른 길을 다시 갑니다.
   - 내용 복사 대신 파일 경로·PR 번호·아티팩트 URL 포인터로.
   - 판정 기준: 아무것도 모르는 내일 세션이 이 줄만 보고 이어갈 수 있는가.
4. 되돌리기 어려운 판단·사고가 있었으면 cxo-db 인박스 이슈 (아래 경험DB 절).
   해당 없으면 안 남깁니다.
5. **한 줄 마감 보고** ("한 것 / 내일 볼 것") 후 사장님이 **세션을
   닫습니다(아카이브).** 유휴 세션은 캐시(1시간 수명)가 식어, 다음 재개 때
   전체 컨텍스트를 정가로 재처리합니다.
