# 아침 의식 (세션 시작, 개시어 "하이~") <!-- id: c010 -->

사장님이 **"하이~"**라고 하면 아래 의식을 수행하라는 뜻입니다.

1. **새 세션으로 시작합니다.** 어제 세션을 이어받지 마세요. 시작 때 `get_usage`로 5시간·주간·컨텍스트 잔량을 한 번 보고, 기준선을 넘었으면 [토큰 저잔량 모드](../../../docs/토큰_저잔량_모드.md)로 움직입니다(2026-09-21, 백로그 7). **탐은 이 값을 반드시 기록한다**(2026-09-22 사장님 지시, 사장님 목표: 주간 한도 초기화까지 탐을 쓰는 것): `python scripts/ops/pace_log.py --week <주간%> --five <5시간%> --reset <주간 resetsAt> --ctx <컨텍스트%>`. 출력이 "주의"나 "경고"이면 첫 응답에서 사장님께 페이스와 하루 권장 사용률을 알린다. 기록이 30시간 넘게 없으면 감시 대장이 붉어진다.
1-1. **탐: 자율 착수 규칙(2026-09-22 사장님 지시).** 사장님의 첫 지시가 없으면, 자기 인수인계의 **"탐 단독 진행 큐"**(사장님 결정·할 일이 없는 항목만 있음)를 1번부터 바로 착수한다. 첫 응답에서 "큐 N번을 시작합니다"라고 한 줄 알린다. 사장님이 다른 지시를 주면 그것이 우선이다. 큐에 없는 일, 결정이 필요한 일은 스스로 시작하지 않는다.
2. 읽는 것은 **자기 역할 노트 + 진행상황.md 상단 우선순위**뿐. UX_GUIDE·
   STYLE_GUIDE 같은 가이드는 그 화면을 실제로 만지는 시점에 읽습니다.
   역할 노트 위치: `docs/역할노트-<이름>.md`
3. 저장소는 오늘 쓸 것만 부착합니다 (cxo-db는 기록할 게 생겼을 때 요청).
   **우편함 확인 (2026-09-19 도입)**: solar-bible 저장소가 붙어 있으면 `python mailbox/mailbox.py read <내 이름> --recent 24`로
   최근 24시간 메시지를 먼저 봅니다(다른 세션이 먼저 읽음 처리했어도 놓치지 않도록)(로컬 세션은 시작 훅이 개수를 알려 주고, 클라우드 세션은 `add_repo`로
   `hansunghee7/solar-bible`을 붙입니다). 다른 에이전트에게 알릴 일은 사장님께 복사·붙여넣기를 부탁하지 말고
   `mailbox.py send`로 보냅니다. **`SendMessage`(세션 메시지)로 먼저 보냈어도 같은 내용을 우편함에 한 줄
   남깁니다**(사장님 모니터링 그룹은 우편함만 비춥니다). 규칙: solar-bible `mailbox/README.md`.
4. **첫 응답은 아래 형식 그대로**. 저녁 의식이 남긴 자기 페르소나의 최신
   인수인계 블록(`[페르소나] 상태` ~ `손대지 말 것`)을 진행상황.md에서 찾아
   **요약하지 말고 그대로 출력**하고, 그 아래에 `📢 전체 공지` 확인 결과와
   오늘 첫 지시 후보를 한 줄씩 붙입니다. 사장님은 이 화면으로 어제 마감이
   제대로 저장됐는지를 확인하므로, 한 줄로 압축하면 확인 자체가 안 됩니다
   (2026-09-08 실제 사고: 저녁 의식 템플릿만 고치고 아침 의식은 "한 줄
   보고"로 남겨둬, 다음 날 세션이 규정대로 압축 보고해 사장님이 "저장이
   안 된 것 아니냐"고 원인 조사를 요청함).

   ```
   (진행상황.md의 자기 인수인계 블록 원문 그대로)

   공지 확인: 새로 볼 항목 없음 / [항목명] 봤습니다
   오늘 첫 지시: (인수인계 "다음 것"의 [페르소나](다음 세션) 줄 그대로)
   ```

   자기 페르소나의 인수인계 블록이 없으면 그렇다고 첫 줄에 쓰고, 우선순위
   절만 보고합니다.
