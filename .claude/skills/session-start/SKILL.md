# 아침 의식 (개시어 "하이~") <!-- id: c010 -->

1. **새 세션으로 시작한다.** 어제 세션을 잇지 않는다. `get_usage`로 5시간·주간·컨텍스트를 한 번 본다. 기준선을 넘으면 [토큰 저잔량 모드](../../../docs/토큰_저잔량_모드.md). **탐은 반드시 기록**: `python scripts/ops/pace_log.py --week <주간%> --five <5시간%> --reset <주간 resetsAt> --ctx <컨텍스트%>` (reset은 5시간이 아니라 주간 값). "주의/경고"면 첫 응답에서 페이스와 하루 권장 사용률을 알린다.
2. **세션 시작 카드 `docs/세션카드/<이름>.md`를 먼저 읽는다**(시범 10/3~10/10). 이어서 자기 역할 노트(`docs/역할노트-<이름>.md`)와 진행상황.md 상단 우선순위만 본다. 가이드류는 그 화면을 만질 때 읽는다. 탐·핏은 카드의 `session_brief.py` 한 번이 인수인계·열린 건·문제 줄을 대신한다(업무대장·진행상황.md 전체를 읽지 않는다).
3. **우편함**: `python mailbox/mailbox.py read <내 이름> --recent 24` (solar-bible 부착 시, 로컬은 시작 훅이 개수를 알려 준다). 보낼 때는 `SendMessage`로 먼저 보냈어도 우편함에 한 줄 남긴다(규칙: solar-bible `mailbox/README.md`).
4. **내 이름의 열린 미병합 PR부터 확인**: `gh pr list --search "author:@me" --state open`. CI 통과·충돌 없음이면 병합하고 로컬을 당긴다. 막혀 있으면 이유를 먼저 보고, 그 PR 안 인수인계가 최신일 수 있다. 같은 브랜치에 커밋을 더하기 전에 `gh pr view <번호> --json state`로 MERGED가 아닌지 확인한다.
5. **최신 인수인계 블록은 훅의 커밋 목록에서 찾는다.** 거기서 내 이름이 든 최근 커밋을 골라 `git show <해시> -- docs/진행상황.md`. 없으면 `git log --format='%h %ad %s' --date=format:'%m-%d %H:%M' -30 -- docs/진행상황.md | grep <이름>` 한 번, 그래도 없으면 "없음". 진행상황.md 전체나 아카이브를 열지 않는다.
6. **탐 자율 착수**: 사장님 첫 지시가 없으면 [탐_업무대장.md](../../../docs/탐_업무대장.md)의 상태 `대기`·결정자 `탐` 행을 위에서부터 착수하고 "대장 N번을 시작합니다"를 한 줄 알린다. 우편에서 새 요청을 읽으면 착수 전에 대장에 행부터 만든다. 사장님 지시가 우선, 결정이 필요한 일은 스스로 시작하지 않는다.
7. **첫 응답 형식**(압축 금지, 사장님이 마감 저장 여부를 이 화면으로 확인한다):

   ```
   (자기 인수인계 블록 원문 그대로)

   공지 확인: 새로 볼 항목 없음 / [항목명] 봤습니다
   오늘 첫 지시: (인수인계 "다음 것"의 [페르소나](다음 세션) 줄 그대로)
   ```

   인수인계 블록이 없으면 그렇다고 첫 줄에 쓰고 우선순위 절만 보고한다.
