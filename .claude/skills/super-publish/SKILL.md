# 슈퍼발행(마야 글 채널판)

정본은 [docs/슈퍼발행.md](../../../docs/슈퍼발행.md)(핏, 2026-10-22). 영상용 도구(`post_verify.py`, `resched_all.py`)는 마야 채널에 그대로 못 쓰므로, 원칙과 용어만 가져와 글 채널 절차로 옮겼다. 글 쓰기 자체는 `ink-desk`가 먼저다.

## 원칙(정본 다섯 중 마야에 맞는 넷)

1. **날짜의 정본은 하나다.** 글 채널은 `assets/data/publish_plan.json`(요일 체계는 `docs/SNS_라이팅_가이드.md` 5절)이다. 영상의 정본은 핏의 주제 시트라 서로 섞지 않는다. 채널 앱에서 따로 날짜를 고치지 않는다.
2. **"예약됨"과 "게시 확인됨"을 나눠 보고한다.** 예약 서비스가 "올렸다"고 해도 실제 글이 있다는 뜻이 아니다. 존재는 따로 본다.
3. **점검은 하루 1회, 알림은 문제가 있을 때만, 한 채널(텔레그램 마야 방)로만 보낸다.**
4. **일정 변경은 한 곳에서 한다.** 새 예약을 먼저 만들고 옛 예약을 취소한다. 삭제는 사장님만 한다(이미 공개된 글은 건드리지 않는다).

## 상태를 부르는 말(보고에서 같은 말을 쓴다)

- **예약됨**: 채널 또는 AItoEarn에 시각이 걸려 있고 아직 공개 전.
- **게시 확인됨**: 공개된 글을 채널 화면이나 API에서 직접 봤다(주소 또는 확인 시각을 남긴다).
- **어긋남**: 게시 기록은 있는데 글이 없다.
- **지연**: 예약 시각이 30분 넘게 지났는데 아직 예약됨이다.

## 새 글을 등록하는 순서

1. `python scripts/slot_audit.py`로 빈 슬롯과 미등록 채널을 본다.
2. 홈페이지 글은 스튜디오에서 예약 설정(`docs/예약_발행.md`), 채널 글은 채널별 방식으로 예약한다: 링크드인·페이스북·인스타는 AItoEarn(`publish-sns.yml`), 브런치·네이버는 `scripts/sns/post_brunch.py`·`post_naver.py`, 로켓펀치·리멤버는 당일 수동.
3. 같은 날 [docs/SNS_등록대장.md](../../../docs/SNS_등록대장.md)에 한 줄 추가한다(날짜, 글, 채널, 방식, 상태 예약됨, 시각).
4. 예약 시각이 지난 다음 세션에서 채널 화면으로 **게시 확인됨**을 확인해 같은 줄 상태를 고친다. 확인 수단이 없는 채널은 "게시 확인 수단 없음"으로 적고 핏 요청 목록에 둔다.
5. 날짜가 바뀌면 `publish_plan.json`과 원장을 같이 고치고, 새 예약을 만든 뒤 옛 예약을 취소한다.

## 게시 확인 수단(핏 실측, 2026-10-22)

- **링크드인·페이스북·인스타·스레드**: AItoEarn 상태 1이고 `workLink`(플랫폼이 돌려준 글 주소)가 있으면 **게시 확인됨**. 플랫폼 응답까지의 확인이라 독립 존재 확인은 아니다.
- **브런치**: 공개 주소가 HTTP 200이면 확인, 404면 어긋남.
- **네이버**: `PostView.naver?blogId=&logNo=` 주소로 확인한다. 짧은 주소는 없는 글도 200이라 쓰지 않는다.
- **로켓펀치·리멤버**: 확인 수단 없음. 당일 세션이 프로필 화면에서 직접 보고 원장에 시각을 남긴다.

## 하루 1회 점검

- 자동: `python C:/work/shorts-lab/tools/publish/text_post_verify.py`(감시 대장에 하루 1회 등록, 핏-발행#63). 큐 registered 항목을 AItoEarn 상태와 대조해 예약 30분 초과 상태 0·6은 지연, 취소·오류·작업 없음은 어긋남으로 보고, 지연·어긋남일 때만 알린다. [실측: 2026-10-22 게시 확인 16건, 문제 0건]
- 마야 첫 세션: `python scripts/slot_audit.py`로 빈 슬롯을 본다. 알림이 왔으면 그 글부터 처리한다. 문제가 없으면 따로 보내지 않는다.

## 원장 상태 칸

`SNS_등록대장.md`의 상태는 **예약됨 → 게시 확인됨**(확인 시각과 주소 한 줄) 또는 **어긋남**으로 쓴다.

## 하지 않는 것

- 영상(숏폼·롱폼)은 이 스킬이 아니다. 핏의 슈퍼발행 도구를 쓴다.
- 채널 앱에서 날짜를 직접 고치지 않는다. 이미 공개된 글을 수정·삭제하지 않는다.
