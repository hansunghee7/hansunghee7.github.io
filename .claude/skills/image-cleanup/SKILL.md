# 이미지 자산 정리 (`log_assets/images/`)

`log_assets/images/`에서 "고아 이미지"(어디서도 안 쓰는 파일)를 찾아 정리할 때는
**절대 블로그 글 본문만 기준으로 판단하지 마세요.** 2026-08-29에 그렇게 정리하다가
사이트 로고(`logo_white.png`)와 JSON-LD용 캐릭터 이미지(`character_black.png`)를
"안 쓰는 파일"로 오판해 격리하는 바람에 실제 라이브 사이트 로고가 깨진 사고가
있었습니다 — 두 파일 다 블로그 글이 아니라 `_includes/`, `_layouts/` 같은 사이트
템플릿에서만 참조되고 있었기 때문입니다.

반드시 다음 스크립트로 확인하세요:

```bash
python scripts/find_orphan_images.py
```

이 스크립트는 블로그 글 본문뿐 아니라 저장소 전체(템플릿·include·JSON-LD·다른
스크립트 등)에서 참조를 찾고, 로고·캐릭터 이미지 같은 브랜드 자산은 이름 패턴으로
한 번 더 보호합니다. **절대 파일을 바로 삭제하지 않고 격리 폴더로만 옮깁니다**(
`--quarantine` 옵션 필요, 기본은 리포트만 출력) — 오판이었다는 게 나중에 드러나도
`git mv`로 바로 되돌릴 수 있게 하기 위해서입니다. 최종 삭제는 격리 폴더의 README를
보고 사람이 직접 판단해서 하세요.

`--quarantine`을 실행한 직후에는 반드시 홈페이지 등 주요 페이지를 실제로 열어
로고나 이미지가 깨지지 않았는지 육안으로 확인하세요 — 이 스크립트는 텍스트 참조
여부만 확인하므로, 그것만으로 완전하다고 보지 마세요.
